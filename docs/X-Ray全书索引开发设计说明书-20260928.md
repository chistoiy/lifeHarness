## 1. 目标与非目标

**目标（一期）**：读者可对任意已导入 EPUB **手动触发**生成全书实体索引（人名/地点/机构/术语/缩写/书名），在 X-Ray 面板浏览、**点击出场记录跳转到阅读位置**，并可增删合并词条形成自增强闭环；纯离线、零模型、零网络。

**非目标（一期不做）**：GLiNER/任何神经网络推理；官方完整 CFI；自动后台解析（导入即跑）；重型任务锁定阅读；电量感知暂停；外部知识库（Wikipedia/Goodreads）；章节摘要/知识点关联（AI 层二期后）。

## 3. 总体架构（与阅读器的集成点）

```
epub_import（新增：算 MD5、写 books.md5）
DocStore 排版快照 ──流式逐章读──▶ XrayEngine（Isolate·单飞串行）
                                   │ 正则通道 / n-gram通道 / gazetteer / 对白通道
                                   │ 仲裁 → 常用词表+称谓路由 → TF-IDF+TextRank+PMI 置信分
                                   │ 叠加用户层（confirm/add/delete/merge 覆盖表）
                                   ▼
                    sqflite: xray_task / xray_entity / xray_mention / xray_userdict
                                   ▼
     书架状态角标(F7) ←进度事件─ XrayScheduler（复用预载服务单飞/状态机先例）
     X-Ray 面板(F4/F5) ─锚点换算─▶ PagStore/分页引擎 ─跳转─▶ reader_page（目录跳章同款链路+段高亮）
     选区工具条(F6/F8) ─命中查询─▶ xray_entity 索引点查
```

约束：解析 isolate 与预载/分页互斥排队（全局单飞）；DocStore 未就绪的章节先触发排版再抽取（复用预载进度）；**任何同步 IO 不得进开书关键路径**（写时物化原则，见 §7）。

## 4. 抽取引擎规格（一期定案栈）

输入：DocStore 段落序列（章号+段号即锚点）。通道：
1. **正则**：`·` 全名/短名拆分｜姓氏+1~2字+语境动词（说/问/认为…）｜称谓+名（23 词表可扩）｜地名后缀/机构后缀｜英文大写缩写｜《》书名；
2. **n-gram**：2~5 字候选 → 首尾虚词字过滤 → 边界熵（两侧邻接均固定=碎片丢弃）→ 包含抑制（子串频次比≥0.7 丢短）→ 章节 TF-IDF → **PMI 结合度**（≥3 字且 minPMI<0.5 丢弃）；
3. **gazetteer**：国家/城市/地区词表最长匹配（主地名通道）；
4. **对白归属**：引号段↔说话人名（正则），产出角色台词计数与代表语录；
5. **TOC 加权**：目录命中词提升置信分并打「目录词」标。

后处理：跨类型仲裁（同名保留最高分类别）→ **常用词表过滤（必须含裸称谓词，实测小说术语噪声 7/40→0/40）** → 称谓组合名路由到人名 → TextRank 分值融入置信分（0.6+0.4×TR）。

阈值：按文本量自适应（demo 公式），产品暴露为设置项「索引灵敏度」（低/中/高，映射候选最低频次）。

## 5. 预置数据（7 张纯文本表 · `assets/xray/dicts/`）

| 表 | 生产规模/体积 | 用途 | 来源 |
|---|---|---|---|
| 停用虚词表 | 千级 / 20~50KB | n-gram 首尾过滤 | 公开中文停用词表 |
| 常用名词表 | 数百~千级 / 30~60KB | 术语净化（含裸称谓/亲属/日常名词） | 自建裁剪 |
| 称谓词表 | ≤200 / <5KB | 人名通道+路由+别名合并三用 | 自建 |
| 姓氏表 | ~150 / <5KB | 人名防伪 | 百家姓（公版） |
| 地名/机构后缀表 | 60+50 / <10KB | 兜底通道 | 沿用 demo 表 |
| 英文虚词表 | ≤200 / <5KB | eng 词防污染 | 公开 stopword |
| **gazetteer 地名词典** | 3~5 万条 / 压缩 300~800KB | 地名主通道 | **行政区划表优先**；若用 GeoNames 需关于页 CC-BY 署名 |

一期预置合计 ≈0.4~0.9MB，APK 增量 ≈+0.5~1MB（另 Dart 代码约 +0.3MB）。加载：isolate 启动时构建集合/首字索引，冷启 ~5ms；三层词库=预置只读 → 全局用户词典 → 按书覆盖层，同构 loader。

## 6. 数据模型（sqflite 迁移 · 自 v30 起，号位见文首校正）

```
books            + md5 TEXT(可空,懒补) 
xray_task        book_md5 PK, total_ch, range_start, range_end, status(pending/running/pause/success/failed/canceled),
                 processed_ch(断点), score_meta, update_time
xray_entity      id PK, book_md5, name, type(per/loc/org/term/abbr/book), n(提及数), chs(跨章数),
                 score(置信分), src_channels(位标志), status(active/user_added/deleted/merged_into:id),
                 aliases(JSON), ai_desc, relation, first_c{ch,para}, toc_flag
xray_mention     id PK, entity_id, book_md5, ch, para, snippet(可空;每实体仅前 N 条带文), 
                 索引 (book_md5, entity_id), (book_md5, ch)   ——锚点全量存，snippet 截断存（体积决策见§10）
xray_userdict    scope(book_md5|GLOBAL), word, type, action(add/forbid/merge_pair), pattern_hint, create_time
```

体积口径（实测背书）：单书索引 0.1~1MB（阿加莎全集 820KB）；「波洛」级高频实体 1.2 万锚点 ≈100KB，可全存。

## 7. 用户层与自增强语义

- **写时物化**：加/删/合并在操作事务内完成 mention 迁移与 score 重算并落库；面板渲染只查询，不重算（守住二次打开 <10ms）。
- **覆盖层**：解析产出候选后永远叠加用户层再呈现；重解析/增量/MD5 复用同一路径，用户结果不丢。
- **删除=状态位**：`status=deleted` 永久屏蔽，阈值再低也不复活；「应用到所有书」写 GLOBAL 黑名单。
- **合并**：称谓组合名规则自动并（标注「按你的惯例」透明化）；译名变体生成候选卡片待用户确认；mention 归属**迁移**至规范名（与账目「改名不迁流水」语义刻意相反——出场属于实体本体）。
- **回流建议**：用户新增词的出现上下文若 ≥30% 命中某模式（如「X+探长」），弹一条「建议规则」卡片，采纳进全局表。

## 8. 任务调度 / 性能 / 功耗

- 全局单飞串行队列（含预载/分页互斥优先级：阅读打开 > 分页 > X-Ray）。
- 内存护栏：按章流式（禁整本驻留）；n-gram 计数**章内先低频剪枝再全局合并**（demo 峰值 275MB → 目标 30~60MB）；候选词表上限+采样（大书按章全跑而非采样，剪枝后不超）。
- 耗时基线（桌面 Python 实测→手机外推）：30 万字单书 2~5s；1000 万字全集 <5 分钟；均有逐章进度与取消。
- 生命周期策略：前台跑；退后台自动暂停（断点已落库），回前台一键恢复。**一期不做后台续跑与电量感知**（工作量级不需要，且避免引入 workmanager 类依赖）。
- 加词全书补扫：走同调度器，秒级，带进度。

## 13. 数据携带性（X-Ray 跟随图书 · 换机零重建）

**归属原则**：X-Ray 一切数据以 `book_md5`（书的内容指纹）为键，**跟随图书本体而非书架条目**；同一 MD5 的多份条目（重复导入/备份副本）共享同一份索引与用户整理结果。

三条携带路径（全部无需重新解析，「再养一遍数据」不存在）：

| 路径 | 载体 | 覆盖内容 | 场景 |
|---|---|---|---|
| A 同设备 | `books.md5` 命中检测（F9） | 实体+出场+任务态+用户层全量 | 重复导入同书 → 提示「直接复用」 |
| B 换机/重装 | **四张表建在 sqflite 主库内 → 自动随 `.lhbak` 整包备份与 WebDAV/S3 快照走，恢复即生效**（无需新文件体系；需在备份排除组登记处确认 `xray_*` 不在排除组，类比 `ai_calls` 先例） | 同上 + GLOBAL 用户词典 | 常规换机，用户无感知 |
| C 单书迁移/分享 | `.xraybak`（F10：md5+实体+出场锚点+context截断+用户层，不含正文） | 单本书 | 跨库合并、把整理好的索引分享给读同一文件的人 |

边界（沿 PRD 原口径）：文件一字不同→MD5 变→视为新书不复用（不同版本）；导入备份仅校验 MD5，内容一致性由用户确认。体积成本已控（单书 0.1~1MB），路径 B 不会撑爆备份。

## 14. 验收与风险

- 抽取验收基线：简史 地名≥20/23、术语≥16/25 噪声≤3/40；阿加莎 人名≥12/20 术语噪声≤2/40（GT 与脚本在预研目录，扩展素材先补 GT）。
- 性能验收：单书 30 万字真机 ≤8s；全集 ≤6min 且不 OOM（内存曲线峰值 ≤80MB）；二次打开书/X-Ray 面板路径新增延迟 ≤10ms。
- 主要风险：①n-gram 计数内存实现不达标 → 章内剪枝阈值调参，兜底分章两遍落盘合并；②后缀碎片残留（机制天花板）→ 由折叠区+用户移除消化，二期 TextRank/ jieba 复审；③原型轮未过即开发禁令（保真流程红线）。
