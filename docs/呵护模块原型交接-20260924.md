## 3. 数据模型（开发对照）

- 事件记录：`{k,s,e,dur,ml,tmp,seg,dia,color,tex,vol,name,unit,amt,note,rec,at}`；展示文本由 `logTitle(r)` / 图标由 `icOf(r)` 生成，不存展示串。
- 亲喂分段 `seg='左L′/右R′'`；辅食过敏 `ala=[{f,r}]`；补剂一条记录一个 name/amt（多条=多条记录）。
- 按宝宝分档字典（键=宝宝索引，删除档案需 `shiftDict` 重排）：`ALLLOGS / GRW / GV / GFOWN / VAXS / MHS / MILES / ALLERGIES`。
- 本机持久化 localStorage：`lh_ev_order`（速记区顺序）、`lh_ev_custom`（自定义事件表）。
- 演示常量：`CARE_TODAY='09-19'`、`CARE_NOW='14:35'`、日期键 MM-DD（解析日用 `slice(3)`）。

## 4. 事件体系

内置 13 类（`EVENTS` 注册表）：母乳亲喂（计时/手动双模）、瓶喂母乳、配方奶、换尿布、睡眠、洗澡、玩耍、补剂、游泳、喝水、辅食、吸奶、自定义（录入流）。
自定义事件：经「管理 → 新建」任意多个（名称/图标池/单位 ml·min·g·次·°C），键 `cus:名`，可改名（键迁移）/换图标单位/删除；可编辑态「固定到速记区」。
速记区：⇅ 排序模式调序；「管理」入口 sheetEvManage。

## 5. 已拍板决策（开发时不得偏离）

1. 模块显示名一律「呵护」（含首页宫格入口「🍼呵护」）；不用「她」第三人称。
2. 周期/宝宝为两个顶层整屏，点左上角标题互切（无切换钮、无页内 tab）；**两视图均不显示返回键**，退出走底部导航；互切不堆返回栈（careSwap 前后 strip 栈中 p-care/p-baby）。
3. 「照护汇总」钮仅宝宝视图显示。
4. 今日列表行不带删除钮（删除在记录详情弹层内）；所有记录全字段可二次修改（含起止时间、量）。
5. 时间/数值输入一律就地内嵌滚轮（WHEELS 基建），禁「点击→弹层→再操作」两段式；日期用 sheetCareDate 品牌选择器（禁原生 date input）。
6. 母乳亲喂录入=竞品式双模：计时（两侧总时长大字+左右圆形计时球+上次徽章）/手动（左右分钟双滚轮+最后使用提示）；编辑既有记录默认进手动模式回填 seg。
7. 补剂=多行「名称|用量」+ 常见补剂 chips 快填，一次保存可入账多条。
8. 尿布：尿/臭臭/混合 + 颜色 7 点 + **粘稠度维持 4 档（糊状/水样/成形/蛋花样，婴儿适用口径，2026-09-24 定案）** + 量少中多；砖红/灰白触发就医参考提示。**不加称重/克重字段（2026-09-24 定案）**。
9. 全天记录筛选=事件类型多选（bdKinds Set，不筛选/确定，标签「全部/单类/已选N项」）；hero 三数据位（喂养/尿布/睡眠）可点进全天记录并自动带筛选。
10. 疫苗计划完整 CRUD + 已完成可「重新发起」；完成自动生成下一针提醒（L10 联动开发期接真）。
11. 宝宝档案/记录人身份均完整 CRUD：新增宝宝初始化独立空档（曲线 2 点占位）；删除二次确认+字典重排+落相邻档；记录人重名拦截、至少保留 1、删默认自动回落、历史署名保留。
12. 周期数据属敏感类：p-careRemind 与设置页均有「排除 WebDAV 同步（模块级）」开关。
