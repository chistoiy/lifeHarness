## 〇、一句话总纲

> **省 token 的本质不是少干活，而是少读无关上下文、少跑无用验证、少重复解释已知事实。**

三类开销与对策：

| 开销来源 | 对策 | 预计节省 |
|---|---|---|
| 读文件（大文件/全仓检索） | 钉子文件 + 定点读 + 脚本代劳 | **50~70%** |
| 跑测试（编译/全量/重复跑） | 工装化 + 单轨 + 一次合并 | 40~60% 时间与 token |
| 重复解释项目事实 | 记忆与工装文档承载 | 会话起步省 1~3 万字 |

## 三、测试与验证：工装化 + 单轨

### 3.1 永远用 `tools/ftest.sh`，不用裸跑

```bash
bash tools/ftest.sh test/reader_ui_test.dart test/reader_select_test.dart
```

内含本机 sqlite3.dll 并发冲突的 4 次重试自旋与专用错误码判定。**裸跑 `flutter test` 会撞 errno=183 假红**。

### 3.2 三条调度纪律（2026-10-02 事故固化）

1. **全仓单轨**：任意时刻只允许一个 `flutter test` 进程。后台批未退出前禁止再开跑。
2. **一次调用合并编译**：开跑前列清本轮全部测试文件，一次跑完。**禁止"跑一轮发现漏了再补"**（每补一轮白付 1~2 分钟编译）。
3. **重套隔离**：`log_page_test` 等全 app 大套件不与轻量套件混批；只需验一组时用 `--plain-name` 限名。

### 3.3 批内 vs 收口（§7.2 两档，不削减）

- **批内**：`flutter analyze` + 仅受影响测试文件 + 批 commit。**不打三包**。
- **收口**：全量（`bash tools/run_gate.sh`）+ 三包 + prerelease + 文档登记。

### 3.4 环境变量清代理（每次都要，忘了起不来）

```bash
HTTP_PROXY= HTTPS_PROXY= http_proxy= https_proxy= NO_PROXY=* flutter test
```

### 3.5 调测护栏（铁律 9，违规会被驳回）

任何可能挂死的调测**先设护栏再跑**：墙钟 80~120s + 峰值内存 1.5GB 超即杀 `flutter_tester`。
量内存用 Dart `ProcessInfo.currentRss` 写临时用例（本机 `tasklist`/`wmic` 取不到进程数据）。
**FakeAsync 里 `print` 会丢**，取证用 `File(<绝对路径>).writeAsStringSync(..., mode: append)`。

**判据速查**：`--timeout` 杀不掉 ⇒ 该 isolate 同步空转 ⇒ **先查死循环，别先查死锁/竞态**。

## 四、改 UI 时的省 token 管线（原型 1MB，不能整读）

阅读器专版原型走**片段管线**（样板 `tools/health/`），绝不整体重写 1MB 单文件：

1. `cp prototype/index-bookshelf.html <改后文件>`（或按 §2.2 铁律 12 复制成专版副本）
2. 新内容拆成 `css/` `pages/` `sheets/` `js/` 片段文件（放**仓库外**）
3. 用**带唯一性断言**的 patch 脚本精确替换（锚点用分区注释 `<!-- ===== P12 …` 与 `/* ================= … */`），失败即报错不落盘
4. 三道校验：`new vm.Script(<最后 script body>)` 验 JS 语法 ｜ 结构断言（**本模块零 emoji** 正则 `[1F000-1FAFF]` 等，**不含排版箭头 →**）｜ 真实 Chrome 无头交互断言
5. 精确视口截图必须走 **CDP**（Windows 无头 Chrome `--window-size=390` 不生效，布局被 clamp 到 ~768，"顶栏按钮不见了"是假象）

**中文单文件里做替换时**：别用 shell heredoc 传含 `$`/`${}` 的脚本（会被展开），写进文件再跑。
