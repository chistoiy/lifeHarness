| 表 | 关键字段 | 说明 |
| --- | --- | --- |

### 2.2 派生数据不落库（重要）
综合达标度、热力格、周报六数据位与环比、周变化/区间变化、配速（可由距离+时长算）、估算 kcal（MET 表）、依从率、达成度环——**全部实时算**，与习惯/记账模块「派生不落库」口径一致，避免改目标后历史失真。
唯一例外：`pace_sec` 与 `kcal` 在保存时落一次（用户可手改，改后以存值为准）。

### 2.3 迁移与守护
- v24→v25 建七表 + 索引（`health_body.date` UNIQUE、`health_exercise.date`、`health_drug_log(drug_id,date)`）。
- 迁移只建表不搬数据（新模块）；`schema.dart` 注释按既有格式登记「v25：健康管理七表」。
- 架构守护：模块目录 `lib/features/health/**` 不得被其他 feature 直接 import（沿用 R-系列规则）；`go()` 目标必须落在 `ShellRoute` 内 tab（R6）。

## 五、口径与算法规范（易错点集中）

1. **综合达标 = 喝水 40% + 睡眠 35% + 运动 25%**，三项分母一律取 `health_goal` 当日目标；各分量封顶 100%。运动为**门槛制**（当日 ≥10 分钟记满分），非比例。⚠ 原型睡眠分母写死 8h 属演示简化，开发按目标实现。
2. **睡眠归属日 = 醒来日**；时长 = 醒来 − 入睡，≤0 则 +1440min。「按时入睡」= 入睡时刻 ≤ `bedLine`（默认 23:30）。
3. **分期四段**之和与总时长差 >20min 时提示核对，不阻断保存；四段全空＝未记录分期。
4. **运动三模互算**：距离/时长/配速知二算一，模式 seg 决定「哪一项是被算出来的」，派生项也要回显（原型曾因此残留上一模式值）；无距离类型（力量/瑜伽/其他）只填时长，距离与配速置灰。
5. **配速**存 `秒/公里`；展示 `m′ss″`。解析输入容忍 `6'00"`、`6:00`、`600` 三种写法（原型 `parsePace` 取前两组数字）。
6. **kcal 估算** = 分钟 × MET（跑步 10.5 · 骑行 7.5 · 游泳 9 · 力量 5 · 球类 7 · 瑜伽 3.4 · 步行 4.2 · 其他 5）；用户填了则以其为准。
7. **BMI** = kg ÷ (cm/100)²；分级 偏瘦 <18.5 · 正常 <24 · 超重 <28 · 肥胖 ≥28。
8. **用药计划** = 每个档案的 `times` × 当日；**已服** = 该时刻有 taken 行；**漏服** = 时刻已过（宽限 `missed` 分钟，默认 30）且无 taken/skipped 行；依从率 = 已服 ÷ 计划。
9. **每周运动次数** = 本周内 `duration_min ≥ 10` 的**记录条数**（同日多条各计一次，与原型一致）。
10. **单位**：存储恒公制；斤 = kg×2，mile = km×0.621371，展示层四舍五入到 1 位。切换单位后所有派生值（周变化/距目标/曲线轴标）同步换算，禁止只换标签不换数。
11. **趋势区间**：周=7 天、月=30 天、年=12 个月聚合；超出实测数据范围时按趋势补全（原型用确定性哈希，正式版改为「无数据日显示空槽 + 文案标注」，不造假数据）。

## 七、跨模块联动

- **时间账本**：运动记录写入「运动」分类（与阅读/观影同构的进度写入路径复用）。
- **目标 OKR**：`week_ex` 目标作为一个 KR 数据源自动汇聚；体重/睡眠可选数据源在目标页登记。
- **提醒通知中心**：新增「用药提醒」（按档案时刻，逐条）与「每日达成度小结」两卡；本模块只登记与展示，**真系统排程延后**，通知中心侧对未排程项标注「V1.x 起排程」。
- **今日仪表盘**：「今日健康」卡（达成度环 + 杯数 + 运动分钟），开关在 `health.show_dash_card`。
- **母婴呵护**：工作台保留母婴入口（跳模块 15），不重复建周期数据。
- **备份与导出**：七表随 `.lhbak`；`include_in_backup=false` 时整模块排除（含用药与身体数据）；CSV/JSON 导出带表头与单位列。

**所有既有健康表同步加 `profile_id`**（喝水/睡眠/运动/身体数据/用药/目标/打卡），默认落在「本人」档案；**跨档案一律不聚合**。

### 11.2 新增路由与弹层
`/health/profile`（档案）· `/health/vitals`（体征）· `/health/symptom`（症状）· `/health/report`（报告）；
弹层 `sheetHProfile`（档案新增编辑）· `sheetHProfileMng`（档案管理）· `sheetHBaseline`（基线）· `sheetHHistory`（病史三组）· `sheetHVital`（五类体征录入）· `sheetHSymptom`（症状录入）· `sheetHReportAdd`（报告建档）· `sheetHMetric`（检验项录入）· `sheetHRemind`（提醒）· `sheetHAiSummary`（AI 小结）。

### 11.3 新增口径
1. **参考区间**（血压 90~139 / 静息心率 55~95 / 血氧 ≥95 / 空腹血糖 3.9~6.1 / 体温 36~37.2）为**内置默认常量**，异常只作提示与汇总，不作诊断表述。
2. **基线对比**：血压显示「较基线 ±」，心率显示「较静息 ±」，其余显示「参考 x ~ y」；无记录时卡片标「未记录」而非「正常」。
3. **血糖时段**四选一（空腹/餐后2h/随机/夜间）+ 饮食备注；血压时段六选一；同一时刻多条允许并存（不同时段）。
4. **疼痛分级** 0~10 就地分段条（0-3 轻 / 4-6 中 / 7-10 重着色），不用弹层与滑杆控件。
5. **报告检验项**：项目库 10 项内置参考范围，点选即带入参考上下限并把数值滚轮量程收窄到该区间附近（避免 0~400 粗滚轮）；自定义项目走宽量程。
6. **AI 小结**两步制：`预览将要发送的内容`（逐行可核对，只含关系称谓 + 聚合值 + 文字描述）→ `生成`；输出卡固定带「AI 生成 · 仅文本整理」与「不构成诊断或用药建议」两行；可复制或存入笔记。
7. **提醒排程**：开关切换即 `schedule/cancel`；复诊提醒同时写一条「重要日子」倒数卡（复用既有通道，不重复造轮子）。
8. **档案删除**二次确认且明示「连同该档案全部健康数据移除」；病史类文本随档案导出与删除。
