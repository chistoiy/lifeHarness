## 6. 注意事项 / 已知点

- ⚠️ **云协议排障 SOP（V1.41 R6 固化，做 S3/WebDAV 相关问题前先读）**：
  1. **本地直连验证通道**：`node tools/cloud_verify.js`（脚本零密钥可入库；凭据放 gitignored `tools/.cloud_verify.env`，**用完即删**，永不进仓库/提交/日志/release 正文）。App 报云端 4xx 时先跑脚本对照「脚本 200 vs App 4xx」判定差异在 App 请求还是云端。
  2. **二分定位法（R6 实战验证）**：脚本 200 → 用 App 同款代码（`SigV4Signer`+`toWireUri`+http 包）写一次性 dart 探针复现 → 加/减头部二分排传输差异 → **固定同一时间戳让 App 与 node 各签一次、逐字节比对 Authorization**，差异一目了然（R6 即以此锁定 credentialScope 段序写反：AWS 规范 `date/region/service/aws4_request`，写反时缤纷云严格节点 List 回 400 InvalidRequest、列桶回 403，宽松节点碰巧放行=潜伏隐患）。
  3. **SigV4 三钉**：canonical URI/query 必须与实际 wire 逐字节一致（`sign()` 内置校验拒发）；`x-amz-copy-source` 要进签名头集且按字典序（R5d）；scope 段序 date/region/service（R6）。测试钉值改动时须用独立实现（node crypto）重算签名，不许拿被测代码自产期望值。
  4. **坚果云**：MOVE 目标父目录不存在回 **404**（非 409），两种状态都要触发补建父目录重试；put 前无条件预建父链（根级文件也要建 cloudDirName 集合）。
- ⚠️ **真机联调（USB）固化经验（2026-09-25）**：
  1. **安装 -25「无法降级」**：split-per-abi 三包 versionCode 带 ABI 偏移（base+1000 v7a / +2000 arm64 / +4000 x86_64），arm64 手机误装 v7a 包即被判降级——**真机一律下 arm64-v8a**，release 正文已带此提示；覆盖安装数据无损，**绝不要卸载重装**（会清本机库）。
  2. **adb 注入点击需 HyperOS「USB 调试（安全设置）」**单独开启（普通 USB 调试只给截图/装包）；未开时切「我发指引+用户操作+我拉日志/截图核对」协作模式，勿反复重试 input tap。
  3. 构建/测试与 adb 并行时注意 sqlite3.dll 文件锁互踩，flutter 命令串行执行。

- ⚠️ **测试挂死 ≈ 先怀疑死循环，别先怀疑死锁**（2026-09-20 事故）。本工程已在 `flutter test` 里踩过一次代价极高的坑：一处 `for` 增量子句漏写 `++` 导致**同帧同步死循环**，表现为"CPU 满核 + 内存涨到 20GB + `--timeout` 杀不掉"。判据与处置：
  - **判据**：`--timeout` 杀不掉 ⇒ 该 isolate 不让出事件循环（同步空转），不是等锁/等 IO，因此**不要**去查死锁、`pumpAndSettle` 收敛性、异步竞态。
  - **定位**：在被怀疑的点插"自终止护栏"（计数超阈值即**写绝对路径文件**再抛错——FakeAsync 下 stdout 缓冲不会 flush，`print` 取证会丢）。护栏落在 `build` 里却不触发时，说明循环在 `initState`/`layout`/非 build 路径，换点再插。日志用绝对路径（`flutter_tester` 的 CWD 未必是工程根）。
  - **修复**：构建定长列表一律 `List.generate(n, (i) => ...)`（无增量子句 = 该 bug 不可表示）；其次才是手写循环并确保 `i++` / `i += n`。
  - **守护**：`test/architecture_test.dart` **R4** 静态扫描 `lib/**`，裸标识符/字面量作增量即测试红（已用注入原 bug 验证会精准报出 `文件:行`）。新增/改动循环后请跑 `flutter test test/architecture_test.dart`（秒级）。
  - **调测护栏（以后跑任何可疑用例都先这么做）**：`--timeout` 靠不住，必须在**进程外**设两道闸——内存阈值 + 墙钟超时，超了直接 `taskkill /F /PID` 掉 `flutter_tester.exe`。本机 `tasklist`/`wmic` 取不到进程数据，量内存用 Dart 自带 `ProcessInfo.currentRss`（写进临时用例，跑完删）最稳。示例（Git Bash）：

