## 4. 关键决策记录（ADR 摘要）

| # | 决策 | 原因 |
|---|---|---|
| D1 | 纯本地无账号 | 隐私优先、离线可用，降低 V1 复杂度 |
| D2 | 同步=本地备份+WebDAV(坚果云) | 用户自有云盘，无需自建服务端 |
| D3 | 四象限为核心交互而非附属视图 | 体现时间管理理念，差异化卖点 |
| D4 | 微信读书走第三方导出解析 | 无官方导出接口 |
| D5 | 番茄钟/习惯/OKR完整/生活记录/人生看板后置 | 控制 V1 体量，按依赖成熟度排期 |
| D6 | V0.1 建库即预留 健康/财务/物品 表 | 避免后期数据迁移 |
| D7 | 物品「每日成本」用直线法默认、可选按次/止损 | 兼顾简单与真实 |
| D8 | 模块联动经 shared/linkage 服务解耦 | 防止 feature 循环依赖 |
| D9 | 原型仅 Tailwind CDN + Inter 字体，禁重型 UI 库 | 单文件、双击即运行、无后端 |
| D10 | Anthropic 采用客户端内置协议适配器（Messages API），不引入官方 SDK | 一个验证工具覆盖全服务商；Key 按服务商独立存储域；避免 SDK 重依赖（V1.17） |
| D11 | 原型层持久化统一用 localStorage（主页布局等），正式版换设置表并随备份策略 | 原型可真实验证刷新后仍保持；两环境实现差异已抽象为存储接口层（V1.17） |
| D12 | **不设置应用锁/PIN**（OQ-1 拍板） | 纯本地无找回通道，锁丢=数据永久不可恢复，危害大于收益；图标伪装如需入 V1.x 备选池；设置页该行已在原型中置灰标注（V1.18） |
| D13 | **统计日界线固定自然日 00:00**（OQ-2 拍板） | 夜间哺乳/睡眠/跨天事件由「开始日归属+跨天标记」机制保障，无需偏移日界；降低实现与认知复杂度（V1.18） |
| D14 | 插件试点维持 M4；排期接受 M0~M4 全量约 29 周，M1 末发首个内测（OQ-3/排期 拍板） | 宿主能力 API 冻结+双试点验证后再迁移，稳妥优先；需求进入可开发状态（V1.18） |
| D15 | **本地数据库定案 sqflite（放弃计划书首选 Isar）** | Isar 稳定版 3.1.0+1 已停更约 3 年、v4 仅 dev、仓库归档，在 Flutter 3.38/Dart 3.10 大概率无法编译；触发计划书「48h 切 sqflite」预案，Repository 层隔离 DB 实现（2026-09-19 用户确认） |

