## 二、数据模型（DB v12 → v14）

约定：全部表在宿主库 `lifeharness.db`；`book_` 前缀；软删除统一 `deleted_at`；时间戳统一 `INTEGER`（epoch ms）；JSON 列以 TEXT 存。

### 2.1 v12 · 书与阅读行为（批1）

```
books(
  id TEXT PK, title TEXT NOT NULL, author TEXT NOT NULL DEFAULT '佚名',
  translator TEXT, publisher TEXT, pub_date TEXT, series TEXT, isbn TEXT,
  cover_path TEXT,                 -- 应用目录相对路径；空则用色板渐变
  color_idx INTEGER DEFAULT 0,     -- 书脊色板下标（原型 BS_COV）
  state TEXT,                      -- 在读|想读|已读|弃读
  format TEXT,                     -- 纸质|电子书|有声
  progress_way TEXT,               -- page|pos|chap|pct|min（随 format 默认）
  pages INTEGER DEFAULT 0, read_pages INTEGER DEFAULT 0,
  total_loc REAL, read_loc REAL,   -- 电子书位置单位（Kindle location / 微信读书百分比）
  chapter TEXT,                    -- 进度方式=章节时的当前节点
  rating REAL DEFAULT 0, fee REAL DEFAULT 0, fee_txn_id INTEGER,  -- 费用自动生成记账流水后回填
  source TEXT, grp TEXT,           -- 来源/分组（字典表可校验，非外键）
  started_at INTEGER, ended_at INTEGER,
  intro TEXT, author_note TEXT, note TEXT, final_note TEXT,
  created_at INTEGER, updated_at INTEGER, deleted_at INTEGER)
  索引：state / author / source / grp / isbn(unique 部分索引 where isbn<>'')

book_sessions(                    -- 一次计时＝一行，L4 账本数据源
  id INTEGER PK AUTOINCREMENT, book_id TEXT NOT NULL,
  started_at INTEGER NOT NULL, ended_at INTEGER,
  minutes INTEGER DEFAULT 0, speed REAL,      -- 倍速（有声）
  from_page INTEGER, to_page INTEGER, from_loc REAL, to_loc REAL,
  source TEXT DEFAULT 'timer',                -- timer|manual|import
  txn_id INTEGER)                            -- 时间账本回填（L4）
  索引：book_id / started_at

book_quotes(
  id INTEGER PK AUTOINCREMENT, book_id TEXT NOT NULL,
  kind TEXT NOT NULL,                          -- 划线|感想
  tag TEXT NOT NULL,                           -- 重点|共鸣|待查证|行动|疑问（颜色同源）
  body TEXT NOT NULL, thought TEXT,
  chapter TEXT, page INTEGER, loc REAL,
  image_paths TEXT,                            -- JSON 数组，摘录配图
  starred INTEGER DEFAULT 0,
  created_at INTEGER, updated_at INTEGER, deleted_at INTEGER,
  origin TEXT,                                 -- 手动|OCR|微信读书|Kindle…（导入溯源）
  dedup_hash TEXT)                             -- 去重键（见 §5）
  索引：book_id / tag / created_at / dedup_hash(unique)
```

### 2.4 迁移与守护

- 迁移只做 `CREATE TABLE` + 必要 `ALTER`，不猜数据；`onUpgrade` 每版单独一段，与既有 v3~v11 写法一致。
- 升级后首启跑一次「一致性自检」：`books.state` 合法值、`progress_way` 与 `format` 的默认映射、孤儿 `book_sessions/book_quotes`（书已删）→ 归档不崩。
- 时钟回拨防护沿用需求清单「日期水位线」：`book_sessions` 起始时间戳落库，重启续计不重复入账；`ended_at < started_at` 直接丢弃并记日志。
- 测试环境约束（既有踩坑）：widget 测试用 `databaseFactoryFfiNoIsolate`；全量测试**必须按模块拆独立文件**防 isolate 污染挂死。

### 3.1 信息架构收敛规则（2026-09-22 · 已按此改原型）

书架页从 1464px/11 块压到 808px，详情页从 37 个按钮压到 24 个。落地时**必须保持**这几条，否则实现会把页面重新堆回去：

1. **一行筛选**：分区 chips 常驻一行；「按维度」「排序」做成触发条（点开是二级面板 `sheetShelfDim` / `sheetShelfSort`），标签行**只在维度=标签时出现**。禁止把 8 个维度 chips 与标签 chips 同时平铺。
2. **入口收进一行图标工具条**：笔记库/统计/书单/资料/导入/设置/复习/继续 = 一行 8 个图标钮（58px 宽），不做 2×4 大卡。
3. **年度信息只留一处**：目标卡内一行「N / 50 本 · 还差 M 本 ·〔今年读完〕」，宫格默认折叠；不再单独占一张 268px 的卡。
4. **操作分三层**：常驻主操作 ≤3 个（详情页头＝记摘录 / 记进度 / 操作）；其余进 `sheetBookOps`（编辑·改分区·标记读完·移入书单·轨迹·导出·移除）；摘录卡的收藏/转日记/转待办/转笔记/复制/删除全部进 `sheetQuoteOps`，卡片右上角只在已收藏时显示小星。**卡片上不再平铺 →日记 / →待办 链接。**
5. **tab 只留 5 个**：书摘（内嵌 seg 全部/划线/想法/星标）· 目录 · 总结 · 轨迹 · 相关。原「划线」「想法」两个 tab 合并，不新增第六个。
6. **统计钻取折叠**：年份/月份/度量/构成 收在一条「2026 · 全年 · 时长 · 标签 ▾」触发条下，展开才占高度。
7. **不写教学性说明**：原「书架规则」「这一页能做什么」「书单能怎么用」「两级目录…」「均速按…」等解释卡已删；只保留功能标签与状态提示。
8. 长按书籍＝直接弹 `sheetLongPress`（项与顺序来自设置），不再默认进多选；多选入口在长按菜单里。

## 五、导入与去重规范

渠道矩阵（原型 `BS_IMP` 已列 28 家）分五类：**授权**（微信读书、三联）·**电脑端配对**·**API**·**文件**（Kindle / KOReader / BOOX / Apple Books / 豆瓣阅读 / 京东读书 / 掌阅 / iReader / Neat Reader / 汉王 / 滴墨 / Koodo / Reeden / Readeast / 晒书房）·**剪贴板**（按来源模板自动识别 9 家）。

- 格式表以**资源数据包**形式随包（`assets/read_import/*.json`：渠道 id、字段映射、去重键、示例片段），符合需求清单「解析器数据包」插件化方向；格式变更不必改 Dart 代码。
- 去重三级：`isbn` → `author + title 归一化` → 摘录 `dedup_hash = sha1(bookKey + chapter + page + normalize(body))`。命中即跳过并在预览里标「已存在」。
- 解析兜底：规则解析失败 → 提示走 AI 识别格式（需求清单 AI 表「导入解析兜底」），AI 不可用时只跳过不崩。
- 导入写库必须**整批事务**，UI 提供「撤销本批」。
- 导入的原文与想法若来自同一卡片，落 `book_quotes` 一行两字段；`origin` 记渠道，便于二次清洗。

## 七、跨模块联动

- **L4 时间账本**：`book_sessions` 结束即写账本流水（分类=阅读），回填 `txn_id`；删除会话时同事务删流水；**计时明细被手工修改（改时长/日期/页码或补记）时按差量更新同一条流水**（`txn_id` 复用不新建，补记走 `origin='手动补记'`），并回算 `books.min/times/rp/p` 与起止日期；**购书费用默认自动生成一笔「阅读-购书」支出流水**（`books.fee > 0` 且未生成过流水时写入，回填 `fee_txn_id`；改费用则同事务更新该笔；删除书籍时流水保留并在记账页标「来源书已删」）。
- **L5**：摘录卡「→日记」插入今日日记草稿（复用 `journal_sections` 结构）；「→待办」生成任务（默认无截止日，遵守「截止日当天不算逾期」既有口径）。
- **L7 目标**：年度本数、每日/每周时长、每周读书天数、每月摘录数五路汇聚；周报与仪表盘卡引用。
- **收集箱**：每条收集箱可分流为「阅读摘录」，落库时 `origin='收集箱'`。
- **影音游同构（2026-09-22 定案：不共表）**：阅读计时**独占 `book_sessions`**，观影计时另建 `media_sessions`，两表字段同构（起止/时长/倍速/进度区间/来源/`txn_id`）。理由：① 阅读有「位置↔页」折算与目录节点匹配，观影是集数与时间点，口径不同；② 账本分类不同（阅读 vs 娱乐），分表可各自加索引与统计口径；③ 影音游后续可能插件化（需求清单 V1.15），分表便于整表随插件卸载清理。**共用的只是代码层**：`SessionRepository` 抽象基类 + L4 流水写入器同一实现。
- **插件化**：阅读模块整体保持内建（数据密集、与账本强耦合），仅**导入解析数据包**外置。

## 九、风险与未决

1. **位置单位**：Kindle location 与页无固定比例，只能按当前书线性折算；UI 必须显示「≈」并允许改回页数。
2. **OCR 依赖**：Android 侧 ML Kit 需额外原生库，本机网络受限（GitHub/download.flutter.io 不可达）——批3 先做「手动粘贴 + 图片附件」，OCR 作为可选插件包，装不上时入口置灰而非隐藏。
3. **导入渠道维护成本**：28 家渠道格式随版本漂移，必须走数据包 + 解析失败兜底，不能硬编码。
4. **有声书计时口径**：倍速折算与「播放时长」二选一，默认折算；若与影音游倍速记录冲突，统一到会话表。
5. **已拍板（2026-09-22）**：① 计时会话表**不与观影共用**——阅读用 `book_sessions`，观影用 `media_sessions`，仅代码层共用仓储基类与 L4 流水写入器（见 §7）；② 摘录**不跨书合并**，`book_quotes.book_id` NOT NULL，一条摘录只属于一本书，跨书聚合只在「笔记库」视图层做；③ 购书费用**默认自动生成记账流水**（`read.feeTxn` 默认 true，可在阅读设置关闭；关闭后只保留费用字段不出账）。
