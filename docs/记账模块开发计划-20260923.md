# 记账模块开发计划（V1.32 定稿 · 2026-09-23）

> 事实源：`prototype/index-ledger.html`（记账专版高保真·16 屏 + 7 弹层·全功能可操作）
> 设计规格：`docs/superpowers/specs/2026-09-23-ledger-prototype-design.md`
> 需求依据：《需求清单》模块 8（V1.32 记账专版定稿段）
> 校验三件套：`node tools/ledgercheck.js`（emoji/处理器/id）· `node prototype/checkjs.js` · `node prototype/checktop.js`
> 排期定位：M2（V1.0）基础记账 + 账单导入；M3（V1.1）预算/报表/资产/周边全家桶，两批间可并行插单。

## 一、模块定位与对标

- 对标小星记账等成熟记账 App：**速记体验、多账户资产、两级分类、预算体系、报表钻取、周期账单、心愿单、借贷、标签、结转、搜索、导出**十二簇能力一个不缺。
- 与既有约定对齐：纯本地无账号、金额永不上传；账单导入四步向导（V1.9）保留并加「导入至账户」；记账模块**永久原生内建**（V1.25 拍板，不做插件化）。
- 分类边界：记账分类树独立（`ledger_categories`），与 V1.19 全局分类表（日程/时间账本 CATS/SUBS）互不共用；两树各自管理各自入口。

## 三、数据模型（Drift · 与原型 `L` 对象一一对应）

```sql
CREATE TABLE ledger_txns(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  kind TEXT NOT NULL,              -- expense|income|transfer|refund|adjust
  amt REAL NOT NULL,               -- adjust 允许负值；其余恒正
  cat_id INTEGER, sub TEXT,        -- 两级：一级外键 + 子分类名（原型口径）
  account_id INTEGER NOT NULL, to_account_id INTEGER,
  date TEXT NOT NULL,              -- 'YYYY-MM-DD' 归属日（自然日）
  note TEXT, tags TEXT DEFAULT '[]',
  source TEXT NOT NULL DEFAULT 'manual',  -- manual|bill|recurring|wish|debt|item|read|import
  link_id TEXT,                    -- 物品名/日程id/书id 等弱引用
  refund_of INTEGER, recurring_id INTEGER, bill_hash TEXT,  -- 去重键
  created_at INTEGER
);
CREATE TABLE ledger_accounts(id INTEGER PRIMARY KEY, type TEXT, name TEXT, base REAL,
  credit_limit REAL, bill_day INTEGER, repay_day INTEGER, icon TEXT, color TEXT, archived INTEGER DEFAULT 0);
CREATE TABLE ledger_categories(id INTEGER PRIMARY KEY, kind TEXT, parent_id INTEGER, name TEXT,
  icon TEXT, color TEXT, hidden INTEGER DEFAULT 0, sort INTEGER);
CREATE TABLE ledger_budgets(month TEXT, cat_id INTEGER, amt REAL, total REAL, carry INTEGER, PRIMARY KEY(month,cat_id));
CREATE TABLE ledger_recur(id INTEGER PRIMARY KEY, name TEXT, amt REAL, cat_id INTEGER, sub TEXT,
  account_id INTEGER, freq TEXT, next_date TEXT, active INTEGER);
CREATE TABLE ledger_wishes(id INTEGER PRIMARY KEY, name TEXT, target REAL, saved REAL, done_date TEXT, done_txn INTEGER);
CREATE TABLE ledger_debts(id INTEGER PRIMARY KEY, side TEXT, person TEXT, total REAL, paid REAL, note TEXT);
```

- **余额口径**：账户余额 = `base + Σeff(流水)`，写路径同事务重算物化列 `ledger_accounts.balance_cache` 供仪表盘快读；`refund` 冲抵分类支出、`transfer` 只移动余额、`adjust` 由「调整余额」生成差量流水（原型已按此实现，回归基线）。
- **月口径**：预算/统计按 `date` 自然月归属；`monthStart=15` 仅影响「日均可用」与结转周期显示，不改变流水归属。
- **去重**：账单导入 `bill_hash = 交易单号 ?: hash(时间+金额+对方)`，UNIQUE 索引兜底。

## 四、逐元素操作逻辑总表（关键交互·防回退）

| 元素 | 行为 |
|---|---|
| 记一笔键盘 | 数字追加/小数点唯一/连续运算先乘除后加减（`12+3×4=24`）；`⌫` 逐字符；保存校验金额>0、转账账户互斥 |
| 保存后 | `afterSave=back` → 回 L1 并五处联动刷新；`stay` → 清金额留在表单 |
| 分类宫格 | 一级横滑 rail 选中高亮 ring；子分类 chips 再点取消；＋子分类 → 直达分类管理新增 |
| 退款 | 仅 expense 且未被退过；生成 refund 流水互链；分类/预算/合计同步冲抵 |
| 删除 | `confirmDel` 开：双击确认（2.6s 窗口）；删原支出连带删其 refund |
| 转账 | 详情页展示 转出→转入；不计收支；余额双向移动 |
| 周期账单 | 到期日 `next<=today` 汇总横幅 + 批量生成；生成即 `next=freq+1周期`（月频按同日号、月末截断）；写 L8 续费提醒日程 |
| 预算 | 总环/分类条>100% 红 + 「已超支 x」；日均可用 =（总−已用）/剩余天数；结转=上月剩余滚入总额 |
| 资产 | 净资产=Σ正余额−Σ负余额；删除账户守卫余额清零；「调整余额」生成 adjust |
| 分类删除 | 有流水 → 二次确认后流水整体迁移「其他」；兜底分类不可删 |
| 心愿兑换 | saved≥target 才可用；选账户生成 expense（source=wish）并归档 |
| 借贷还款 | 记还款/结清均生成实际流水（source=debt），进度条回写 |
| 金额隐藏 | 全局开关，所有 AMT() 出口统一打点 |
| 搜索筛选 | 条件即时组合过滤（AND），结果合计实时；标签单选切换 |

## 五、批次拆解（开发 · 每批独立可测）

1. **批1 核心闭环（V1.0 随基础记账）**：表 v7→vN 迁移、L1/L2/L3/S1/S2、写路径回算、导入向导「导入至账户」列接线；测试对齐原型断言（联动/转账/退款/删除守卫）。

## 九·补 · V1.33 修订（验收轮1 · 2026-09-23）
- **多账本**：新增表 `ledger_books(id,name,sort)`；`ledger_txns` 加 `bk INTEGER NOT NULL`（索引 (bk,date)）；`ledger_budgets/recur/wishes/debts` 均加 `bk`；**账户表不加 bk**（全局共用），余额=base+Σeff(全部流水)；账本删除守卫=账本内流水数 0。
- **记一笔新增列**：`ledger_txns` 加 `unpaid INTEGER DEFAULT 0`（未付款：计入收支不动余额）、`nb INTEGER DEFAULT 0`（不计入收支和预算：从 mStat/catStat/预算剔除）、`merchant TEXT`、`who TEXT`（自己/家人/…）；借贷 tab 直写 `ledger_debts`。
- **常用类别**：`ledger_fav(catId,sub)` 收藏表；记一笔 chips = 收藏 ∪ 近 30 天高频子分类（去重截 12）。
- **路由新增**：分类选择半屏为记一笔内弹层（非独立路由）；分类管理/新增沿用 `/ledger/cats`。
- **测试补充**：双账本隔离回归（切换后 L1/L4/L5/L9/L10/L11/L12 全部随 bk 过滤）、unpaid/nb 两开关的四出口口径、子分类改名同步流水。

## 九·补2 · V1.34 修订（验收轮2 · 2026-09-23）
- **数据模型增量**：无新表。约定复申：S1 速记半屏撤销后，「记一笔」唯一入口为全屏 `p-txAdd`（真实版 FAB 直接路由，不留中间态）。
- **交互口径**：① 记一笔快捷 chips =「当前大类子分类 ∪ 回落常用集」，且**按当前 tab 的收支树过滤**（收入 tab 只出收入大类及其子类）；首枚=大类本身，点它记到未细分；② 弹层层级固定：分类半屏 50 < 新增分类页 70 < 所属大类选择 80，关闭逐层回退；③ 分类管理大类/子分类均长按拖动排序（同列表内重排，跨树仅换父不改序）；④ 报表分类排行双维度：大类=按 `cat`、小类=按 `cat|sub` 聚合 Top15，sub 为空归「未细分」；两维度均支持点击钻取该类目流水。
- **实现提示**：常用类别回落集仍读 `ledger_fav` ∪ 近30天高频；kind 过滤在取 chips 时做（`LCATS[kind]` 树），不要在收藏表里冗余 kind 字段。

## 九·补3 · V1.35 修订（验收轮3 · 2026-09-23）
- **数据模型增量**：无新表新列。消费洞察为**纯前端规则引擎**（真实版同样不需要 AI：主要支出占比、环比 ±5%、预算 90%/超支、最大单笔四规则，输入=当前区间聚合值），洞察条目不落库。
- **图表口径**：趋势柱按 `max(支出+收入)` 堆叠归一（防溢出）；趋势曲线与柱共用同一 buckets 数组；曲线均值线=区间总额/桶数（年视图=月均，其余=日均）；峰值气泡越界时 x 夹取到 [54, W-54]。
- **主页布局**：五宫格功能入口（资产/预算/报表/周期/更多）是顶部渐变卡的组成部分（Flutter 实现放同一 Container 内），不再是独立卡片行。

## 九·补4 · V1.36 修订（验收轮4 · 2026-09-23）
- **导入数据模型**：`ledger_import_batches`（批次 id、平台、文件名、写入条数、新建账户 ids、时间；支持整批撤销=按批次删除其流水并可选回收空账户）；txns 沿用 `src='bill'` + note 存「平台 · 日期 时刻」。账户匹配结果不落表，仅本次导入生效；选「自动新建」时按付款方式名建本地账户（debit/credit/ewallet/invest 按列推断，credit 无额度默认 0）。
- **导入管线口径**：解析（表头前缀识别+编码自适应）→ 按「付款方式」列聚合出账户清单做匹配 → 逐笔去重（交易单号唯一键优先，缺失时 时间+金额+对方 MD5 兜底）→ 预览三组（新/重复/将写入=勾选集）→ 确认写入。重复组允许强制勾选导入（用户可能在本地删过）。
- **UI 口径**：向导五步 imp-dot 进度；预览组可折叠、组内全选、行内点分类循环改（真实版弹分类选择半屏）；确认按钮文案实时「确认导入 N 条」。

## 十、未决

- U-1 报表「自定义区间」是否需要预置快捷段（近30天/今年）——原型仅日期两端，真机可加。
- U-2 心愿单「存入/取出」是否生成真实流水（当前原型仅记进度不动账，兑换才出账）——保持现口径，如需入账改口径需回改原型。
- U-3 借出/借入是否纳入净资产（当前不计入，避免重复计量）——同 U-2 走确认门。
