## 1. 9a 原型施工规格（本批唯一交付）

重建 `prototype/index-media.html` 的 `m-import` 段＋两枚新弹层，形态对齐记账导入五步定式（先例＝批3.6 记账四屏）与 §五 文字：

1. **渠道矩阵**：13 家按**取法五档分组**（授权 / 电脑端配对 / API / 文件 / 剪贴板），每行＝渠道名＋取法徽标＋格式说明一句（人话，不写教学长文）；Steam 库扫描＝占位灰钮（本机扫描无通道，明示不编）。
2. **导入五步**（半屏或整屏按记账定式择一，过门点②）：选渠道 → 给料（文件选择/粘贴区/配对说明）→ **解析预览**（识别出的条目逐行：命中外部 id/标题年份/将新建或将更新/重复跳过计数）→ 确认导入 → 结果页（新增/更新/跳过三计数＋**撤销本批**一行）。
3. **粘贴自动识别**：单输入框，粘 IMDb `tt\d+`／豆瓣 subject_id／Steam `app/\d+` 前缀即出「识别为 X · 去录入/去导入」两动作（与录入弹层已有剪贴板识别同口径）。
4. **导入歌单**（音乐详情「导入歌单」钮现挂 toast）：接真形态＝半屏选源（网易云/Spotify/QQ/Apple Music 四家文件/粘贴两法），预览复用五步第③④段。
5. 演示数据零随机；读数全现算；emoji 零；「演示」字样禁（批8b A16b 同闸）。

**闸**＝新常驻 `media_b9acheck.js`（tools/ 新立）（无头 CDP，沿 b8b 工装：轮询全局在场＋独立算子期望值现算＋变异刀≤3）；registry 登记新弹层 id；protogate strict 零违例。
