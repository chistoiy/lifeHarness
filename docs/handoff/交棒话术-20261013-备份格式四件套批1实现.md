## 批1 范围（本工单·核心链）

1. **P0-3 套包排除**：`LhBak` 打包对附件成员按扩展名排除 `.lhbak`（本地导出与同步快照两条腿同闸——`exports/` 落点的云快照同样套包）。
2. **P0-2 退版包 schema 漂移**：`unpack` 从「按包内快照 DDL 重建」改为**按当前 schema DDL 重建＋按列交集拷贝**；快照缺表按当前 DDL 建空（missingTables 口径不变）；快照多出的遗留表（如 events 退役）按快照 DDL 保数据迁入；辅助索引/触发器＝当前 schema 的建、快照遗留 best-effort；事务后显式 `PRAGMA user_version = 当前版本`。
3. **P0-1 附件落盘恢复**：新增 `LhBak.restoreAttachments`（`attachments/<目录名>/...` → 目录映射落盘、`attachments/<散件>` → 根落点；加密包逐成员解密；**组在包内才清旧目录**）；`BackupService.importBackup` 在 unpack 成功后接线（目录映射＝attachDirs 基名→原目录，散件根＝attachRootDirs 父目录）；恢复报告增附件组清单。
4. **structVersion**：manifest 增 `structVersion`（create 写 2；旧包无此字段读作 1，verify 双版本通吃）。
5. 新增常驻用例（面板第三行）。

## 红线

- 附件恢复失败＝导入失败（fail loud，自动备份 `auto_before_restore_*` 已先行可回退）。
- `unpack` 整库替换语义不变，**绝不复用做子集恢复**。
- 凭据（云 token/密码/口令）绝不入包。
- 旧口令加密包解侧（KDF 白名单/轮数封顶/GCM tag）一行不动。
