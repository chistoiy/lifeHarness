## 1. 结论速览

1. **架构选型正确，不建议换内核**：「内容层（自研抽取＋CSS 子集解释器）→ Flutter TextPainter 测量 → 自研 PagStore 分页 → widget 树绘制」四层分工**今天仍成立**；`docs/阅读器排版路线说明-20261003.md` §四「否掉 WebView 整页」的理由（划词/书摘/CFI/简繁/X-Ray 全锚在自研 `PagPiece` 原文坐标上，换内核＝跨 JS 边界全部重做）**已核，今天仍成立**。
2. **一条既有挂账要销号**：**「分页表按章分片、开书只读当前章」已落地**（`PagStore` v6，见 §2.1）——真机读数表里的「取表 886ms/997ms」是 **v6 之前**的旧数，须重测（见 §6）。
3. **效率侧 4 条硬伤**：无段级测量缓存、`layoutChapter` 溢出段双测、`EpubDocCache` **名 LRU 实 FIFO**、`_LazyChapterList._cache` **无上界**（见 §2.2）。
4. **手感侧 6 条**：底栏三图标与抽屉多行**裸 `GestureDetector` 零按压反馈**、翻页动画**手写 220ms 单向**、放大镜**每帧 `toImageSync` 抓整页**、手柄/色点触控 **<44**、划线**无撤销**、进度 seek **无节流**（见 §4）。
5. **UI 侧**：原型五层语义色写死深色（深底不可读）、慢提示色对比 **1.11**、二级页**系统返回键不闭环**、阅读器失败态**未接现成 `LoadErrorBanner`**、硬编码色 **119 处**、**不支持项提示行未与「跟随原书样式」开关联动**（见 §3）。
6. **一条最可能被用户读成 bug 的**：**滚动模式位置不跟踪也会在退出时写错进度**（`_setMode` 无定位、无滚动监听，见 §3.5）。

## 2. 效率与架构

### 2.1 一条挂账要销号：分页表**已按章分片**（v6）

- `lib/features/read/data/epub_cache.dart:39 class PagStore`（`tableVersion = 6`，`:52`）；`:78 _chapterFile(...) => ch_$ci.json`＝**单章分片**；`:97 static Future<bool> hit(...)` 只读几 KB 的 `index.json`（注释原话：「**不是取表**」）。
- 文件头注释（`:33-37`）明写：「旧单文件全书表一次取表随体积涨到约 1 秒（新书 7ms），**开书/续算一律只按章读写**，取表成本不再随书体积增长」。
- ⇒ **批三工单 §3G「结论二：必须与分页表分片同批」已兑现**；本项建议**正式销号**（原挂账见批三工单 §3F 三条候选第一条）。
- ⚠ 但 `§3G` 读数表（温开「取表=命中 886ms」/冷启 997ms）与 v6 代码**矛盾** → 见 §6 待确认。

### 2.3 现状：已被证伪的「低效」点（别再改）

- **按章懒排为真**：`reader_page_pag.dart:56 void _ensure(...int ci)` 只排 ci；翻章 `reader_page.dart:532 _ensureCur(); // 跨章＝按需实算新章`，**不重排全书**。
- **测量与渲染同源红线成立**：`TextSpan paraSpan(`（`reader_pager.dart:621`）为唯一出口，测量 `:741` 与上屏 `reader_stage.dart:355` 同吃；分段表 `paraRunStyles`（`:484`）亦单出口。**无「两处各算必出空页」风险**。
- **整本驻留只在 `openFileDetached`**：`epub_doc.dart:315 openFileDetached`（`Isolate.run`）→ `:319 d._copyNoLazy()` **结构化克隆整本 chapters 跨 isolate**（一次性成本，首载口径内）。

### 2.4 更高效方案（按性价比排序）

1. **翻章「命中优先＋邻近章预排」**｜做法＝`_startBgPaginate`（`reader_page_pag.dart:82`）改为从当前章向**前后各 N 章**优先补齐、再环形扫尾；`_ensureCur` 先试分片读。｜收益＝消掉 forward-flip 撞未排章的**同步卡帧**（worst-ch 399ms 风险）｜风险低｜改动面＝`reader_page_pag.dart` 单文件｜**不需过门**。
2. **段级测量缓存**｜做法＝`pieceHeight` 前挂 `(段文本+runs+layout 关键位)→height` LRU，去 `layoutChapter` 双测与 `paraHeight` 重算。｜收益＝TextPainter 次数显著下降（E1 主成本）｜⚠风险＝key **必须**含 `orig/s2t/indMode/宽/字号`，漏项破同源红线（出空页）｜改动面＝`reader_pager.dart`。
3. **`DocStore.save` 移入 isolate**（E4）｜收益＝预载期主线程让出｜风险低｜改动面＝`epub_cache.dart`。
4. **`EpubDocCache` 改真 LRU ＋ `_LazyChapterList._cache` 加界**（E2/E3）｜收益＝内存真回收｜改动小。
5. **消费段级 `text-align`/`margin-*`**（批三挂账②，仍成立）｜属功能补齐，须同步改 `paraMeasureW/paraOuter`，否则破同源红线｜**排最后**。

> **不可行项**：TextPainter 只能在 UI isolate 跑 ⇒「整书 isolate 建表」不可行；isolate 化只对 `DocStore.save` 有意义。

## 3. UI / UX

### 3.1 外观面板与二级页（`reader_appearance_sheet.dart` / `reader_appearance_subs.dart`）

- **[P1] 二级页系统返回键不闭环**：全文件无 `PopScope`，子页（font/ind/turn/theme/bg/s2t）按 Android 返回键**直接关掉整个面板**，返回只给一个 `⌄` 钮。← `reader_appearance_subs.dart:28 List<Widget> _apSub(ColorScheme cs)`（无 PopScope 拦截）
- **[P1] 主↔子切换无转场**：`_sub` 变化即整块替换，生硬；且子页复用宿主滚动条 `:67 controller: widget.scrollCtl` → **切页保留上个列表滚动位**。
- **[P1] 裸 `GestureDetector` 无按压反馈**：`:651 key: ValueKey(keyTag)`（_segPill）、`:605 key: ValueKey('brApSubBtn-$k')`（_entryCard）等 **8 处**；`Pressable/InkWell` **0 处**。

### 3.2 不支持项提示行（口径核心，部分达标）

## 5. 查漏补缺清单（汇总）

**实现侧**
- `EpubDocCache` 名 LRU 实 FIFO（E2）；`_LazyChapterList._cache` 无上界（E3）。
- 翻章 `_ensure` **同步**跑 TextPainter 于主线程（E1）→ worst-chapter 卡帧风险。
- 段级 `align`/`margin-*` 未消费（批三挂账②）。
- 指纹 `font` 进的是**枚举串**，字族映射变更只靠**人工升 `tableVersion`**（`epub_cache.dart:42`）→ 易漏。
- 无「单章最坏耗时」上报，只有全书续算 totals（`reader_page_pag.dart:129`）。
- 阅读器失败态无重试/无原因/无出口（§3.3）。
- 不支持项提示行未与 `orig` 联动（§3.2）。

**原型侧**
- 无目录书时目录抽屉**全空白无空态**：`brTocRender` 直接 `innerHTML=''`（快照 `6398`）→ 应给「本书无目录 · 可手动补录」。
