## 3 · 边缘右滑内收带（真机反馈轮2）

改法＝`EdgeSwipeToOpen.edgeZone` 判定带默认 28→**110** 逻辑像素：起点**稍内移**（约 30~110px，系统手势区之外）右滑即可开树；贴边段保留不判死（关了系统手势的机器照旧）。累计右移 ≥56、横向主导、抬手不重复触发等判定全不动；卡片左滑回收站不受影响（Listener 不进竞技场，方向判据天然排除左滑）。
兜底预案（若某机型 30~110 仍被吃）＝Kotlin `systemGestureExclusionRects` 原生通道——涉 `android/**` 则同批必跑 kotlin_check 并复验随 6100 后的下一枚包；本批不先赌原生（HyperOS 对该 API 的遵从度无实测证据）。
