## 1. 模块目标

**一句话核心目标**：为个人生活管理 App 提供**以「书」为唯一事实源**的阅读闭环——用户管理书库（四分区/标签/书单/资料），记录**原文摘录与想法**，用**阅读计时与多方式进度**沉淀时长与轨迹，看**真实阅读统计**，并能**打开本地 EPUB 直接阅读、划词成摘录**（与摘录库同库同源），必要时用 **X-Ray 全书索引**回看人物/地点/术语。

**业务价值**：

1. **数据闭环**：修掉「阅读时长不落库 / 书架生态删除不生效 / 表单字段永远填不了 / 统计与记录伪随机造数」四条根因，让「记的准、删的掉、改的动、看得真」。
2. **交付可信**：修掉「深链/刷新 5 屏全白」与「返回/底栏跨文件跳」两条交付链断点，让原型验收与截图链路可用；修掉伪数据与假成功提示，让后续验收判断不被污染。
3. **口径单一**：把三源（需求/原型/实现）长期打架的 18 条（C1~C18）一次性定音，消除返工与测试歧义。
4. **体验对齐**：主题矩阵（令牌/衬线/等宽/深色）、状态层（空/错/加载/禁用第三态）、手感（按压反馈/动画/触控目标）三项系统对齐，补齐与全站既有标准的落差。
5. **回归网归位**：把模块三个专版闸从「红的 / 假绿的 / 没人跑」修成「绿且进收口链」，让本模块重新有活回归。

### 2.1 数据与诚实性闭环（必选-批1）

| # | 功能 | 验收标准 |
|---|---|---|

## 6. 开发约束

### 6.1 Flutter 实现限制（架构红线）

- **目录**：`lib/features/read/**`（原地整改）；**不新建跨模块直连**——与 journal/media/calendar 的联动只经 `shared/linkage` 出口（守护 R1）。
- **架构不换内核**：保持四层（自研抽取 + CSS 子集解释器 → Flutter `TextPainter` 测量 → 自研 `PagStore` 分页 → widget 绘制）。划词/书摘/CFI/简繁/X-Ray 全锚在自研 `PagPiece` 原文坐标，**禁**引 WebView/Readium 替代。
- **同源红线**：`paraSpan` / `paraRunStyles` / `pieceHeight` / `layoutChapter` 为**唯一出口**，测量与上屏必须同源；任何段级测量缓存 key **必须**含全部布局维度（漏项＝出空页）。
- **列表**：定长列表用 `List.generate`；**禁三段式集合推导**（漏 `++`＝静默 OOM，守护 R4）；长列表用 `ListView.builder`/`SliverList`。
- **禁止对仓库跑 `dart format`**（非格式化干净态）。
- **UI 变更先改原型再过门**（本档已附原型改动；实现侧照原型落地）。

### 6.2 数据库与资产约束

- 表：`books` / `book_sessions` / `book_quotes` / `book_toc_nodes` / `book_dict` / `book_lists`（＋成员）；X-Ray：`xray_*`。**本整改批原则上无新增迁移**（F1~F4 为行为修与主题改）。
- 若确需新列（如 `books.wb_at` 类）：**`DbSchema.version` 常量与 `migrations` 最高键同批同步**（6109 教训）；守护 **S6**（`version == max(migrations)+1`）＋**S7**（真升级路径）必跑 `test/journal_test.dart`。
- 资产：`assets/read_import/*.json`（渠道数据包，格式变更不改 Dart）；`assets/xray/dicts/*.txt`（词表；扩表走纯数据）。
- **禁写路径**：`lib/core/backup/**`（备份线在飞）、`lib/features/journal/**`、`lib/features/media/**`、`prototype/index.html` 内他模块段。

### 6.3 性能要求（秒开 / 缓存 / 功耗）

> **硬口径（产品 2026-10-04 立）**：不得劣化性能。一切耗时行为允许放在「第一次加载」（导入/预载）阶段完成，第一次加载耗时不限；**加载完成后，打开书必须秒开**。

| 项 | 规格 |
|---|---|
| 开书首帧 | 目标 ≈190ms（重导后 0ms）；**首帧文字先上**，续算不挡字 |
| 取表 | 按章分片（v6 已落地）；`hit` 只读 index；取表成本**不随书体积增长** |
| 分页 | 按章懒排；翻章「命中优先 + 邻近章预排」（F5-1）；**段级测量缓存**（F5-2） |
| 长列表 | 书架四视图 / 笔记库 / X-Ray / 记录**懒构建**；封面 `ResizeImage`/`cacheWidth` 解码，**禁**每帧 `existsSync` |
| 序列化 | `DocStore.save` 入 isolate（F5-4）；主线程不跑 `jsonEncode(全书)` |
| 缓存 | `EpubDocCache` 真 LRU；`_LazyChapterList._cache` 加界；`maxLive` 策略明确 |
| X-Ray 内存 | 摘 `_df`/`_chGrams`（F7-1）；整本驻留按 §8.1（须签字）；目标：引擎峰值回归 ≤80MB 档 |
| X-Ray 耗时 | 单章跟随 ≤1.5s（§8.1 口径）；30 万字整本目标 ≤8s |
| UI 帧 | 拖动扩选/进度 seek 不掉帧（放大镜降频 + seek 节流）；切换分段/维度不整树重建 |
| 秒开门 | 全项目口径冷启动 ≤2s；本模块本地读，首帧无阻塞 |

**功耗**：
- 计时读数秒级 ticker **仅前台且存在进行中会话时**运行；离屏即停。
- 无计时块时停脉冲动画；无动画不常驻重绘；`Timer.periodic` 一律接生命周期离屏停。
- 阅读器无内容变化时不每帧重算（测量缓存 + 不整树重建）。
