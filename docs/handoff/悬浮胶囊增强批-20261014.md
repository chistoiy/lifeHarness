# 悬浮胶囊增强批（立项 2026-10-14 · 规划待开工）

> 需求源＝产品口述（2026-10-14，顶部胶囊三轮真机回知后的正式立项）：**app 外系统悬浮窗 ＋ app 内胶囊交互增强**。
> 前置背景＝顶部胶囊热修三连（显隐失效链/落点/纯悬浮零让位，承载 6124~6126，见 `docs/交接文档.md` 2026-10-14 段）。
> **状态＝规划**：开工前置＝**原型先行过门**（§3），本档先冻结需求边界与分期。

## 1. 需求明细（产品原话结构化）

### 1.1 app 外（系统级悬浮窗 · 原生批）

- 在桌面/其他 App 之上显示计时胶囊（`SYSTEM_ALERT_WINDOW` 权限 + 前台 Service 载体 + 悬浮 view）。
- 权限引导页：设置页开「悬浮计时条」时跳系统「显示在其他应用上层」授权页（Android 11+ 无弹窗式授权）。
- 悬浮窗内容与 app 内胶囊同构（书名 · 阅读中/影音中 · 时长 · ■ 结束），进阅读器时自动隐藏（与 `readerOpenProvider` 挂起口径一致）。

### 1.2 app 内（TimerBarOverlay 交互增强 · 纯 Flutter 批）

| # | 能力 | 验收口径（冻结） |
|---|---|---|
| C1 | **可拖动** | 按住胶囊任意拖放；松手位置记忆（per 形态存 kv：`read.pillPos`），跨页保持 |
| C2 | **折叠小化** | 可折叠成小圆点（只留呼吸点/进度环），折叠态仍可见会话在跑 |
| C3 | **点击放开** | 折叠态点击展开回胶囊；展开/折叠有轻动效（〇B 档） |
| C4 | **贴边折叠** | 拖到屏幕左/右边缘自动吸附成半折叠（半露胶囊），反向拖出还原 |
| C5 | **显示到秒** | 计时时长显示到秒（`mm:ss` 或 `h:mm:ss`，等宽数字），秒级跳动；结束结算口径不变（仍按分钟计） |
| C6 | **点击添加笔记** | 胶囊上有「＋笔记」入口，点击就地对在跑书的会话补一条笔记/感想（歧义：进书摘库新建 vs 就地小输入框——**开工前原型定稿时拍板**） |

- 影音计时条（media.timerUI=capsule）同构继承 C1~C5（C6 仅阅读侧）。
- 现有口径保持：进阅读器（`/read/reader/:id`）自动隐藏；「■ 结束」钮语义不变；C6 笔记与「■ 结束」并列不互斥。

## 2. 分期与施工面预估

- **批A（app 内）**：`lib/shared/linkage/timer_bar_overlay.dart`＋`lib/features/read|media/presentation/*providers*`＋kv（折叠态/位置）＋test。纯 Flutter，无原生。原型过门后即可开工。
- **批B（app 外）**：`android/**`（悬浮 Service/权限/通知渠道）＋MethodChannel＋引导页＋`lib/core/platform/**`。原生批＝必跑 `tools/kotlin_check.sh`＋装机复验（模拟器给不了悬浮窗真实观感）。
- 批A/批B 可独立交付：批A 先行，批B 随后。

## 3. 前置门

1. **原型先行**：书架/阅读专版补胶囊拖动/折叠/贴边三态与秒显样张（含 app 外悬浮窗示意），产品过门后动实现。
2. C6 笔记歧义（新建书摘 vs 就地输入）原型定稿时拍板。
3. 批B 前置＝权限引导话术与隐私口径过门（为何要「其他应用上层」权限）。

## 4. 验收清单（真机门 · 待开工时展开）

- 拖动流畅不卡帧；折叠/展开/贴边三态切换无跳变；秒显与分钟结算一致性；app 外悬浮在微信/桌面上层可见且点击不穿透错位；权限拒绝后降级为仅 app 内；进阅读器自动隐藏、退出恢复。
