## 1. 需求明细（产品原话结构化）

### 1.1 app 外（系统级悬浮窗 · 原生批）

- 在桌面/其他 App 之上显示计时胶囊（`SYSTEM_ALERT_WINDOW` 权限 + 前台 Service 载体 + 悬浮 view）。
- 权限引导页：设置页开「悬浮计时条」时跳系统「显示在其他应用上层」授权页（Android 11+ 无弹窗式授权）。
- 悬浮窗内容与 app 内胶囊同构（书名 · 阅读中/影音中 · 时长 · ■ 结束），进阅读器时自动隐藏（与 `readerOpenProvider` 挂起口径一致）。

### 1.2 app 内（TimerBarOverlay 交互增强 · 纯 Flutter 批）

| # | 能力 | 验收口径（冻结） |
|---|---|---|
| C1 | **可拖动** | 按住胶囊任意拖放；松手位置记忆（per 形态存 kv：`read.pillPos`），跨页保持 |
| C2 | **折叠小化** | 可折叠成小圆点（只留呼吸点/进度环），折叠态仍可见会话在跑 |
| C3 | **点击放开** | 折叠态点击展开回胶囊；展开/折叠有轻动效（〇B 档） |
| C4 | **贴边折叠** | 拖到屏幕左/右边缘自动吸附成半折叠（半露胶囊），反向拖出还原 |
| C5 | **显示到秒** | 计时时长显示到秒（`mm:ss` 或 `h:mm:ss`，等宽数字），秒级跳动；结束结算口径不变（仍按分钟计） |
| C6 | **点击添加笔记** | 胶囊上有「＋笔记」入口，点击就地对在跑书的会话补一条笔记/感想（歧义：进书摘库新建 vs 就地小输入框——**开工前原型定稿时拍板**） |

- 影音计时条（media.timerUI=capsule）同构继承 C1~C5（C6 仅阅读侧）。
- 现有口径保持：进阅读器（`/read/reader/:id`）自动隐藏；「■ 结束」钮语义不变；C6 笔记与「■ 结束」并列不互斥。

## 9. 热修记录（6128 装机 P0 → 6129 · 2026-10-14）

- **现象**（产品 6128 装机实测）：授权「显示在其他应用上层」后开「系统悬浮窗」开关即闪退；此后每次开 app 都闪退（kv 残留 true → 开机同步器即触发同一路径）。
- **根因**（真机 crash 缓冲区实锤）：Manifest 只声明了 `FOREGROUND_SERVICE_SPECIAL_USE`（API 34+ 子类型），**漏了基础权限 `FOREGROUND_SERVICE`**（API 28+，两者不互含）→ `Service.startForeground` 抛 SecurityException，服务在主进程＝整 app 崩。
- **修复三处**：① Manifest 补 `FOREGROUND_SERVICE` 基础权限；② `TimerPillService.onStartCommand` 重构＝`startForeground` 先行且包 try/catch（防"起了 FGS 没进前台"的 RemoteServiceException 同族崩溃·权限被撤时自停不崩）；③ MainActivity `sync` 通道 `startForegroundService` 包 try/catch 降级不崩。
- **守护**：`sys_pill_test` 新增 Manifest 四断言（FGS 基础/specialUse/foregroundServiceType/Service 声明）。
- **闸**：analyze 零读数＋kotlin_check KT-OK＋sys_pill 波 19 例全绿。

### §9.1 热修二（6129 装机回知：悬浮窗不出·服务被停后恢复链断裂 → 6130）

- **现象**（产品 6129 实测）：通知栏有计时信息但**桌面/其他 app 上层没有悬浮胶囊**（产品截图两处＝锁屏＋app 内——锁屏是系统限制 overlay 不上锁屏、app 内是设计隐藏，两处本就不该显示；真不出的是桌面态）。

### §9.2 热修三（6130 装机回知：阅读页在栈上＝回桌面不显示 → 6131）

- **现象**（产品 6130 实测＋WiFi adb 对照实验）：从「阅读计时」页（或阅读器）按 HOME/切别的 app → **系统悬浮窗不显示**；从「我的/今天」页退后台则正常显示。探针实证：阅读页退后台后 overlay 窗口 0 个、`lastActivity` 停在退后台时刻（Dart 一次 sync 都没发）；按一次返回退出阅读页再 HOME → overlay 立刻出现、`lastActivity=-4s`。
- **根因**：`sysPillTarget` 把 `readerOpen` 当**独立于 app 前后台**的条件（`if (appActive || readerOpen) return none`）——「进阅读器隐藏」的本意是 app 内不重复显示（app 内已有胶囊），但退出 app 后阅读页仍在导航栈上 → 目标恒 none → **app 外永不显示**，恰与悬浮窗的用武之地（app 外看计时）相反。
- **修复**：`sysPillTarget` 去掉 `readerOpen` 参数（app 前台一条已覆盖「阅读器豁免」语义）；同步器调用点与 import 同步清理；测试改写该用例为「阅读页在栈上但 app 退后台 → 仍 read」。
- **闸**：analyze 3 文件零读数＋5 波 38 例全绿。
- **出包**：6131（arm64·base 4131）adb 直装复验（含阅读页退后台场景）。

### §9.3 热修四（6131 装机回知：退后台整进程被挂起＝秒显停/窗口不现 → 6132）

- **现象**（6131 实测＋WiFi adb 深探）：授权与开关都正常、服务在 FGS 态（`isForeground=true`·Doze 白名单在·standby bucket=EXEMPTED），但**退后台后 `lastActivity` 停在退后台瞬间**（Dart 一次 sync 都不再发）、无 overlay 窗；前台时一切正常。
- **定性**：HyperOS 退后台会**挂起整进程**（Dart tick 与同进程 FGS 一起冻）——「靠 Dart 每秒推」的前提在真机不成立；且事件序列与电源策略都不是主因（白名单已给仍冻）。
- **修复（三件·让功能不依赖 Dart 后台存活）**：① **原生自走秒**——载荷带 `startedAt`（会话起点 epoch ms），服务自身 1s Handler 按起点算秒显（Dart 全停也照走）；② **appActive 以引擎真值 `WidgetsBinding.instance.lifecycleState` 为准**（事件标志只是促重算信号），并在 app.dart 把 **hidden 同 paused** 处理＋**生命周期事件当场 `invalidate` 促重算**（不等下一 tick；退后台瞬间推可见态＝前台起服务合法）；③ **僵尸兜底放宽 120s→30min**（短窗口会把「Dart 被系统挂起」误杀）。
- **诊断基建**（保留）：`lh/pill` 增 `log` 方法→logcat `lh_pill` tag（Dart 侧打点：tick/appActive/target/push/stop；原生打点：onStartCommand 载荷、overlay add/remove/失败原因）——release 装机可直读。
- **闸**：analyze 零读数＋kotlin_check KT-OK＋5 波 39 例全绿（sys_pill 20 例含新守护三条）。
- **出包**：6132（arm64·base 4132）adb 直装＋logcat 复验。
- **6132 复验（WiFi adb·logcat `lh_pill` 直读）**：退后台瞬间 `visible=true` → `overlay added`；T+20s/T+65s 窗口均在（越过旧 120s 误杀窗口）；对时截图 `资治通鉴 · 阅读中 1:11 → 1:56`（45 秒准点，显示在别的 app 上层）＝**原生自走秒生效**。§9.1~§9.3 三轮修复后功能闭环。

### §9.4 热修五（6132 装机回知：app 内胶囊裁边＋退 app 后悬窗不现 → 6133）

**产品原话三件**：①「二次点击后显示内容变多，靠右显示时笔记和停止按钮看不到了」；②「就不要显示书名这些信息就足够了」；③「通过返回键会退出 app 此时手机不会显示胶囊；通过主页键回桌面也不会显示」。

- **① 展宽形态：整条去掉**（不是修裁边）。
  - 根因两层：**裁边**＝`timer_bar_overlay.dart` 的 `left` 夹取写死 `mq.width - 60`（余量 60px 远小于胶囊实际宽 ~215px），展宽后靠右必出屏；**冗余**＝书名在 app 内胶囊里本就是次要信息。
  - 修复：删 `readPillLabelOnProvider`/`mediaPillLabelOnProvider` 两个开关与「点时间＝显隐书名」入口（时间改为纯文本），胶囊**恒紧凑**＝呼吸点＋时长＋动作钮。口径与批A 原稿一致（批A 当时默认已是不显，只是留了入口）。
- **② 贴合夹取口径**：新增 `_barW(mq)`＝「实测宽·未测到时用保守估值 240（宁大不小——夹取更紧只会偏左，绝不裁右）」，`build`/`_dragBar`/`_settleBar`/`_unfold` **四处统一走它**（原四处各写各的：60 / size.width / 200 / 写死 236）；首帧 post-frame 量一次实测宽供夹取。
- **③ 退 app 后悬窗不现：显隐决定权从 Dart 移到原生**（本轮真正的根治）。
  - 根因：**BACK 结束 MainActivity 时 `FlutterActivity` 会连 `FlutterEngine` 一并销毁**——Dart 隔离区随之消失，此后一帧都不会再跑。退后台那一次 `lh/pill` push 与 engine teardown 是**竞态**：赶不上就永不出现，且此后 Dart 无从再推。HOME 走 `paused` 有充足时间（所以 6132 复验能过），BACK 不同（所以产品两条路径结果不一致——不是「奇怪」，是两条路径的 engine 寿命不同）。

### §9.5 热修六（6135 装机回知：拖动不跟手＋胶囊交互/UI 与 app 内不一致 → 6136）

**产品原话三件**（对 6135 首装机截图）：①「你看这个 ui，跟 app 内的一样的吗，很奇怪好吧」；②「应该是展开后的摁住拖动要跟手的」；③「胶囊单机是展开，如果用户摁住拖动则也是要跟手移动位置，不是展开。要有跟手度，当前拖动一点都不顺滑」。

- **⓪ 最关键的一处＝「拖动不跟手」的根因是个逻辑死 bug，不是手感/性能问题**：
  ```kotlin
  val p = overlayParams()                       // ← 构造时已写入 posX/posY
  if (p.x == posX && p.y == posY) return        // ← 恒真，每个 ACTION_MOVE 第一行就 return
  ```
  `overlayParams()` 内部已用 `posX/posY` 填了 `x/y`，所以「是否需要更新」的守卫**恒为假**，`moveOverlay()` 从未真正执行过——窗口从头到尾一次都没被移动过，用户看到的是「拖不动」，而不是「不跟手」。
  - 修复：新增 `appliedX/appliedY` 记录**窗口上一次真正应用的位置**，守卫改比对这对字段；`addView` 成功后播种（否则首个 MOVE 会被吃掉）。
  - **通用教训（已入经验坑）**：去重守卫**不能拿「即将使用的目标值」去比**，必须存上一次的实际应用值。
- **跟手第二层「起步粘滞」**：跨过 `ViewConfiguration.scaledTouchSlop` 的**那一帧**没把超出阈值部分计入，手指要滑一段才开始追。现改为同一帧内 `slopBase = downPos - sign(d) * slop`，越过阈值的首帧即贴住手指（对齐 app 内 `GestureDetector` 的连续 delta 累加）。
- **圆圈「一按就展开、不能拖」：不需要改判定逻辑**——是上一条传导：位移传不进去 → `dragging` 恒为假 → `ACTION_UP` 一直走「点击」分支。修好后自动恢复成 app 内语义：**按住拖＝跟手移动＋松手吸附最近边（`_settleFab`）／轻点＝展开（`onTap`）**。
- **UI 三处不一致（产品指出的）**：
  ① **按钮**：app 内阅读胶囊是**双按钮**（`＋笔记`＋间距6＋`■结束`），原生只有一个 `■结束`。补 `＋笔记`（**阅读侧才有**，影音侧按 app 内口径不加），并打通事件链：原生 `ACTION_PILL_NOTE` → `MainActivity.pendingPillNote` → `takePillEvent(type='note')` → Dart `drainPillEvents` → `showQuoteEditPage(bookId: 在跑书)`。
  ② **字重**：`Typeface.MONOSPACE` 常规档偏细偏宽 → 新增 `MONO_BOLD`（MONOSPACE+BOLD），最接近 app 内 `FontWeight.w700`＋`FontFeature.tabularFigures()`。
  ③ **展开定位**：原用 `BAR_W_GUESS_DP=240` 猜胶囊宽，右边缘展开必错位 → 改**实测宽** `measuredBarW`（`addView` 后 `v.post` 量一次，对齐 app 内 §9.4 的 `_barW(mq)`），`settle()` 的贴边折叠判定与 `unfold()` 的落点两处共用。
- **闸**：analyze 零读数＋kotlin_check KT-OK＋pillcheck 相关三波（`sys_pill_test`/`read_pill_fab_test`/`read_timer_bar_test`）全绿＋doclint 全绿＋**6136 装机产品回知「验证全都通过」**。
- **出包**：6136（arm64 分包·base 4136；包内 versionCode=**8136** 属分包 +2000 正常口径，非残钉）。
- **本节＝该线终态**：原生悬浮窗的显隐（§9.4 `AppVisibility`）、计时（§9.3 原生自走秒）、拖动跟手与折叠、UI 双按钮对齐，四个面全部闭环。
