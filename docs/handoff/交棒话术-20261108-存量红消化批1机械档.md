- 现场：`mindmap_schema_test`×4、`nfc_card_dao_test`×2、`journal_test` S7 一条，全部崩在 `SqfliteFfiException … no such table: item_events`。

## 4.5 执行记录与两处偏差（2026-11-08）

**落地结果**：11 个文件全绿（`analyze lib test` 零 error、新件零告警），另顺手修出一条真缺陷。

1. **偏差①（须产品知晓）**：`item_edit_page` 那 1 处「不透明近白底面」现场是
   `Colors.black.withValues(.60)` 遮罩上的**白字**（照片角标），不是白底面。按裁定「改代码换令牌色」
   会把白字落到浅底上读不清，故改按本闸自己的口径**登记进基线并写明理由**（与 `media_card`／
   `diary_fan_fab` 同形态：前景白、底面吃主题）。其余「变小」项按闸提示收紧（`journal_page` 5→3、
   `ledger_import_page` 3→2）＋新增两处登记（`ledger_step_dots` 1、`items_page` 3→4，后者是此前
   被「新面」红挡在闸后的存量）。
2. **偏差②（真缺陷，非存量红）**：`ledger_import_undo_test` 单跑时红、全量时绿，查实是
   `importBatches()` 只按 `created_at DESC` 排、无 `id` 兜底——`created_at` 虽是毫秒，但 Windows
   时钟粒度约 15ms，连做两批导入撞同值后「最近一批」会指到旧批，**撤销钮挂错行、点下去删的是另一批流水**。
   已改 `orderBy: 'created_at DESC, id DESC'`（生产代码 1 行＋注释），该测试由此变确定性。
3. `size_budget` 另有 3 个 ledger 件（repository／add_page／pick_sheets）是同族棘轮欠账，按同日
   「一次销账」裁定刷到实测并写明；`ledger_import_page` 1202 行**未豁免**，按红线拆出
   `widgets/ledger_step_dots.dart`（纯展示件整段搬迁，零行为变化）。
