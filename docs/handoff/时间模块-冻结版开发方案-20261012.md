## 前置 B · 尼尔森十大可用性原则落地对照（设计自检）

| 原则 | 本模块落地 |
|---|---|
| 1 系统状态可见性 | 日视图秒级 `HH:MM:SS` 时钟 + 当前时间红线游标；记账时「已 X 分钟」秒级刷新；四视图/账本读数同源 |
| 2 系统与真实世界匹配 | 用时间语汇「时间块/计时中/补录/自动接龙」；周视图按自然人周；日视图 0–23 小时板 |
| 3 用户控制与自由 | 撤销（`undoAct`）保留；月历展开态可切换并记住；拆分/合并/删除均即时可撤销 |
| 4 一致性与标准 | 复用 `lhConfirm`／`AppToast`／既有 sheet 骨架／线性 SVG 图标／设计令牌 |
| 5 错误预防 | 跨天「结束早于开始」拦截 + 就地红字；`e ≤ s` 拦截；分类删除列连带数；计时中单活防双计 |
| 6 识别而非回忆 | 视图档一屏可达；块视图分类速记列常驻；「现在」游标直观；空/错态文案区分 |
| 7 灵活且高效 | 速记列点＝记到此刻 + 自动接龙；块视图选区直接标记（免弹层）；拆分/合并一步到位 |
| 8 美观且简约 | 去假入口（标签）；去教学性外露文案；日视图信息密度适中 |
| 9 帮助用户识别诊断并恢复 | 错误态 + 重试；跨天/越界就地红字；取数失败不吞 |
| 10 帮助与文档 | 空态一行引导；不写正文教学说明 |

## 1. 模块目标

**一句话核心目标**：为个人生活管理 App 提供**以「时间块」为唯一事实源**的时间记录与统计闭环——用户用四种视图（轴/块/日/周）**记录、补录、计时**一天的时间去向，用账本（L4）**回看分布与排行**，并与待办/分类双向联动。

**业务价值**：
1. **数据闭环**：修掉「跨天补录出错行 / 计时跨零点丢时长 / 分类换组失效 / 拖选卡顿」四条 P0，让记录「记得准、不丢、不卡」。
2. **口径单一**：三源（需求/原型/实现）长期打架的 6 条（圆点/月历/轴列/视图数/▶/周对齐）一次性定音，消除返工与测试歧义。
3. **治理升级**：从「壳内跨模块屏」抽为**独立专版 `index-time.html`**（屏单一归属），并给模块装回**活回归网**（`time52check` 归位）。
4. **体验对齐**：补日视图三件（定时待办紫行 / 当前红线游标 / 秒级时钟）与 a11y / 错误态，补齐与全站手感的落差。

```
   p-calendar ── 顶栏「今」/ 月历点日 / 周条滑 ──▶ 切换 calDay
        │ 顶栏视图钮 ▶ 视图菜单 ──▶ 轴 / 块 / 日 / 周
        │ 顶栏日期钮 ──▶ sheetDatePick ── 确认 ──▶ 换 calDay
        │ 顶栏账本钮 ──▶ p-timeStats
        │ 块视图点格/日视图点空白小时/轴视图点空白 ──▶ sheetTimePick
        │ 块视图点已有块 / 轴·日·周点事件卡 ──▶ sheetTimePick（预填编辑）
        │ 速记列点分类 ──▶ 记到此刻 + 自动接龙（有选区则直接标记）
   p-timeStats ── 分类行 ──▶ sheetTsCat（明细下钻）
   p-calendar 弹层「管理 ›」──▶ p-sub-cats ──「＋添加分类」──▶ p-sub-catAdd
   p-sub-catAdd ──「上级分类」──▶ sheetCatParent
```

### 3.3 返回与状态保持

- 四视图切换**保留** `calDay`（当天）与月历展开态（C2）。
- `p-timeStats`／`p-sub-cats`／`p-sub-catAdd` 为 nav 栈内页（顶部返回可退）。
- 弹层以 sheet 骨架自底部上滑；关闭后主屏不重置滚动位。

## 4. 交互规范

### 4.1 视图与手势

| 场景 | 触发 | 行为 | 边界 |
|---|---|---|---|
| 切视图 | 顶栏视图钮 → 菜单 | 切轴/块/日/周 | 四档，无第五档（C4） |
| 切日 | 月历点日 / 周条点/左右滑过阈 / 「今」 | 换 `calDay` | 收/展态各一（见 4.2） |
| 块视图拖选 | 网格按下并移动 | 选区高亮，只重绘受影响格（F1-4） | 松手：命中已有块 ⇒ 开编辑弹层；否则选区待分类标记 |
| 块视图速记列 | 点分类钮 | 有选区 ⇒ 直接标记该区间；无选区 ⇒ 记到此刻 + 自动接龙结束上一段 | 仅今天可速记 |
| 周视图 | 点空格 | `sheetTimePick` 带 day/hour 预填 | 同格多项并排 + `+N` 徽标 |
| 日视图 | 点空白小时 | 今天＝按当前时间开始计时；他日＝补录 | 点事件卡 ⇒ 编辑弹层 |
| 轴视图 | 点空白 | 补录（见 `gapHtml` 空闲段） | 点事件卡/定时待办行 ⇒ 对应处理 |

### 4.2 月历（C2 落地）

- 展开态：迷你月历（有事项的天右下角显圆点，圆点色按 C1 取最高优先级：计时中/计划中/已完成）。
- 收起态：单周行（左右滑动切天，过阈换天；右上「展开」回展开态）。
- **默认展开**；用户切换后写 prefs（B9），跨会话记住；切视图档**不改**展开态。

### 4.3 「计时中」交互（单活）

- 唯一源＝当日 `tm=1` 时间块（C7）。开始：速记列点分类 / 日视图今天点空白小时（按当前）。
- 结束：点块或弹层「■ 结束计时」⇒ 结束时刻＝当前时刻；跨 0 点自动拆两段（C8/B2）。
- 其余入口开始新计时 ⇒ **自动截断**上一段（`closeTimingAt`）。
- 「已 X 分钟」秒级刷新（前台），离屏停（B4/F5-3）。

### 4.4 统一弹层（`sheetTimePick`）

- 结构：分类网格 → 子分组 → 起止滚轮（时/分）→ 日期（跨天时给结束日轮）→ 底部「删除 / 继续添加 / 添加·保存」。
- 编辑态：额外给「✂ 对半拆分 / ⇧ 与上一个合并 / ⇩ 与下一个合并」（合并间隙阈 `30` 分）。
- 跨天补录：开关打开后出现结束日轮，范围＝起始日 `+0..7`（B1）；`eDate<sDate` 就地红字拦截。
- 「标签 ›」假入口**已摘**（C9）；「管理 ›」→ 分类管理。

### 4.5 动画

| 场景 | 规格 |
|---|---|
| 弹层出入 | 复用既有 sheet 骨架（自底部上滑 120~180ms `EaseOut`） |
| 计时中块 | `animate-pulse`（**无计时块时停**，F6-3） |
| 视图切换 | 即时切换（无过渡）；月历展/收即时 |
| 撤销 | `AppToast` 撤销条（`clearToasts` 测试口径） |

> 微动时长统一 120~180ms（对齐 `docs/UI组件规范.md` 〇B）。

### 4.6 加载状态

| 场景 | 表现 |
|---|---|
| 首次进模块 | 本模块数据本地，**无网络加载态**；DB 读失败 ⇒ 错误态（B5） |
| 账本切档 | 本地重算，无 spinner；大区间（年档）现算读数 |
| 空态 | 该日无记录 ⇒ 留空并给「点空白补录」轻引导 |

### 4.7 异常/边界场景（全部按 前置 A.2 冻结表执行）

跨天/跨月补录（B1）、计时跨 0 点（B2）、起止越界（B3）、无计时中/离屏（B4）、取数失败（B5）、分类删除连带（B6）、拖拽落空（B7）、跨天段记账（B8）、展开态持久化（B9）、旧 events 兼容（B10）。

### 4.8 无障碍（a11y）

- 可点原语补 `Semantics(button, label)`（F5-2）：月历格、周条、速记列、日行、事件卡、弹层按钮。
- 触点 ≥44dp（F5-4）；色彩不单独承载语义（圆点优先级同时给无障碍 label）。

## 5. UI 规范

### 5.1 布局规则

- 主屏：顶栏（日期 + 工具）+ 月历/周条 + 当前视图容器；视图切换仅切容器显隐。
- 块视图：左网格 + 右固定**分类速记列（宽 70）**；粒度条在上。
- 间距：8dp 网格（4/8/12/16/24 档）。

### 5.2 字体（LH-F01 角色链）

- UI 标签/按钮/分类名＝**无衬线**；时间轴时刻/账本读数＝**等宽**（`tabular-nums`）。
- **不随包字体文件**（与全项目口径一致）。

### 5.3 间距与触点

| 元素 | 规格 |
|---|---|
| 触点最小尺寸 | ≥44dp（F5-4 逐项核对） |
| 月历格 / 周格 / 速记列 / 日行 | 现状 <44 的按 F5-4 修正或登记豁免 |
| 弹层内边距 | 复用 sheet 骨架规格 |

### 5.4 颜色

- **一律走设计令牌**（`:root` 7 主题 + `.dark`）；分类色、计时中、完成、计划、圆点、定时待办（紫）全部令牌化。
- **禁硬编码 `Color(0x...)`**（doclint 守护十色值棘轮）；现状 49 处硬编码进基线，**新增一律拦**；同义色去重（圆点三色 `0xFFF43F5E`/`0xFF34D399`/`0xFF6366F1` 收敛为令牌）。

### 5.5 组件复用规则（强制）

| 用途 | 复用对象 | 禁止 |
|---|---|---|
| 删除/不可逆确认 | `lhConfirm`（多行后果） | 自造确认框 |
| 轻反馈/撤销 | `AppToast`（注意 `clearToasts` 测试口径） | 自造 toast |
| 弹层骨架 | 既有 sheet 规范（`sheet*` 命名） | 自造弹层容器 |
| 图标 | 线性 SVG（stroke 1.8） | **emoji 图标**（禁令） |
| 分类色/令牌 | 设计令牌 | 硬编码色值 |

## 6. 开发约束

### 6.1 Flutter 实现限制（架构红线）

- **目录**：`lib/features/calendar/`（既有 17 文件原地整改）；**不新建跨模块直连**。
- **禁 feature 直连**：calendar 与 todo 等互不直连 import，联动经 `shared/linkage` 出口（守护 R1）。
- **列表**：定长列表用 `List.generate`；**禁三段式推导**（漏 `++`＝静默 OOM，守护 arch_test R4）。
- **写权限面**：批 1 仅可动 `lib/features/calendar/`、`core/settings`（**仅加月历展开态键**）、`shared/linkage`（若需）；**不碰**既有 DB 迁移历史段。

### 6.2 数据库约束

- 表：`time_blocks` / `events` / `categories`（`category_dao` / `event_dao` / `time_block_dao`）。
- **本整改批无新增迁移**（C2 走 prefs；F1-1~F1-5 为行为修无 schema 变更）。
- 若后续引入新列（如块级标签）：**`version` 常量与 `migrations` 最高键同批同步**（6109 教训）；守护 **S6**（`version == max(migrations)+1`）＋ **S7**（真升级路径）必跑 `test/journal_test.dart`。
- `events` **只读**（禁新写）；跨天两段行共用同一「会话」关联（如需，用既有字段，不新增列）。
- 顺序/索引：`time_blocks(day, start_min)` 索引；子分类顺序用 `sort`，不靠 rowid。

### 6.3 性能要求（秒开 / 缓存 / 功耗）

| 项 | 规格 |
|---|---|
| 拖选重绘 | 选区态隔离（`ValueNotifier`/独立 `StatefulWidget`），`pointermove` 只重绘受影响格（F1-4） |
