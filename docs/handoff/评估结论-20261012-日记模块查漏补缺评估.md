## 一、审计总评

需求 V1.14/V1.28/M1 的主面**基本落地**：一天多篇、心情 7 档、天气快照（写当天自动抓一次＋手动覆盖＋恢复自动）、模板真结构表（diary_templates+template_sections，内置种子）、列表⇄INS 卡片流双布局、长按批量选中（返回先退多选＋批量删有二次确认）、回顾三件套（心情趋势＋词云＋去年本月）、那年今日、连续记录、今日概览卡（L2）＋AI 反思审阅链（journal.reflect）、仪表盘心情打卡回写（L4）、☐ 待办保存时同步（L3 单向）、Quill 富文本与笔记同口径（Delta JSON 落库）。数据层分节 batch 写入、月历走 entry_date 索引区间查询，均无大恙。

**但有 1 条 P0 崩溃 + 一族丢稿缺陷 + 三条语义断链**。日记侧没有像笔记侧那样吃到「编辑页五条」批与「顺滑批」的治理（两文件结构高度同构，欠账清单几乎逐条对得上）。

## 三、语义断链（三源对账）

- **日记删除不进全局回收站**：V1.60 回收站登记式接口七类（待办/笔记/习惯/书/摘录/清单/物品等）不含日记，日记删除＝硬删＋分节随删（弹层文案自认「不可恢复」，倒是诚实）；删除后图片文件也保留成孤儿（代码注释自认不级联清理）。**最私人的数据反而是唯一不可救的类**——建议进回收站或至少「图片随删＋限时快照」二选一拍板。
- **L3 双向同步只做了单向**：日记 ☐ 行保存时建待办 ✓，但待办完成后不回勾日记行（需求 L3 写明「双向同步」）。
- **L5 摘录→日记素材未落**：INS 卡/列表行的「本页关联」只统计待办数，无摘录引用块（原型关联块含「📚 摘录…」演示行）；阅读摘录转日记素材链路为零。
- **标签只增不减**：保存时把正文 #词 并入 tags 字段，正文删掉 #词 后 tags 残留 ⇒ 筛选浮层出死标签、筛出空结果；且无手动加标签入口（标签唯一来源＝正文 #词）。

## 四、中低危清单（按面分档）

**UI/演示残留**：INS 卡头硬编码演示名「CHIST」与首字母头像（应读 R14-12 昵称统一展示值，`user_settings.dart:212` 已有统一 helper 全仓就这里没跟）；设置·记录管理「日记」组三条里两条是死键——「默认新建模板」trailing 写死「纯文本」、「连续记录提醒」点了只弹敬请期待（假开关，先改灰态或摘除，同 U10 口径）。

**UX**：月历卡点色条＝「新建该日第 N+1 篇」，而卡脚注写「点色条看当天」——既有篇的日子应打开既有篇（新建入口已有 FAB＋入口卡两处）；无心情日色条高度仅约 4px 点不动（热区）；回顾弹层心情趋势柱与词云均不可点（原型逐柱/逐词可点查看当天/含词日记）、月份切换无界（原型限往前 12 个月且禁未来）；INS 分享/评论占位与编辑页多处裸 SnackBar 未走 AppToast 统一口径；日记无搜索（顶栏搜索钮只搜笔记，日记篇数一多没法回找）。

**流畅度**：日记列表非 builder 全量构造（children 一次建全部卡片，含每卡 Image.file——笔记批1 已做懒构建，日记同款欠账）；缩略图无降采样（cacheWidth 未设，多图长列表整图解码）；journalsProvider 全表重拉粒度过粗（点赞/天气/浏览都 invalidate 整列表）；「那年今日」与回顾去年卡的 FutureBuilder future 在 build 里现建——列表每次 setState（含多选勾选）都重查 DB；月历卡每帧 O(31×N) 逐日过滤；回顾词云每帧算两遍。

**持久化**：INS 布局与筛选档为纯内存态，冷启动回「列表/全部」——笔记批5③ 刚把同族筛选持久化（重启不复位），日记没跟上；「记录段 tab」同理（或属有意，随批拍板）。

**测试缺口**：widget 面只测过编辑页新建路径（唯一开页用例不带既有篇）；高危 1~6 与结构化重开/模板切换/自动存/防重入全部无用例；修复批须逐条补，P0 用例＝「建模板写一篇→重开不炸且分节标题正确」。

## 五、原型侧债务（改 UI 前必读）

- 日记面跨两文件：**记录页日记段＋INS 流在书架专版**（`index-bookshelf.html` p-records 段），**编辑页与模板/筛选/回顾/天气四弹层在壳**（`index.html`）——注册表 journal 模块无 screens 明细（file=null、rep=编辑页）。改列表屏去书架专版动刀，改编辑页/弹层在壳动刀，别拿壳里残留的孤儿日记 JS（renderDiaryList/switchRecord 等，DOM 宿主已迁出）当事实源。
