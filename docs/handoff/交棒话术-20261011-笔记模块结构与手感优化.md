## 3 · 批1 设计要点（实现口径）

1. **列表视图懒构建**（`note_tab.dart` 列表分支）：`ListView(children: [for …])` → `ListView.builder(itemCount:, itemBuilder:)`，逐条 `_card(...)`。
   零视觉：padding、条目间距（`_gap`）一字不改。
2. **瀑布流高度缓存**（`note_tab.dart::_estHeight`）：按 `(id, title, preview, colW)` 记忆化，命中不重算 `TextPainter`。
   加 `@visibleForTesting` 计数器 `kNoteEstComputeCount`（缓存命中不计数）供用例钉「按篇缓存生效」；超 600 条清一次防无界。
3. **编辑页专注段懒构建**（`note_edit_layout.dart::_bodyArea` focus 分支）：
   `ListView(children: [标题, 分隔, …段, 附件卡])` → `ListView.builder`，映射 index 0=标题 · 1=分隔 · `2..2+n-1`=段 · 末位=纯文本附件卡。
   段的 `TextEditingController`/`FocusNode` 仍由 `_paras`/`_paraNodes` 持有，懒构建不丢输入态与焦点。
4. **树底「展开/折叠」真双向**（`note_tree_drawer.dart::nt-bt-expand`）：`onPressed` 里先求全集 `all`；
   **已全展开 → 清空 `_open`（收起）**，否则全展开；顺带收起行内动作态 `_actId`。
   口径依据：原型 `ntExpandAll` 是 `ntAllOpen` 翻转的 toggle、`docs/UI组件规范.md` LH-S38 钮名「展开折叠」；
   实现此前只有展开路径（全文件无清除 `_open` 的路径）＝单向缺陷，不属 UI 变更新设计，故无需新原型门。
