## 1 · 背景与已修/未修边界

- **已修（提交 `eb7c4c1`，6061 真机已验）**：`lhbak` 不在 file_picker 的 Android MIME 表 → `FileType.custom` 直抛 `PlatformException` 且 UI 无 catch＝点「选择 .lhbak 文件」从未弹起过。现 custom 被拒降级 `FileType.any`（降级留痕日志）＋UI 可见失败条。雷电 6061 实测：选择器正常弹起。
