## 1 · 背景与已修/未修边界

- **已修（提交 `eb7c4c1`，6061 真机已验）**：`lhbak` 不在 file_picker 的 Android MIME 表 → `FileType.custom` 直抛 `PlatformException` 且 UI 无 catch＝点「选择 .lhbak 文件」从未弹起过。现 custom 被拒降级 `FileType.any`（降级留痕日志）＋UI 可见失败条。雷电 6061 实测：选择器正常弹起。
- **未修（本批主项）**：云同步「仅云端」下载的 `.lhbak` 落**应用内部目录** `files/exports/`，SAF 选择器只能浏览公共存储——**下载下来的包选不到**，换机恢复链路仍断最后一环。旧代码注释承诺的「本机导出记录 tab」原型从未画过、实现从未有过（本次核销该承诺，由本批 B-1 兑现）。

## 2 · 需求条目草案

- **B-1 备份管理屏（导入主通道）**：数据与同步页新增「备份文件」行→统一屏（家＝同步线，`/settings/backupFiles` 级路由）。列表＝`exports/` 目录全部 `.lhbak`（含本地导出、云端下载、`auto_before_restore_` 自动备份），行＝文件名·大小·日期·**来源角标**；动作＝**恢复**（进既有 校验→口令→二次确认→整库替换 链，同 S5 导入段复用）·**删除**（不可逆→逐条二次确认弹层，明确列出连带后果；长按批量）；S5 导入段保留「从其他位置选择」（SAF）为次通道。空态走 EmptyDashRow 定式。
- **B-2 差异对比图片预览**：S3 差异半屏四态列表中，**本地侧存在文件**且扩展名 ∈ {jpg,jpeg,png,webp,gif} 的行，点文件名→全屏图片预览（黑底·缩放·页滑，复用 `showImageLightbox` 同款交互，数据源改磁盘路径）；「仅云端」行不可点（本机无文件，不做假热区）。
- **B-3 图片清理预览**：「图片存储清理」页行缩略图/行名可点→同款全屏预览；勾选清理交互不变。

## 3 · 已定口径与红线

- 预览两处**同一查看件**（新共享件，禁各造一套）；UI 禁 emoji，线性 SVG；不写教学文案。
- 删除备份文件＝物理删，不进回收站（回收站是数据记录面，文件面不混）；**必须**二次确认＋后果人话（对齐「不可逆必确认」口径）。
- 手动删除不影响 `snapshot_service` 保留 N 份自动裁剪策略与同步台账（台账里被删文件路径下次 compare 自然归「仅云端」，勿改 compare 语义）。
- B-1 列表读取只扫应用 `exports/` 目录（浅层），不触 SAF；E 批 `deleted_at` 审计与本批无关（文件面无软删）。
- 与 ⑦ 回收站互斥面：不碰六表语义。
- **存储位置口径（2026-10-04 产品认可钉死）**：数据库位置**不做自定义**——SQLite 需真实路径而 SAF 只给 content URI；`MANAGE_EXTERNAL_STORAGE` 是 AGENTS 红线；内部存储＝呵护敏感数据隐私边界。「换机恢复选不到文件」的解是本批 B-1 应用内列表，**不是**把落点搬公共目录。**首启强制选目录不做**（违「打开就记」定位）。既有「另存到…」保留为把包带去文件管理器的通道。

## 7 · 轮6真机反馈落地记录（2026-10-04 晚，提交 `35aab6e`，已修待复验）

产品报「另存到…导出的 .lhbak 为 0 字节／点钮后 app 卡住很久才弹选择器／包里没图片」。真机 logcat 实锤为**一条链**：

1. `LhBak.create` 的 zip 压缩＋附件收集全同步跑在 **UI isolate** → 界面卡死十几秒（＝「卡住」）；
2. 阻塞期间系统判 **bg ANR** 杀进程（`20:06:53 Killing 1581 (adj 700): bg anr`）；
3. 用户选好位置后，系统**冷启动新进程**投递 SAF 结果 → `flutter_file_dialog` Kotlin `sourceFile!!` NPE 崩溃（`20:07:10 FATAL … request=19112 … NullPointerException`）→ SAF 已建好的空文档停在 **0 字节**。
4. 「没图片」＝0 字节的连带观感：`.lhbak` 本就是 zip 容器，图片在包内 `attachments/note_images/`、`book_covers/` 等路径；应用目录那份（`<docs>/backup/`，弹框前已写完）是完整的，数据未丢。

修复（全部随 `35aab6e`）：①打包阶段整体交 `LhBak.packRunner`（生产 main 注入 `Isolate.run`，测试默认内联）；②**摘除 flutter_file_dialog**，自研 `lh/saf` 通道（`lib/core/platform/saf.dart`＋`MainActivity.kt`）：无挂起态静默忽略过期结果（不再崩）、拷贝走通用 OutputStream（不再强转 FileOutputStream）；备份/X-Ray 词库/索引包三处另存一并迁移；③`xrwords`/`xraybak` 选择器同补「自造扩展名被拒→降级全文件」（与 `eb7c4c1` 同缺陷族）；④导出/另存异常一律可见 toast＋日志，导出钮加「正在导出…」态；⑤连带修上批 R6 架构红灯（落架 `context.go` 清栈改 `pushReplacement`）。常驻用例 6 条（真 isolate 打包×2、通道契约×2、弹层错误可见×2）＋两刀变异自证。
