## 2. 已落地

### F7-1 死结构摘除＋微优化

- **摘 `_df`／`_chGrams`**：`_df`（文档频次）只写不读，而 `_chGrams` 唯一用途就是喂 `_df`——两枚一起摘掉。省的是每章一个「全章 n-gram 的 Set」分配（大书几万段规模下这是实打实的内存与 GC 压力）。
- **`split` 正则提 `static final`**（`_nonHan`）：旧写法每个段落都新建一次 `RegExp`，一本书＝几万次编译。
- **采样闸门下到段内**：旧写法只在段前判一次 `_sampled < 上限`，一旦放行就整段照加，`_sampled` 会一路冲过上限（大书多算数倍 n-gram，纯白烧 CPU）。现在按剩余额度截断段落，到线即停。
- **`busyProbe` 扩到后台续算分页**：新增 `bgPaginatingProvider`（书 id 集合），阅读器 `_startBgPaginate` 开跑置位、`whenComplete` 清位（页卸载即不再碰 provider）；X-Ray 调度器 `busyProbe` 由「只看服务层预热」改为「预热**或**阅读器续算分页在跑就让路」。两条循环互抢 CPU 的老症状（翻页与解析一起变粘）由此消除。

### F7-6 面板懒构建＋重算记忆

- **列表改 `ListView.builder`**：旧实现先把全部行 `new` 成 `List<Widget>` 再交给非 builder 的 `ListView`——2000 词条＝当场全建 2000 个 widget。现在 `specs` 只存「这一行是什么」（词条行本体或四枚分节标记），可见才建。
- **`_scoped` 记忆化**（`_scopedOf`）：类型 tab 行与列表原来各跑一遍全表过滤，现在共用一次；签名＝实体/锚点身份＋范围＋当前章＋页段集合。
- **hi/lo 与排序记忆化**：签名再叠类型/两个搜索词/排序键，滚动、勾选、展开低置信都不再触发全表重扫重排。
- 前置拆分：面板已 1181 行（1200 面），把列表渲染群（`_list`/`_kwBanner`/`_row`）整组搬进新 part `reader_xray_panel_list.dart`（extension 口径同 `reader_xray_panel_learn.dart`），主文件回 937 行。
