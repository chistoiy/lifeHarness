## §2 · 硬口径（新会话最容易踩的四条）

**① `doclint` 的 `PASS strict 全绿` ≠ 守护全绿。**
它和 `T13 档③ 红灯` **可以同时出现**。判读须看**最后有没有 `PASS 零死链 + 守护全绿` 那一行**。
本批第一件事就是栽在这上面——只看 `PASS strict` 就把 3 枚 emoji 违令放过去了。

**② `size_budget` 的「登记后只许减」意味着——登记值本身越线是允许的。**
所以**闸不红不等于债还了**。查存量债的姿势＝打开 `test/size_budget_test.dart` 的 `budget` 表，
看有没有值 **> 1200**。本批还的那条（`diary_edit_page: 1262`）就挂了四个月没人动。
拆完的正确收尾是**删掉登记项**（让闸回「超线即红」），**不是把值调小**。

**③ 拆 State 用库内既有样板，别自创。**
`part 'x.dart';` 放主文件导入区之后 → 新文件首行 `part of '主文件.dart';` → 内容写成
`extension _Xxx on _XxxState { ... }`。样板看 `note_edit_rich.dart` / `diary_edit_rich.dart`。
**必踩**：`setState` 是 `State` 的 protected 成员，extension 里直接调报 `invalid_use_of_protected_member`，
上一行加 `// ignore: invalid_use_of_protected_member` 即可，**别为此把方法搬回主文件**。
另：机械搬迁会让 `feature_size_budget` **净增**（本批 +14 全是搬迁壳），这是必然代价，登值并写清理由即可。

**④ 出包只编 arm64，但 `unzip -l` 里会看到三个 ABI 目录——这是正常的。**
判「真只编 arm64」看 **`libapp.so` 是否只在 `arm64-v8a`**；`armeabi-v7a`／`x86_64` 里只有插件预编译的
5 个 `.so`（`libbarhopper_v3`／`libdartjni`／`libdatastore_shared_counter`／
`libimage_processing_util_jni`／`libsurface_util_jni`）。别看到多 ABI 目录就重打。
出包前 `node tools/prebuild_check.js --code <编号+2000>` **会拦 `local.properties` 钉版不一致**——
那个文件在 gitignore 里，每次换包号都得手改，构建吃钉版值而非 `--build-number`。
