## §2 硬口径（实现批必须照此，别自己定）

1. **同日多篇，日期块只渲一次**（首篇处），后续同日条目左栏留空轨＋细竖线 —— 不重复画日期。
2. **日期块吸附**＝钉在页面内容顶端（原型 `stickyTop=4`），钉住期间块自绘页底色压住下方内容。
   实现侧对应 `SliverPersistentHeader(pinned: true)`；**禁**再叠手势位移（原型曾用 JS transform＋sticky 两套位移，互相打架已改）。
3. **「没图的格子」定义**（评估件留的开口，本次定死）：
   - 该日**无日记** → 虚线空环格子；
   - 有日记**无图** → 心情色实心块（不画缩略图，不画占位图标）；
   - 有日记**有图** → 心情色实心块＋右上 ▣ 角标（只表示「有图」，不做图片浏览）。
   图墙**只为「哪天写过」服务**，不做图片浏览入口。
4. **地点行**＝有 `loc` 才出行，无则整行不出（不占位、不显示「未知地点」）。
   数据侧现成：`JournalEntry` 已有城市字段；原型本次给样例补了 `loc`。
5. **收藏/点亮**：判据单源 `dwHit(i)`，三档视图共用；切档/筛选切换必须重绘当前视图
   （原 `diaryReact` 只在 INS 档重绘，是死胡同的直接成因之一）。
6. **月历图墙只在轨道档露出**；列表/INS 档收起为零高，**不改旧版式**。
7. **视图档位持久化**沿用 `journalIns` 的 settings 口径，扩成三值（`track/list/ins`），旧值向后兼容。
8. **（批1b）心情柱状条只属于列表档**——轨道/INS 档整卡收起，不做「只藏色条留卡头」的中间态。
9. **（批1b）写日记入口只留 FAB 一处**——顶行整行删；FAB 关掉时用户从「设置弹层／编辑页」进，
   **不要**为了弥补再补第三个入口。
10. **（批1b）FAB 开关只作用于日记页**（`p-diaryHome`），其他页 FAB（记想法/记待办/记一笔…）不受影响。

②「图标全部改线性轮廓」涉及全仓图形资产，不在本批；③ 指导件末尾问「看板要不要改成轻量统计条」——**保留大卡片**，待产品定了再改。

### §4f-3 横排收敛 + 自定义起止 + 主题兼容（2026-10-19 02:3x）

原话：「那三四年以前的怎么办？增加一个起始、结束时间的选择器。标记、标签都横排选择，减少屏幕占用高度」
＋追加令：「注意，豆包给的治理方案，色彩要与项目支持主题切换相兼容」

**① 标记/标签改横排胶囊**（`#dfGroups` 重写）

原来每项 `.df-row` 高 48px 独占一行，6 项 ≈ 288px + 分组标题 88px，弹层几乎顶满一屏。

| 项 | 改前 | 改后 |
|---|---|---|
| 单项形态 | 48px 整行（图标 + 文字 + 右侧对勾） | 32px 胶囊 `.df-chip`（14px 图标 + 文字，`df-on` 走主色描边 + 主色文字 + 6% 淡底） |
| 每组占高 | 48 × 项数 | 32（一排横排，自动 wrap，实测两组各 1 排） |
| 两组总高 | 288px | **108px** |
| 分组标题外边距 | `18px 0 4px`（两组共 88px 纯空白） | `8px 0 6px` + `line-height:1`，首组 `margin-top:0`（共 44px） |

> 取舍：横排后组间已有胶囊描边做视觉分隔，不需要原来那么大的呼吸量；标题字号不变，只压掉行高冗余。

**② 时间段收成单段横排**：原按「全部 ｜ 近期…／按日历 今年·上月」两行 + 竖分隔 `.df-range-sep` + 行首小标签 `.df-range-t`
（100px）。改为一列 8 枚胶囊自然折行（实测 76px，两排），两个装饰元素删除（断言 I3 钉 `sep===0 && rt===0`）。

**③ 自定义起止选择器**（`#dfCustom` · 解决「三四年以前」）

- 形态＝`起始 date` — `结束 date` ＋「应用」按钮，整行等宽（`flex:1`）。
- **一端可留空**＝开区间（「某日之后」／「某日之前」），比预设更通用。
- 只有两端合法（`from <= to`）时应用钮可点（`.df-go-on`），否则置灰 —— 防止非法区间静默筛出空。
- 应用后 `diaryRange='custom'`；`#dfRange` 行尾追加一枚「自定义」胶囊进选中态，且**常驻**（否则用户找不到回入口）。
- `dwInRange` 的 `custom` 分支直接用 `iso=yy+'-'+MM+'-'+DD` 与 `dfFrom/dfTo` 做字符串比较（ISO 串字典序即时间序，免手算天数差）。
- 命名走新函数 `dfRangeName()`：`2023-01-01 至 2024-12-31` 这样回显，底部计数与 toast 都用它（原来直接取 `DIARY_RANGES` 名字，`custom` 不在表里会漏成空）。
- 重置（`diaryFilterReset`）同时清空 `dfFrom/dfTo`，否则下次打开会带着旧区间。
- 实测：`2023-01-01 ~ 2024-12-31` → 只出 2024-03-08、2023-12-31 两条，不混入当年 8 条。

**④ 主题兼容（产品追加令）** —— 这是本节最要紧的口径，实现批必须照抄。

问题的本质：本原型有 **4 套主题（minimal 靛紫 #6366f1／fresh 翠绿 #10b981／retro 琥珀 #b45309／neumorph 蓝 #5b7cfa）× 明暗两档 = 8 种组合**，
`--accent` 每套都不同。而本轮及前几轮新增的选中态淡底一律写死 `rgba(99,102,241,.06)`（靛紫）⇒ **fresh 主题下会出现「绿字绿描边 + 紫淡底」**。

落法：新增一组**主色淡化档 CSS 变量**，由 `--accent` 现算，8 种组合自动跟随，**以后新增主题也不用再改一遍**：

```css
:root{ --accent-06:rgba(99,102,241,.06); --accent-06:color-mix(in srgb,var(--accent) 6%,transparent); /* …06/08/10/12/18/22/28/42/55 */ }
html.dark{ --accent-06:…color-mix(in srgb,var(--accent-l) 12%,transparent); /* 深档整体加厚一档 */ }
```

三条必须遵守的细节（各自都有实测踩坑）：

| # | 口径 | 踩过的坑 |
|---|---|---|
| a | 派生块**必须放在四套主题变量之后** | 放进 `:root` 首块会被折叠：`--accent` 在同一个 `:root` 里还没被主题覆盖，`color-mix` 解析时取到的是基础靛紫 |
| b | 每条属性**先写一条靛紫 fallback，再写 `color-mix`**（同属性两遍） | Chromium<111 不认 `color-mix`，没有 fallback 就是整条失效（不是退化，是选中态完全没有底色） |
| c | **深档选择器权重够不够要看实际选择器链** | `html.dark .df-chip`（0,2,1）会压过 `.df-chip.df-on`（0,2,0）⇒ 深档下选中态描边停在被覆盖的浅灰、整个选中态消失。必须并写成 `html.dark .df-chip.df-on, .df-chip.df-on`（断言 J3 实测抓到，四主题深档描边全是 `rgba(255,255,255,.16)`） |

替换范围（本轮已全部改为变量，实现侧照抄这套变量名）：`.df-pill`／`.df-chip`／`.df-custom-in`／`.dr-quote`（那年今日）
／`.dw-wall-cell.dw-wall-on`（图墙选中光晕）。**`.dark` 简写与 `html.dark` 混用是既有存量**，新增规则一律用 `html.dark`（权重高、更可预期）。

**⑤ 断言**（`tmp/diary_filter_probe3.js`，**14 项全绿**）

| 组 | 覆盖 |
|---|---|
| I1a/I1b | 两组均单排横排；两组总高 ≤110px（实测 108，原 288） |
