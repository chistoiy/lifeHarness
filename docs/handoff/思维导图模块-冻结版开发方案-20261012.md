## 前置 A · 适用范围与需求冲突裁决（开工前必读）

### A.0 适用范围澄清（防止代码模型自造）

本文档模板原含「阅读、文本选中、X-Ray、AI 大纲」等**阅读器交互**字样。经回源，**这些能力属于阅读模块（模块 17），不属于思维导图模块**，代码模型**一律不得在导图中实现**。对照关系如下（左＝阅读器概念，右＝导图中的对应物；若无对应则明确「不适用」）：

| 阅读器概念 | 思维导图模块的对应物 | 处置 |
|---|---|---|
| 正文阅读（翻页/滚动/进度） | 画布浏览（平移/缩放/视口） | **平移缩放**（§1、§4），无翻页概念 |
| 文本选中（划线/取词） | 节点标题的**文本编辑选段** | 仅存在于「编辑节点」弹层内，走系统文本编辑（§4.6） |
| X-Ray（实体/人物索引中心） | **不适用** | 导图无实体索引；**禁止**实现任何 X-Ray 形态 |
| AI 大纲（模型生成结构化大纲） | **连接点④**（md 笔记→导图初稿解析） | 只做**本地规则解析**（标题层级/空行/缩进），**不接 AI**（AI 增强属需求 §六，另批） |
| 书摘/摘录联动 | **连接点②**（日记/摘录插导图卡片） | 见 §2.2-F13 |

> **红线**：代码模型若在本模块实现 X-Ray、AI 生成、翻页、划线等阅读器概念，视为需求越界，判不合格。

### A.1 需求冲突裁决表（三源对账后逐条定音，全部已拍板）

| # | 冲突/歧义 | 各方说法 | **冻结裁决（唯一口径）** |
|---|---|---|---|
| C1 | 删节点是否可撤销 | 原型 toast 写「可撤销」，但批 1 无撤销栈 | **删节点走二次确认（列明连带子级数），文案不出现「可撤销」**；撤销栈排批 2 |
| C2 | 「删图」入口 | 原型提示「去更多里删图」但无入口 | **图列表行内更多提供「删除导图」**，图进回收站第九类 |
| C3 | 节点备注读回 | 只有写侧（加子节点时），读侧为零 | **长按菜单「重命名」升级为「编辑节点」**，标题＋备注均可读回改写 |
| C4 | 节点标题 vs 笔记标题 | 需求暗示跟随，原型独立，用例假设回落 | **实时跟随**：节点挂的是引用，显示层取笔记标题；笔记改名节点跟着变，笔记删除回落「（已删除的笔记）」占位 |
| C5 | 点节点行为 | 需求要「跳笔记」，原型只选中 | **单击＝选中；双击＝进笔记详情** |
| C6 | 一图多根 | 需求写多根，原型单根遍历 | **批 1 支持多根**：补「加根节点」，布局改多根遍历 |
| C7 | 添加同级节点 | 排查件自认缺一枚 | **节点菜单增「添加同级节点」**（在根节点上即＝加新根） |
| C8 | 收集箱第五向 | 需求要双向，原型只有导图侧拉取 | **收集箱页侧也加「转导图」入口**，与导图侧拉取成双向 |
| C9 | 连接点② 卡片实体 | 首批含②，原型只有一行入口＋toast | **②保留首批**，补卡片实体（形态/点击进画布/默认预览＝根节点集合） |
| C10 | 折叠态持久化 | 原型纯内存，重开全展开 | **冻结：持久化**（节点表加 `folded` 列），重开图恢复折叠态 |
| C11 | 视图态（scale/tx/ty） | 原型切走复位 | **冻结：不持久化**（每次进图 fit 到内容），此为有意取舍，非缺陷 |
| C12 | 布局「方向 right」与纵向树语义 | 纵向树不可右延，命名不自洽 | **冻结**：`dir` 维度仅在 `struct=radial` 或宽 viewport 下有横向语义；`tree` 默认形态命名为「纵向树」，「向右/双向」在批 4 随 `radial/both` 一起生效（批 1 只需把 `viewport` 与布局解耦） |
| C13 | 横屏 | 清单列入 MVP | **只做「横向布局预览」**（批 4）：App 内不转屏、画布按横向比例重排；**放弃强制转屏** |
| C14 | 画布底栏 | 模块「不占底栏」，原型画布有自绘两枚导航 | **画布为 push 路由**（`/mindmap/canvas`），顶部自带返回；原型 `#mmNav` 两枚**不实装**为底栏，改由顶部返回承载 |
| C15 | 折叠/边线等配色 | — | 一律走**设计令牌**，禁硬编码色值（doclint 守护十色值棘轮） |

## 前置 B · 尼尔森十大可用性原则落地对照（设计自检）

| 原则 | 本模块落地 |
|---|---|
| 1 系统状态可见性 | 画布显示缩放比例标签＋节点数；编辑即自动保存（顶栏/角标给「已保存」微反馈）；大图加载指示 |
| 2 系统与真实世界匹配 | 用脑图语汇「根节点/子节点/同级节点/折叠」；空态用「新建一张图开始思考」类自然文案 |
| 3 用户控制与自由 | 点空白取消选中；返回不丢稿（自动保存＋PopScope flush）；删除走确认＋回收站可恢复 |
| 4 一致性与标准 | 复用 `lhConfirm`（多行后果）／`AppToast`／既有 sheet 骨架／线性 SVG 图标／设计令牌 |
| 5 错误预防 | 删除二次确认**列明连带子级数**；空标题拦截；md 解析超限提示；回收站兜底 |
| 6 识别而非回忆 | 画布工具条常驻可见；长按菜单一次列全；挂载笔记的节点有**可见角标** |
| 7 灵活且高效 | 双击进笔记（跳过菜单）；拖拽定位；加同级（免「选父再加子」迂回）；多根 |
| 8 美观且简约 | 画布无冗余控件（工具条仅 3 枚）；节点/连线走令牌自动跟随主题；不写教学文案 |
| 9 帮助用户识别诊断并恢复 | 挂载失效显式占位；删除后回收站可原位恢复；解析失败降级为「零节点」并提示 |
| 10 帮助与文档 | 空态一行引导（轻量，仅空态出现）；不写正文教学说明 |

## 1. 模块目标

**一句话核心目标**：为个人生活管理 App 提供一个**以画布为第一形态的结构化思考工具**，让用户把零散的笔记、收集箱碎片、md 大纲**绘制/汇聚成可拖拽、可折叠、可挂接笔记的思维导图**，并与笔记生态四向连通。

**业务价值**：
1. **补全思考闭环**：既有模块能「记录」（日记/笔记/收集箱），缺「结构化组织」——导图把碎片升级为结构。
2. **激活存量数据**：连接点 ①③④ 让既有笔记、收集箱条目、md 文档**反向产出新价值**（沉淀为图），而非孤立新增一个玩具。
3. **差异化护城河**：市面脑图工具（XMind 等）与笔记 App 各自为政；本模块的**四向连通**是竞品不具备的组合能力。
4. **离线优先、零云依赖**：全程本地，导出（批 2）以 HTML 承接「分享」，不做账号体系，契合本 App 定位。

### 2.1 数据与入口（必选-批1）

| # | 功能 | 验收标准 |
|---|---|---|

### 2.2 画布与编辑（必选-批1）

| # | 功能 | 验收标准 |
|---|---|---|
| F1-1 | **建图三起点** | 列表「新建导图」弹层可选起点＝**空白 / 从 md 笔记 / 从收集箱**；空白起点默认建 1 个根节点「中心主题」（可改名）；三种起点都能建出可编辑的图 |
| F1-2 | **自动布局（纵向树）** | 新建/打开即自动布局；默认 `struct=tree`、`dir=right`；**深树（≥5 层）与宽树（≥20 兄弟）无节点重叠、不出可视区（可被 fit 收纳）** |
| F1-3 | **画布平移缩放** | 拖空白平移；双指捏合缩放（下限 25%、上限 400%）；缩放钮 ±；缩放比例标签实时更新；fit 还原到「全图可见」 |
| F1-4 | **多根节点** | 一图可含多根（`parent_id IS NULL`）；「加根节点」生成新根；多根各自成树、互不串行叠加 |
| F1-5 | **加子节点** | 选中节点后加子节点，父＝当前选中；子节点排在兄弟末尾（`sort` 递增） |
| F1-6 | **添加同级节点** | 选中节点后加同级，父＝当前节点的父；**在根节点上加同级＝新增根** |
| F1-7 | **编辑节点（标题＋备注）** | 长按→「编辑节点」弹层，**标题与备注均可读回并改写**；空标题拦截；保存后画布标题与 `TextPainter` 量宽同步刷新 |
| F1-8 | **节点拖拽定位** | 拖动节点仅改该节点偏移 `dx/dy`（**不存绝对坐标**）；松手落库；「归位到自动布局」清偏移归基线；拖拽中只重画该节点与其邻边，松手整树重排 |
| F1-9 | **折叠/展开子节点** | 长按→「折叠子节点」；折叠后子级不参与布局与绘制；**折叠态持久化**（`folded` 列），重开图恢复 |
| F1-10 | **选中与取消** | 单击节点＝选中（高亮）；**点空白取消选中**；无选中时上下文工具条为禁用/收起态 |
| F1-11 | **删除节点（安全）** | 删除走**二次确认**，确认文案含**连带子级数**（「将删除 N 个节点（含 M 个子节点）」）；取消＝零副作用；确认后节点及其全部后代移除 |
| F1-12 | **节点上限保护** | 单图节点（含解析产物）**硬上限 2000**；达上限后新增入口给提示并禁用（见 B9） |

| — | 关系连线/甘特/音频附件/公开链接分享/Word·FreeMind 导入/快捷键·自定义字体/水印 | 明确不做 | 若代码模型实现，判需求越界 |

### 2.6 布局家族冻结口径（批 4 展开，批 1 打地基）

- **4 形态 ＝ 正交两维**：`struct(tree/radial) × dir(right/both)`，默认 `tree/right`。
- **`LayoutEngine` 接口批 1 必抽**（仅一个 `tree/right` 实现也算）——不抽则批 1~4 渲染代码全要重写。
- **`both` 语义**：子节点按数量均分父节点左右两侧，奇数右侧多一个；`side` 节点属性可空（空＝引擎自动分配）。
- **横向布局预览 ＝ `预设 = struct × dir × 容器比例(竖屏友好/横向预览)`**；App 内不转屏（C13）。

## 4. 交互规范

### 4.1 画布手势三分仲裁（核心，冲突面最大）

画布须在**同一片区域**内区分三种手势，且**不得与底栏双指手势（V1.65）互抢**——**壳内页禁用 `InteractiveViewer`**，全部自行仲裁：

| 手势 | 触发 | 行为 | 边界 |
|---|---|---|---|
| 拖节点 | 手指按下命中某节点并移动 | 只改该节点 `dx/dy`，局部重画该节点＋邻边 | 松手落库（防抖 300ms）；移动 <4dp 视为 tap |
| 平移 | 按下命中空白并移动 | 更新 `Transform` 平移量 | 帧内只更 `Transform`，布局延后 |
| 双指缩放 | 两指 | 捏合缩放（25%~400%） | 帧内只更 `Transform`；`scale` 标签实时更新 |
| 单击 | 按下即起（<4dp）落在节点 | 选中（或取消选中另一） | — |
| 双击 | 两次 tap（间隔 <300ms）落在**已挂笔记**节点 | 进笔记详情 | 未挂笔记节点双击＝选中（无跳转） |
| 长按 | 按住 ≥450ms 落在节点 | 弹节点菜单 | — |

> **真机门专条**：画布手势与底栏双指收起**不互抢**（原型层只示意，真机才验得出）。

### 4.2 长按菜单（节点）

一次列全，顺序固定：**加子节点 / 添加同级节点 / 编辑节点 / 挂载笔记 / 折叠子节点 / 删除节点**。

### 4.3 动画

| 场景 | 规格 |
|---|---|
| 弹层出入 | 复用既有 sheet 骨架（自底部上滑，120~180ms，`EaseOut`） |
| 节点新增 | 从父节点位置淡入＋缩放 0.8→1（≤180ms） |
| 折叠/展开 | 子级高度过渡（≤180ms），连线同步收缩 |
| 拖拽 | 拖动中节点跟随手指（无过渡）；松手整树重排 ≤200ms |
| 选中 | 高亮环即时，无延迟 |

> 微动时长统一 **120~180ms**（对齐 `docs/UI组件规范.md` 〇B）。

### 4.4 加载状态

| 场景 | 表现 |
|---|---|
| 大图开图（1000+ 节点） | 加载指示 ≤1.5s 内消失；超时显「图较大，正在渲染」 |
| md 解析 | 预览弹层内出进度态；完成渲染层级树 |
| 收集箱导入 | 列表加载态；确认后生成节点 |
| 空图/空列表 | 空态（引导文案＋新建入口） |

### 4.5 异常/边界场景（全部按 §1 前置 A.2 冻结表执行）

删除安全（B4/B5/B6）、空标题（B8）、节点上限（B2/B9）、无图深链（B1）、挂载失效（B6）、回收站恢复（B7）、解析超限（B2）、拖拽 flush（B4）。

### 4.6 文本编辑（节点标题/备注）

- 编辑节点弹层内标题为**单行输入**、备注为**多行输入**；支持系统文本选段（光标/选中/粘贴），**不做自定义选区**。
- 标题在画布上 `max-width` 截断（ellipsis），**截断仅视觉，数据完整**；全文经「编辑节点」读回。

### 4.7 无障碍（a11y）

- 画布 `CustomPainter` 绘制的节点**必须补 `Semantics`**（label＝节点标题＋挂载态；button＝可双击进笔记），使读屏可见（对齐项目 U9 读屏先例）。
- 工具条按钮均带 `Semantics(label)`；触点 ≥44dp。

### 4.8 触屏适配

- 全部触点 **≥44dp**；缩放钮/工具条按钮同。
- 画布支持多点触控；长按与双击在触摸屏下按 §4.1 阈值判定。

### 4.9 连接点② 导图卡片实体规格（本档冻结，原型须照此补）

| 项 | 规格 |
|---|---|
| 卡片形态 | 日记/摘录正文内嵌一块卡片：左侧线性图标（account_tree）＋ 图名 ＋ 副文案「N 个根节点」＋ 缩略示意（根节点集合的前若干标题） |
| 数据 | 卡片存 `map_id`（引用），**不存导图快照**（图更新则卡片预览随之更新） |
| 点击行为 | 点击卡片 → push `mm-canvas?id=<mapId>` |
| 默认预览 | **导图根节点集合**（每个根节目标题一行，最多 5 行，超出显「…」） |
| 图被删除 | 卡片显示「（导图已删除）」占位，点击置灰无响应 |

### 4.10 HTML 导出规格（批 2，本档冻结）

- **单文件、零外链**：CSS/JS 内联，不引 CDN、不引外部字体。
- **可操作三件**：折叠/展开节点；点节点跳**挂载笔记的标题与摘要**（导出时快照笔记标题）；画布平移缩放。**不含编辑**。
- **与 App 内视觉同源**：同一纵向树布局算法生成初始坐标；深浅色跟随 `prefers-color-scheme`（内联两套令牌）。
- **挂载隐私硬口径**：**默认只导标题、不导正文**；正文需用户在导出弹层**单独勾选（默认关）**。**禁止**提供「默认带正文」的开关。
- **横向预设**：文件自带横向布局预设（落法 C）。

## 6. 开发约束

### 6.1 Flutter 实现限制（架构红线）

- **目录**：`lib/features/mindmap/**`（新建）＋ `lib/shared/linkage/mindmap_mounts.dart`（新建）。
- **禁止 feature 直连**：mindmap 与 journal/read 等**互不直连 import**，全经 `shared/linkage` 出口（守护 R1）。范式＝`search_mounts.dart`（单函数）/`journal_mounts.dart`（事件总线）。
- **画布渲染层**：**`CustomPainter` ＋ 单个 `RepaintBoundary`**，节点/边**不进 Widget 树**。
- **禁用 `InteractiveViewer`**（壳内页禁令，与底栏双指手势冲突面）；手势自行仲裁。
- **不接横屏**：不改 `app.dart`、不动全局 `Orientation`（C13，只做横向布局预览）。
- **零新增原生通道**：HTML 导出复用 `saf.dart`（`safSaveAs`）＋`open_intent.dart`（`writeAsString`）＋`webview_flutter`（已在依赖）。
- **写权限面**：批 1 仅可动 `schema.dart`（**仅迁移段＋新表 DDL**）、`app_router.dart`（**仅加两路由**）、`dashboard_page.dart`（**仅 `_mods` 一行**）、`trash_models.dart`/`trash_specs.dart`（**仅加第九类**）。**不碰** `features/journal/**`、`features/read/**`、`core/settings/**`、`core/database/` 既有迁移段（≤44 一字不改）。

### 6.2 数据库约束

- **双写 DDL**：`mindmaps`/`mindmap_nodes` 的 `onCreate`（全量 DDL）与 `onUpgrade`（迁移语句）**两处都补**。
- **version 与迁移同批**：`version` 常量与 `migrations` 最高键必须同批同步（6109 教训）；守护 **S6**（`version == max(migrations)+1`）＋ **S7**（`v44→v45` 真升级路径）。
- **索引**：`mindmap_nodes(map_id, parent_id)` 复合索引 ＋ `(map_id)` 索引；拉整图不扫全表。
- **顺序**：子节点顺序用 `sort` 整数字段，**不靠 rowid 隐式序**。
- **扁平表不 JOIN**：`(map_id, parent_id, side, sort)` 扁平存储，不做邻接表递归查询。
- **回收站第九类（非白拿）**：`trash_specs.dart` 登记式接口须**接满六条线**（rows/restore/purge/refresh/purgeExpired/signals），**删图须级联删/恢复全部 `mindmap_nodes`**（自写，接口无自动级联；同类先例＝book→quote、journal→分节）；`trash_guard_test` 按 `TrashKind` **逐类点名**。
- **备份**：`mindmaps`/`mindmap_nodes` **默认进备份包、不登记进 `excludeTables`**（防「同步后丢图」）。

### 6.3 性能要求（秒开 / 缓存 / 功耗）

**渲染层七条（批 1 硬要求）**：

| 项 | 规格 |
|---|---|
| 画布渲染 | `CustomPainter` ＋ 单 `RepaintBoundary`，不进 Widget 树 |
| 可视区裁剪 | 维护 `viewport`（平移/缩放/屏幕矩形），**只绘制与视口相交**的节点与边 |
| 文本 | 节点标题走 `TextPainter` 并**缓存量宽**（改文字才重算），不用每帧 `Text` Widget |
| 拖拽降级 | 拖拽中只重画当前节点与其邻边（局部脏区），松手整树重排 |
| 连线 | 折线批量进同一 `Canvas.drawPath`（或 `drawVertices`），不逐边 draw |
| 节流 | 平移/缩放帧内只更新 `Transform`，布局计算延到帧末/节流 |

**数据层三条**：复合索引 / `sort` 整数字段 / 扁平表不 JOIN（见 §6.2）。

**真机门三条（必须在真机真数据上跑，禁小样本推断）**：
- 1000 节点：打开 ≤1.5s，平移/缩放**稳定 ≥50fps**，内存不随平移增长（裁剪生效的读数证据）。
- 5000 节点：打开 ≤5s，交互 ≥30fps（保证「能用」）。
- 画布手势与底栏双指收起**不互抢**。

**秒开**：全项目口径冷启动 ≤2s；开图按上述真机门。  
**缓存逻辑**：`TextPainter` 量宽缓存（键＝节点标题文本）＋ 布局结果缓存（`LayoutEngine` 输出按 `(mapId, struct, dir, viewport size)` 缓存，输入未变不重算）＋ 视口裁剪（天然免重绘视口外）。  
**功耗**：帧内只更 `Transform`；拖拽/手势节流；无动画时**不常驻重绘**（无 `vsync` 空转）；避免每帧文本重排。
