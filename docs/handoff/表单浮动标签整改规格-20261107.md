## 5. 验收与门禁

1. 三态行为：空框未聚焦＝标签在框内且 hint 不显示；聚焦／已有内容＝标签缩小上浮到框内上沿、永久可见，hint 才显露。
2. 结构探针：`label` 与输入框配对、`placeholder` 只含示例值、D 类外部标题行已删、E 类零 `.fl-field` 包裹。
3. **整容器一致**：按屏/弹层统计覆盖率，凡有 `.fl-field` 的容器内「未改输入框」必须为 0（批1 实跑 8 容器全部达标）；半吊子容器一律整份不动留批2。
4. 原型闸：`proto_registry --check` 300/300 复现（改屏块后 `--write` 重算并复跑）、索引卡 `--write` 后 15/15、`protojscheck` 零坏脚本、`protogate[strict]` 零硬红、`doclint` PASS、`git diff --check` 零。
5. 三刀变异各红其位并还原复绿；截图落仓库外不入库。
6. 收口：文件级 pathspec 局部提交，**不推送、不出包**；未推计数如实写回 STATUS。

## 6. 已知坑

- **行尾敏感**：`index-ai.html`／`index-day_aim__goods.html` 盘上是 CRLF，`index.html`／`index-bookshelf.html` 是 LF；注册表 size/hash 按盘上文本实测，写回必须逐文件保真行尾，否则假漂移几百处且 `git diff` 全空。只有真实内容改动才允许 `--write` 重算。
- **外部标题删行的信息保全**：`apUrl` 的「按端点要求填完整前缀」、`apKey` 的「该服务商单独保存」是有效说明，删行前必须迁到下方既有说明区，别只省高度丢信息。
- **padding 挤压**：原型输入框多为 `py-3/px-4` 或 `.inp` 固定内边距，标签上浮后需给输入文字留 `padding-top`，否则文字与标签重叠；真机 Flutter 侧 `isDense: true` ＋ `vertical: 10~15` 同理，实现轮必须出截图复验。
- **JS 模板串**：bookshelf 等文件有 `${ph}` 之类动态生成的输入框，本批不碰，留批2 按渲染点单独裁定。
