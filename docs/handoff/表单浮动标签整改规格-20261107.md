## 0. 产品裁定（2026-11-07）

| 类 | 现状 | 裁定 |
|---|---|---|
| A 纯字段名型 | 字段名只写在 hintText，输入后消失 | **全改** |
| B 字段名＋示例混写 | 如「目标 O 标题，如：O4 把身体养回来」 | **全改**：字段名拆进 labelText，示例值留 hintText |
| C 纯示例值型 | 字段名从未出现，或写成 URL/格式样例 | **全改**：字段名按上下文补进 labelText |
| D 已有外部永久标题 | 字段上方一行独立 Text 标题 | **也改**：字段名并入浮动标签、**删掉外部标题行**以省页面高度（产品明确「这是有价值的优化」）；标题里的必填/说明信息不得丢失，迁进 labelText 文案或 helperText |
| E 搜索框／多行正文 | 搜索、筛选、日记/笔记正文编辑区 | **豁免**，一行不动 |
| 反向错用 | `note_edit_rich.dart:117` 把 `https://…` 写成 labelText | 随 C 类修正 |

- **显式声明口径**：按规则字面「decoration 配置 labelText，floatingLabelBehavior: FloatingLabelBehavior.auto」，全仓显式写 `floatingLabelBehavior: FloatingLabelBehavior.auto`（含已合格的 20 处）；如产品另给口径再改。
- **规范冲突**：`docs/UI组件规范.md` LH-C04 分节卡规格现写「独立 TextField（hint=占位语）」，与本规则相反，实现轮须同步改该行。
- **批2 补充口径（2026-11-08 实跑后立）**：① flex/grid 并列的紧凑数值格用 `.fl-compact` 变体（空框标签 11px／上浮 9px、padding-top 17px），仍属「整容器一致」，不算半吊子；② 只删「纯字段名」的独立标题行（批2 落 `p-itemEdit` 的「物品备注」1 行），带说明/分组语义的标题与输入框下方的单位 span 保留；③ 自身带 `hidden` 的条件字段（如 `aaLimit`），label 由 CSS 跟随隐藏，**不动 JS 显隐逻辑**；④ JS 模板串动态渲染的输入框不参与改造，整份容器留待裁定；⑤ 预填值字段（如 `iePlan` value=300）的空框态本就应上浮，探针按 `defaultValue` 区分。
- **原型先行**：`AGENTS.md` 禁令＝UI 变更先改原型并经用户确认，再动实现。故批1/批2 只改 `prototype/**`，**lib 一行不动**；实现轮另起批并须原型过门。

## 6. 已知坑

- **行尾敏感**：`index-ai.html`／`index-day_aim__goods.html` 盘上是 CRLF，`index.html`／`index-bookshelf.html` 是 LF；注册表 size/hash 按盘上文本实测，写回必须逐文件保真行尾，否则假漂移几百处且 `git diff` 全空。只有真实内容改动才允许 `--write` 重算。
- **外部标题删行的信息保全**：`apUrl` 的「按端点要求填完整前缀」、`apKey` 的「该服务商单独保存」是有效说明，删行前必须迁到下方既有说明区，别只省高度丢信息。
- **padding 挤压**：原型输入框多为 `py-3/px-4` 或 `.inp` 固定内边距，标签上浮后需给输入文字留 `padding-top`，否则文字与标签重叠；真机 Flutter 侧 `isDense: true` ＋ `vertical: 10~15` 同理，实现轮必须出截图复验。
- **JS 模板串**：bookshelf/sync/desktop 等文件有 `PROVIDER_FORMS`、`qp-note` 之类动态生成的输入框；改造脚本必须按 `<script>` 行区间跳过，否则会把 JS 字符串里的占位符一起改坏。批2 已把三类动态表单整份留待裁定。
- **textarea 是成对标签**：只匹配开标签会把 `<label>` 和 `</div>` 塞进文本域内容（浏览器转义成可见文字），必须整段匹配 `<textarea …>…</textarea>` 并保留内容，闭合标签放在 label 之前。批2 首版实跑踩过，靠备份整批恢复后重改。
- **自身 hidden 的条件字段**：如 `aaLimit` 由 JS `classList.toggle('hidden')` 控制显隐，若把 `hidden` 迁到包裹层，JS 就再也显示不出来；正解是 CSS `.fl-field>input.hidden+label[data-fl]{display:none}` 让 label 跟随隐藏。
- **探针两类误判**：预填值字段（defaultValue 非空）的空框态本就该上浮，不能按「空框＝标签居中」判红；`display:none` 的字段无法 focus，断言前需在内存 DOM 临时显形。
- **工厂调用点插 label 必须在右括号内**：首版按括号匹配把 `, label: 'xxx'` 插到了 `_inp(...)` 的 `)` 之后，变成 `TextField` 的未知命名参数（analyze 24 error），并有一处挤进 hint 字符串导致非法字符。正解＝调用方已保证 core 以该调用右括号结尾，直接 `core.rfind(')')` 定位后插在其前。
- **Dart 文件是 CRLF**：46 份目标文件盘上为 CRLF，脚本须 `open(..., newline='')` 读、`splitlines(keepends=True)` 改、按文件主行尾插入新行；Python 3.11 的 `Path.read_text(newline=)` 不支持（3.13 才有），须用 `open()`。
- **插入缩进会造 trailing whitespace／孤立空行**：`InputDecoration(` 后原本就有换行时，插入片段末尾的缩进前缀会独占一行。收口前按「只清纯空白行」＋「删 auto 后紧邻空行」两道后处理，`git diff --check` 才绿。
- **守护断言的豁免文案必须从源码实读**：首版凭印象写了 `inbox_page.dart` 的 `记一笔`，实跑守护即红；该文件真实 hint 是 `脑中任何念头，扔进来…`。断言从需求推，不从记忆反推。
- **D 类包装型标题**：`mindmap_node_sheet.dart` 的 `_Label(text:..., child: TextField(...))` 不是独立行，需按括号平衡拆掉包装壳、保留 child，并同步删掉 `_Label` 的闭合行；独立行型才可直接删行。
- **紧凑变体行高**：`.fl-compact` 把 padding-top 降到 17px，但并列格仍比原输入框高约 8~10px；实现轮 Flutter 侧 `isDense: true` ＋ `vertical: 10~15` 同理，必须出真机截图复验文字不与标签重叠。
