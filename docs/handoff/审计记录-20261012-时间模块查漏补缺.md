## 3. P0 逐条（数据不闭环 / 性能）

### P0-1 跨天补录缺守卫、跨月不可表达 ✅
- 结束日只在**起始月**的日轮里选：`_dayItems = List.generate(_daysInMonth, …)`（`time_pick_sheet.dart:106`），`_eDayN` 又被 `clamp(1, _daysInMonth)`（`time_pick_sheet.dart:134`），`_eDate => DateTime(_date.year, _date.month, _eDay)`（`:194`）——**年月恒等于起始年月**，故 12/31 → 1/1 这类跨月段无法选择。
- 且**没有「结束不早于起始」的校验**：用户可把结束日滚到小于起始日（如起始 9/20、结束 9/5），`_crossDay` 为真后走两段分支（`:278-285`）：先写 `markRange(_sDate, s, 1440)`，再写 `markRange(eDate=9/5, 0, e)` ⇒ **落出一段结束早于开始的错行**。
- 方向：结束日轮覆盖「起始日 + N 天」窗口（或允许跨月步进），并加 `eDate < sDate ⇒ 拒绝 + 就地红字`。

### P0-2 计时块跨零点时长丢失 ✅
- `endTiming` 落库时 `final e = atMin.clamp(b.startMin + 1, 1440)`（`time_block_dao.dart:82`）——请求值被钳到 1440；`effEnd` 同样 `nm.clamp(startMin, 1440)`（`time_block.dart:47`）。
- 后果：23:50 开始、次日 00:10 结束的计时块，结束被记为 24:00，**跨过零点的 20 分钟丢失**，也不按需求「两段行」拆。需求 line 129 只写了「跨天**事件**按两段行落库」，**计时块跨零点这一支没被需求/原型覆盖**（原型 `bend()` 同样 `Math.max(b.s, nowMin())` 封在 1440）。
- 方向：先定口径（计时块跨 0 点是否也拆两段），再改 `endTiming`/`effEnd`。

### P0-3 分类拖拽「换组」在最顶处不生效 ✅
- `_reorder`（`category_page.dart:220-226`）：次级的新父级＝其上方最近的一级 `id`；若上方无一级，`parent = null`，调 `dao.update(c, parentId: parent, sort: sortS)`。
- 而 `CategoryDao.update` 只写 `if (!clearParent && parentId != null) 'parent_id': parentId`（`category_dao.dart:24`）——**`parentId == null` 时不写 `parent_id`**，字段保持旧值 ⇒ 拖到最顶的次级**仍留在原组**，只有 `sort` 变了（跨组 sort 序错乱）。
- 附带：次级行的 `InkWell.onLongPress`（`category_page.dart:120`）与 `ReorderableListView` 的长按拖拽抢手势，换组动作可能被编辑弹层截走（○）。
- 方向：`_reorder` 对「上方无一级」的次级显式传 `clearParent` 或改判据，别用 `parentId: null` 表达。

### P0-4 块视图拖选每 move 全页重建 ✅
- `onPointerMove` 每次 `setState(() => _selB = i)`（`grid_day_view.dart:206-210`），重建整棵块视图 State（网格 + 右侧速记列 + 粒度条）。15 分档 96 格、1 分档 1440 格，拖动全程逐步重建。
- 方向：选区态改用 `ValueNotifier`/`AnimatedBuilder` 只重绘受影响格，或把网格拆成独立 `StatefulWidget`。
