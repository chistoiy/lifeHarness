## 1 · 本批三屏原型规格（落点全部在 `prototype/index-media.html`）

### 1.1 `m-notes` 影音笔记库（升级现屏）
- 顶栏：返回｜品牌「影音笔记库」｜**复习**钮（开 `m-review`，带到期角标读数）｜＋ 记笔记（开 `m-sheet-note-edit`）。
- 筛选行（全部真交互，不许再留演示 toast）：
  ① 类型 chips＝全部＋五类（现成，保留）；
  ② kind chips＝不限 kind/电影/剧集/音乐/游戏（**改真筛选**）；
  ③ 条目 chips 横滚＝只列出**有笔记的条目**（全部条目＋各条目名），选中与 ①② 叠加；
  ④ 标星 toggle chip（只看看过的）；
  ⑤ 标签 chips 横滚（来自 MNOTES.tag 去重，all 默认）；
  ⑥ 关键词搜索输入框（对 body/条目名即时过滤）。
- 视图四档 seg（卡片／行／按条目／截图墙）：卡片＝现形（色标左边线）；行＝单行紧凑（类型点＋出处＋首截）；按条目＝按条目分组带每组计数；截图墙＝两列图块（`image_paths` 有值出图，无值虚线块「无截图」）。**四视图吃同一筛选结果，计数必须一致**（计划 §五验收 L243）。
- 行内动作：点行＝开复习卡定位该条；星钮就地切；删除走 LH-S31 确认式（原型演示 `confirm('…')` 定式）。
- 空态两档：库里零笔记＝虚线「还没有影音笔记 · 点右上＋记一条」；有库但当前筛选没有＝虚线「当前筛选没有笔记」。

### 1.2 `m-review` 名场面复习卡弹层（新屏，注册表＋1）
- 形态＝半屏弹层内一张翻面卡（`.mds-rev` CSS 现成）：正面＝正文（画面描述/歌词/台词/截图缩略），背面＝出处（kind·《条目》·at）＋我的批注（thought，无批注出虚线「未写批注」）。点卡翻面。
- 档位＝艾宾浩斯 1/3/7 天：弹层底部三档 chips 显示**当前档**（演示数据按 `created_at` 距今派生），「记住了」＝推进到下一档并取队列下一条，「跳过这条」＝本条本轮不再出；队列空＝虚线行「今天没有到期的复习」。
- 队列来源＝筛过的笔记（从行内点开＝单条模式，无队列条数与档位动作，只可翻面）。
- 复习结果落库（档位/下次到期）＝**实现批数据面**：现表 `media_notes` 无复习列，实现批按零搬数据加列（v38→v39 三列：`review_stage`/`reviewed_at`/`next_review_at`），工单此处先记账，原型不涉。

### 1.3 `m-sheet-note-edit` 唯一录入表单（升级现弹层）
补齐计划 L207 列的字段，顺序即表单顺序：
条目选择（有笔记对象可点选，从详情/笔记库进入＝预置当前条目）→ 集/曲/章节（文本框，占位语按 kind 换：第几集／曲目 N／章节）→ 时间点 → 类型五 chips（选中项左边色标跟变）→ **附件截图**（缩略位横滚：＋ 附件出演示缩略、已有附件可摘除）→ 标签 → **创建时间**（默认「现在」，就地可改成日期文本，不做两段式弹层）→ **粘贴文本钮**（OCR 不可用降级＝剪贴板粘贴进正文；真 OCR 钮置灰不隐藏，title 说「未安装识别库」）→ → 日记 ／ → 待办（动作 demo＝计划 L306）→ 保存（空正文＝字段旁红字 LH-K32，补输入即撤；防重入）。
从 `m-detail`/`m-info` 进入时条目栏已预置＝FAB 与详情共用唯一表单口径（计划 L207「唯一一张」）。
