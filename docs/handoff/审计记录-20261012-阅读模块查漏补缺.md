## 3. P0 逐条（功能断链）

### P0-1 计时结束丢时长 ✅
- `4589`（`rtToggle`）：`stopTimerUI(); … toast("计时结束 · 本次 "+Math.max(1,Math.round(timerSecs()/60))…)` —— **先停表再取秒数**，`timerSecs()`（`3545`）在 `stopTimerUI()` 把 `timer=null` 后恒返回 0，`Math.max(1,0)` 把结果钳成 1 ⇒ 读数恒「本次 1 分钟」。
- 同一根因传导到落库：`bsSaveProgress`（`3977`）`const sec=timerSecs(),mins=Math.max(0,Math.round(sec/60))` ⇒ **mins 恒 0**，本段时长写不进阅读记录。
- 方向：先 `const sec=timerSecs()` 快照再 `stopTimerUI()`，并把 sec 透传给进度弹层；顶部胶囊路径（`rtOpen`）同源同修。

### P0-2 书架「删除来源/分组/作者/出版社/标签」不生效却提示成功 ✅
- `4865`（`bmDel`）：`const arr=bmVals(bmKind); … arr.splice(i,1)` —— `bmVals`（`4823-4825`）每个分支都返回**新数组**（`[...new Set(...)]` / `bsAuthors()` 等），splice 只改副本；随后照样 `toast('已删除「v」')`。
- 方向：按 kind 定位真实源数组（`BS_SRC`/`BS_GROUPS`/`BS_AUTH_EXTRA`…）删除，或收敛成"管理视图维护"的单一入口。

### P0-3 录入/编辑页五处死键 ✅
- `5757` `bfTap('pubDate','出版日期',…, "toast('就地滚轮选年月（复用现有滚轮选择器）')")`
- `5787` `bfTap('src','来源',…, "toast('从来源库选（复用现有资料库）')")`
- `5790` `bfTap('feeDate','购入日期',…, "toast('就地滚轮选日期')")`
- 同屏还有分组、标记在读时间两处同类（`5780` / `5782`）○
- 后果：书籍资料的「出版日期 / 来源 / 购入日期」**永远无法录入或修改**，但它们被列在表单可编辑区。
- 方向：接既有滚轮/选择器；若本期不做，则改为只读展示，别留可点假入口。

### P0-4 阅读器分页缓存自毁 → 全书逐章重算 ✅
- `5948`：`brPagCache={};brPagCache[key]=pages;return pages` —— 每次调用**清空整张缓存**只留最后一章；而 `brTotal`（`5949`）会逐章调用 `brPagesOf` ⇒ 每次求总页数都重算全书章节。长书（>10 万字）翻页/进目录/拖进度都踩。
- 方向：按 `book|章|样式版本` 组键累加缓存，仅在样式变更时统一失效。

### P0-5 阅读器图片缩放两键是非法 JS ✅
- `2108`/`2109`：`onclick="brIvZoom(-)"` / `onclick="brIvZoom(+)"` —— 一元运算符缺操作数 ⇒ 内联处理器**编译失败**，点击无任何反应。
- 附带门禁盲区：`protojscheck.js` 只解析 `<script>` 体，看不见 HTML 属性里的表达式（§7.5）。
- 方向：改 `brIvZoom(-1)` / `brIvZoom(1)`。

### P0-6 X-Ray「重置」空转 ✅
- `7336` `xrReset`：只改 `XR.done=0; XR.status='none'` + 角标，**不清 `XR_ENTS`** ⇒ 头显「已索引 0/18」而列表仍 24 条；且 `xrHeadHtml` 分支只覆盖 run/pause/fail（`7129-7133`）⇒ status='none' 落进 else，「继续生成 / 重新解析」双双消失，面板内再也发不起解析。
- 方向：重置须清实体/出场/任务态三件，或至少保留可再次发起的入口。

### P0-7 X-Ray 屏蔽链无写入方 ✅
- `XR_BLOCKED` 全文件只有三处：声明 `7432`、读取过滤 `7155`、`delete` `7467` —— **没有任何写入**（`xrDoDel` 的「不再显示该词 / 升级全局黑名单」、养词库 `forbid` 都不写它）⇒ 屏蔽对列表零效果。
- 方向：补写入点（按词/按范围），并让养词库 forbid 与之同源。

### P0-8 X-Ray 角标与面板读数不同源 ✅
- 书架角标读 `b.xr`（`7504-7526`），面板头读模块级单例 `XR`（`7055` / `7127-7133`）⇒ 切到 b2（解析中 57%）开面板仍显示 b1 的「已索引 12/18」。
- 方向：面板头以当前书 `b.xr` 为唯一源，或打开面板前 `xrLoadBook(id)`。
