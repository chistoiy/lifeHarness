## 一、产品定位

| 项 | 内容 |
|---|---|
| 产品名称 | **LifeHarness**（V1.14 由 LifeHaness 拼写修正更名；工程目录 lifeHarness，包名 lifeharness） |
| 目标平台 | Android（Flutter 开发，架构预留 iOS） |
| 目标用户 | 需统一管理日程、任务、记录个人生活的学生 / 职场人士 |
| 核心价值 | 多模块非孤岛，形成「计划 → 执行 → 记录 → 复盘」闭环 |
| 运行模式 | 纯本地无账号、离线优先；同步 = 本地备份 + WebDAV（坚果云） |
| 语言 | 仅中文 |
| 兼容 | Android 8.0+（API 26+） |

### 已确认关键决策
- 纯本地无账号，不做 OAuth；WebDAV 直连（坚果云应用密码）。
- 习惯打卡、番茄钟/专注计时等 → 后置至 V1.x+。
- 多设备同步：本地备份 + WebDAV（坚果云首选适配）。
- 微信读书导入采用「第三方导出文件解析」方案（无官方接口）。
- 备份文件采用自定义 `.lhbak` 格式；可选口令加密。
- 优先级由产品方委托技术方排定（见《开发计划书》）。

## 二、功能模块（共 15 个大模块）

### 模块 1 · 时间管理
日程增删改查（起止/地点/备注/提醒）、**五视图（轴/块/日/日程/周 · V1.19）**、周期事件、时间冲突检测、时间块规划（拖拽）、计划vs实际偏差、时间去向分类与统计图表。专注计时（番茄钟）**V1.x**。
- **五视图体系（V1.19 · 参考竞品截图重构）**：日视图三细分（轴/块/日）+ 日程（agenda 按天分组）+ 周（7×24 网格）；**月浏览由顶部迷你月历承担，不再设独立月视图 tab**；切换任意视图自动收起月历为周行。**五视图是同一数据的不同投影**：事件、时间块、进行中/已完成态在所有视图同步展示与操作，禁止视图间操作逻辑分叉。
- **块视图全天 0–24（V1.19 · 替代 V1.12 的 06:00–24:00）**：格子覆盖 00:00–23:59 全时段，回填/速记不再钳制 06:00 起点；总面积固定与粒度自适应规则不变（1440/粒度 格）。
- **分类速记列（V1.19）**：轴视图与块视图右侧固定分类列（8 类，随分类自定义能力扩展）；**点分类=记录到此刻**——上一段速记自动截止到当前时间，新段从当前时间开始（接龙式一键记时间）。
- **统一事件详情弹层（V1.19 · 修复"完成即失联"）**：任意视图点击事件（计划⚡/进行中●/已完成✓，含格子块与时间轴卡）打开同一详情弹层：查看、▶开始/■结束、✎编辑、删除；**已完成事件保持可编辑/删除**，删除同步五视图与时间账本。
- **事件补录（V1.19）**：新建日程弹层显示"**9月17日 · 09:30 — 10:30**"日期时间行并可任意修改；从日历/日/周/日程视图任一入口创建时**默认落在所选日期时段**（修复实现中忽略选中日的 bug）。
- **周视图拾取弹层（V1.19）**：点 7×24 任一格子 → 日期+时间（滚轮式，原型以下拉模拟）+分类+备注，支持「**继续添加**」（连点连记）与「添加」（落库并五视图同步）。
- **自定义分类（V1.19 · 补原型欠账）**：设置页新增「分类管理」：时间块分类与事件色标的自定义增删改（名称/颜色/排序），全局所有视图与统计引用同一分类表。
- **两级分类管理（V1.19 · 参考竞品图1-3）**：分类树支持**一级/次级两层**（次级带默认标签如 #开会/#加班，颜色继承父级浅色）；**长按拖拽=调整顺序 / 拖入其他父级换组**；工具栏：全部折叠/排序/添加；「添加分类」页：一级/次级切换 + 上级分类选择 + 名称/默认描述/默认标签/颜色（命名色板），支持**继续添加**；保存后速记列/标记面板/添加弹层/时间账本**同源即时生效**。入口：我的 → 分类管理、添加事件弹层「无分类 ›」。
- **统一添加事件弹层（V1.19 · 图4/6/7 · 轴/块/日/周四视图共用）**：点空白时段/格子 → 同一弹层：**上尾/当前日期 + 时:分（滚轮式，原型下拉模拟）+ 时长（0分钟/15/30/1时/2时）** + 两级分类选择（点一级、再点次级精确到子项）+ 标签 + 备注（0/5000 计数）+ **继续添加/添加**；跨天时长显示"· 跨天"标记；添加后五视图与时间账本同步。
- **日程视图对接待办（V1.19 · 图8-10）**：agenda 每天同时展示**日程 + 设置了时间的待办**（紫底行·可勾选完成·象限角标）；待办新建弹层新增「**设置时间**」四态：无/时间点/时间段/全天（**时间段起止相同自动转全天**），可选「**关联计时分类**」（完成后按实际耗时入 L4 账本）；空天提供「＋日程」「＋待办项」双入口。
- **日程视图定义修正（V1.19.2 · 竞品图1）**：日程视图 = **单日小时日程板**（非跨天 agenda）——**每行代表一个小时（0-23）**，事件块/时间块/设了时间的待办挂在对应小时行（事件色块、待办紫框行、进行中红脉冲、完成绿块）；**空行显示「＋添加事件」**，点行打开统一添加弹层（预选该日该小时）；**当前时间红线游标 + 秒级时间标签**（HH:MM:SS 每秒刷新）；全天待办以紫横幅置顶展示。
- **待办表单补全（V1.19.2 · 竞品图2）**：待办新建弹层增加 **状态三态（未完成/完成/放弃）**、**颜色（体现在日程视图，命名色板与分类共用）**、**分组（未分组/自定义）**；"放弃"待办划线降饱和并带 #放弃 标签，可在垃圾箱批处理中一并清理（另批）。
- **日视图双模式（时间轴 / 格子）**：日视图可切换为格子视图，粒度 **1–60 分钟由用户自行设置**（默认 15 分钟）；**按住滑动多选相邻格子**，松手弹出标记面板快速记录时间块（选分类/备注，可选同步生成时间轴日程与计入时间账本）；点击已标记格子可查看、取消或覆盖标记；格子按分类着色，整点刻度标识。
- **进行中事项实时记录（V1.12）**：新建日程提供「**▶ 现在就开始**」两态流——点击即设开始时间（记录正在做的事），事项进入**进行中状态**：时间轴顶部红色脉冲卡（实时已耗时）、格子视图对应块红色呼吸标识、日历对应天红点；做完点「■ 结束」自动生成结束时间与耗时，事项转为**已完成态**（时间轴绿色✓卡片 + 划线样式，保留可查），回填实际耗时（L1）并入时间账本（L4，供周报/复盘分析）；也支持预约未来事项的常规创建。
- **格子总面积固定（V1.12）**：格子容器高度固定为屏幕可视区比例（与页面滚动解耦），列数按粒度自适应（1080 格也不滚动），任意粒度全天一屏完整概览；低粒度隐藏整点数字标签保持整洁。
- **日历智能折叠（V1.12）**：顶部日历默认月历展开态；**用户在下方时间区操作或页面向下滚动超阈值时自动收起为单周 7 天行**；周行支持**手势左右滑动切天（超阈值触发，带平滑滑入动画）**，也可 ‹ › 步进/点选；点当前日重新展开月历；跨月引导展开后切换。固定 6 行 42 格，收起/展开不跳版。
- **事项存在性圆点（V1.12）**：月视图/周行/月视图 tab 统一规则——凡当日有事项（已完成/进行中/计划中）则**日期右下角实心小圆点**；**按状态三色区分：进行中红色脉冲、计划中蓝、已完成绿**；同日多态取最高优先级（进行>计划>已完成），面板附图例说明。

### 模块 2 · 待办事项（含四象限）
任务 CRUD、2 级子任务、优先级、截止+提醒、重复任务、快速添加；清单/智能视图（今天/近7天/已安排/已完成/过期）；拖拽排序。
- **四象限模式（核心交互）**：2×2 矩阵看板，卡片象限间拖拽流转；双录入（手动 / 引导式"重要吗·紧急吗"两问）；象限名称颜色可自定义；智能规则（临期升入紧急、滞留淘汰建议、"重要不紧急"空置失衡提醒）；象限量与耗时占比统计。
- **习惯打卡（V1.14 提前落地原型演示，正式开发为 V1.x 首位候选）**：正向（好习惯坚持：打卡/连续天数/可撤销）与**负向**（坏习惯控制：设定周期内目标不出现次数上限，每天未触发→正向积累 +1，当天触发→扣减并记录触发日，达上限预警，连续达标升级「戒除中🎉」）双模式；周/月双维统计（完成率趋势/连续天数/圆点矩阵）；入口：底部导航可启用「习惯」栏目 + 宫格；习惯提醒归「提醒通知」二级页；创建即接 L10。

### 模块 3 · 日记 / 笔记
每日多篇日记、富文本（粗体/列表/勾选待办）、图片附件、心情 emoji+标签、天气、日记模板（自由/感恩三件事/KPT）；回顾（那年今日、心情趋势、词云）。语音附件 V1.x。
- **日记列表体验升级**：月度概览卡 + 筛选 + 时间线卡片；**☂ INS 风格（V1.14）**：列表页与详情页均可切换「📱 INS 卡片流」——每篇日记为独立卡片（日期+天气头部、心情 emoji 大图、正文、**2×2 图片网格**、标签与关联待办/摘录引用块、❤/⭐ 互动占位），支持 **⛶ 单帖全屏浏览**（点空白关闭）。
- **笔记·纯纯写作风编辑器（参考纯纯写作）**：极致安静的纸感书写界面；**纸色主题**（米纸/纯白/护眼绿/深夜）与字号可调；**段落聚焦（dim）模式**——当前段高亮其余淡出；输入即存的**自动保存**与状态指示；**版本快照**（停输 30 秒/每 500 字自动留存，恢复为副本不覆盖现稿）；断点续写（草稿提醒）；☑ 待办行同步任务列表（L3）；TXT/PDF 导出；字数与阅读时长实时显示；行高 2.15/字距 0.03em 中文阅读优化。
- **Markdown 全能力（V1.9 强化）**：
  - **四模式**：🖊 专注写作 / ⌨️ MD 源码 / 🔀 分屏实时渲染（输入即变）/ 👁 渲染预览，任意切换；
  - **MD 语法快捷操作栏**：标题/粗体/斜体/删除线/行内代码/引用/无序列表/待办项/表格/图片/链接/行内公式/块级公式/分割线，一键插入并包裹选中文本；
  - **语法支持集**：标题 1-4（快捷栏 H 键循环升级 h1→h6→正文，V1.17）、粗斜删、行内代码与代码块、引用、有序/无序列表、GFM 待办、表格、链接、图片、分割线；
  - **LaTeX 数学公式**：行内 `$...$` 与块级 `$$...$$` 实时渲染，**另支持 `\[..\]` 块级定界符（渲染层归一化转换，V1.17）**；正式版用 flutter_math_fork（KaTeX 语法）支持分式/根式/上下标/希腊字母/大型运算符/环境等全量语法；
  - 读写一体：渲染态为展示层，源文件始终为标准 Markdown 纯文本（导出无损、插件可处理）。
- **笔记管理**：文件夹体系 + 置顶 + 归档/回收站（长按）+ 全文搜索 + 排序（更新/创建/字数）+ 图片笔记。

### 模块 4 · 阅读笔记
书库（在读/想读/已读/弃读）、原文摘录+感想、划线颜色分类、书籍标签搜索、一页式总结；**外部导入**：Markdown/TXT/HTML/CSV·JSON（Notion/Obsidian 等）、微信读书（第三方导出解析，字段映射预览）、Kindle `My Clippings.txt`；Evernote(.enex) V1.x；按"书名+原文哈希"去重；导出为 Markdown。
- **阅读计时（V1.11）**：书籍详情页「▶ 开始阅读」一键计时，**悬浮计时条常驻**（跨页面不中断）；看完点「结束」→ 弹出进度录入；也可不走计时直接手动补记。
- **多方式进度录入**：页数区间（132→320页）/ 百分比 / 章节（自动匹配目录）；观影同构：时间点 / 百分比 / 集数（第 5/12 集）；**运动同构（V1.17）：距离 / 时长 / 配速三模互算（健康页记录卡）**；保存后计算本次时长、阅读速度（分钟/页）。
- **耗时统计与预估**：累计总耗时（书级/周/月）、计时次数、均速节奏、**预计剩余耗时与预计读完日期**（按当前进度节奏动态重算）；阅读时长自动写入时间账本「阅读」分类（L4），计入周报与目标进度（L7）。
- **目录体系**：每书目录（章/节两级）：手动维护 / **AI 补全**（按书名作者生成标准目录待确认，属 AI 能力矩阵）/ **导入解析**（微信读书导出含目录节、calibre epub toc.ncx、MD·TXT 每行一章自动识别；按 ISBN 查在线书目库 V1.x）；目录节点标记状态（已读/在读/未读 + 摘录数），点击直达对应笔记。
- **豆瓣书单导入（V1.11）**：导入向导新增「豆瓣 · 书单/片单」源：解析导出文件（第三方导出工具数据或网页导出），导入 已读/在读/想读 标记 + 豆瓣评分 + 标记日期；去重：ISBN → 豆瓣 subject_id → 书名+作者哈希；写入后保留来源标记可批量撤销。排期 V1.0。

### 模块 5 · 收集箱 / 碎片笔记
通知栏/桌面快捷 3 秒记录；每条分流为 待办/日记片段/笔记/阅读摘录；定期清空提醒。

### 模块 6 · 今日仪表盘
首屏：今日日程时间轴+待办进度环+连续记录天数+阅读摘录+心情一键打卡+**今日持有成本卡**；今日小结分享卡片；自动周/月报。
- **主页模块自由编排（V1.10）**：主页所有卡片模块（概览卡/心情/今日日程/收集箱快捷/时间分布/功能宫格等）**顺序完全自由**：「⇄ 编排」模式进入后支持长按拖拽排序与 ↑↓ 微调，卡片描边虚线提示可拖动；退出即自动保存布局并持久化（**原型已用 localStorage 实现，正式版设置表随备份策略**，V1.17），下次启动保持；设置页提供「主页模块顺序→去编排」直达入口；后续可扩展「重置布局/卡片显隐开关」。

### 模块 7 · 目标与 OKR
年度/季度目标 + 2~4 个 KR（百分比/数值）；关联任务/阅读/日记自动汇聚进度；季度复盘引导（KPT）；目标数量上限提醒。完整版 V1.x。

### 模块 8 · 记账 / 财务简账
收支快速记账、分类、预算（超支提醒）、周期账单、月度报表/饼图/现金流；订阅支出→续费提醒日程。基础 V1.0，预算报表 V1.x。
- **账单导入（V1.9 新增）**：**支付宝 / 微信支付**账单 CSV 自动解析导入：
  - 引导文案内置（两平台导出路径步骤提示）；两平台导出均为 **zip 加密包**，导入时输入申请时设置的解压密码；
  - 自动识别支付宝（18 行表头前缀）/微信（17 行）元数据结构与列布局，字段映射自适应；**CSV 编码自适应（UTF-8 含 BOM / GBK 兜底转码，V1.17）**；预览阶段**逐笔点击可手动改分类**，确认后按修改值写入；完成页联动大额数码支出→物品建档（L12）。
  - **去重**：交易单号唯一键优先，缺失时按「时间+金额+对方」哈希兜底，重复项自动跳过可预览；
  - 分类自动映射（支付宝交易分类/微信交易类型 → 应用分类，未命中进「其他」可改，可叠加 AI 辅助归类）；退款冲抵记为负支出；代付/转入等非支出流水可选跳过；
  - 导入预览（条数/重复/将写入）+ 向导式四步流程；**整批导入记录支持一键撤销**；全程本地解析不上传；导入后可衔接物品建档（L12）。
  - 排期：随基础记账同入 **V1.0**。

### 模块 9 · 物品价值 / 每日成本核算

## 六、AI 增强能力（V1.8 调研结论 · 跨模块可选能力）

### 设计原则
1. **默认关闭、显式 opt-in**：总开关 + 能力矩阵逐项授权，未开启时全应用零 AI 请求；
2. **Key 本地化**：API Key 存系统级加密区（flutter_secure_storage），不入备份明文、不落日志、不随 WebDAV 同步；
3. **端点自治**：仅请求用户配置的 Base URL（OpenAI 兼容 Chat Completions 协议），应用自身无任何埋点上报；
4. **数据最小化**：每个功能只发送必需字段，发送前弹层展示完整发送内容可审阅；日记/财务/物品等敏感数据支持「仅摘要发送」模式；
5. **AI 结果透明**：所有 AI 生成内容带标识，写入数据前需用户确认；周报点评只发聚合统计不发原文；
6. **全离线选项**：支持 Ollama 本地模型端点，满足无云需求。

### 预置服务商
DeepSeek / OpenAI / Anthropic（协议适配：Messages API，x-api-key+anthropic-version，Key 独立存储域） / Moonshot Kimi / 通义千问 / 智谱 GLM / Ollama（本地） / 自定义（OpenAI 兼容）。验证工具支持两套协议实调。

## 七、插件平台：大模块可插拔架构（V1.15 新增）

### 可行性结论（先于规范）
Flutter **无法安全分发动态 Dart 代码**（iOS 禁止、Android 灰色地带），故大模块插件化采用：**声明式 UI Schema + JS 沙箱逻辑（QuickJS/WebView 双模式）+ SQLite 隔离表空间**；重交互依赖的宿主要提供稳定能力 API（Shelf/Timer/图表/导入向导钩子），插件只做薄层。代价：非核心模块首屏性能略于原生化，收益：安装包瘦身与社区持续适配能力，整体利大于弊。

### 分层定义
- **宿主核心（不可插件化）**：待办+四象限、日程/时间块/时间账本、日记/笔记、设置与导航框架、DB/WebDAV 同步/备份、悬浮计时条、插件运行时与权限内核、全局搜索框架（宿主索引 + 插件注册可搜源）。
- **可插件化大模块（首批→后置）**：第一波试点 **物品价值、影音游**（依赖少、同构度高）；第二波 母婴呵护、仪表盘装饰、OKR；另含无 UI 的「解析器数据包」（账单/阅读导入/Douban 适配）——格式变更不需升级 App。
- 小工具合集已是插件形态（V1.7 机制），两者共用同一套包规范与签名体系。

### 包与索引规范
- 插件包 zip：`manifest.json`（id/name/semver 版本/minHost/权限声明/mountPoints[含 weight 与槽位类型]/tables 隔离表名声明/dataMigrations 正反向脚本入口/size/sha256）+ UI Schema + JS 逻辑 + 资源；禁止任意网络域（域名白名单声明）。
- 索引：GitHub Release 的 `index.json`（插件列表 + 哈希 + changelog + 最低宿主版协商）；安装渠道：Release ZIP / raw URL / 用户粘贴任意直链（仍须哈希清单比对）。

### 六大能力规范（对应用户六场景）
1. **按需安装**：安装包仅含宿主（演示口径 38MB→15MB，-61%）；未安装模块在宫格/搜索/联动处仅置灰提示“可安装”，不打断主流程；首次进入模块入口可拉起安装浮层。
2. **版本管理**：semver + minHost 兼容协商；检查更新（手动/Wi-Fi 自动周检）；**bsdiff 增量升级**；本地保留 N-1 包与反向迁移脚本 → **一键回滚**（迁移脚本随包附带，数据无损）。
3. **安全校验**：下载后强制 SHA-256 比对 index 清单 + **minisign 发布者签名**；双重通过才解压；沙箱模型：JS 与宿主堆隔离、文件仅限插件私有目录、DB 仅限 `plugin_<id>` 表空间、跨模块交互只能走宿主事件总线与能力 API；权限逐项可拒；吊销名单（blocklist）可远程禁用问题插件；上架前人工审核 + 自动扫描。
4. **离线可用**：安装即本地永久缓存，断网全功能运行；索引降级用 last-known；仅“检查更新”需网。
5. **生命周期**：安装→启用→停用→卸载四态；**停用时释放全部挂载点（导航池/宫格/仪表盘卡）、后台定时任务与通知渠道、DB 表 detach 保留（不删数据）**；卸载：程序与缓存清除，数据快照按政策保留 30 天可恢复；表迁移带版本号，升级/回滚双向可逆。
6. **冲突处理**：挂载点三类型——**单槽互斥**（如仪表盘 hero）/ **多槽排序**（宫格、导入源列表）/ **能力型**（提醒渠道限额）；仲裁链：**用户手动排序 > manifest 声明 weight > 安装时序**；宿主在插件详情展示冲突仲裁结果（可操作），安装新插件冲实时弹仲裁告知卡；关键路径冲突（如同名表空间）安装前置拒绝。

### 交互登记（原型已实现）
「🧩 插件中心」页（底部导航池可启用/宫格/设置二级入口）：发现·已安装·更新三 tab 列表 → 点卡片进详情（功能长介/SHA-256+签名行/沙箱权限逐项/挂载点与冲突仲裁文案/版本历史与回滚按钮）→ 安装七阶段进度动画（连接→下载→哈希校验→签名→权限审阅→建表→挂载）→ 完成后管理（停用/卸载/回滚）；更新 tab 演示 bsdiff 增量流程；页面顶部常驻冲突仲裁规则说明；自定义源索引 URL 可改。

### 排期

## 八、全局边界与异常处理规范（V1.16 新增）

### 8.1 时间与系统时钟
- **时钟篡改防护**：成本摊薄/习惯连续/记录天数采用「日期水位线」法——记录最大已见日期，时钟回拨不重复摊薄、不断连、不新增记录；所有计时（阅读/观影/哺乳/进行中事项）起始时间戳落库，App 重启后可恢复续计。
- **跨天归属**：夜间哺乳/睡眠/跨天事件按开始日归属 + 跨天标记；「日界线」固定为自然日 **00:00（OQ-2 已决策）**；夜间场景由开始日归属机制保障不统计错，无需额外日界偏移。
- **日期边界**：2/29 生日非闰年按可配惯例（2/28 或 3/1）庆祝；农历闰月显式标注；跨年周计算以 ISO 周为准。
- 时间戳统一 UTC + 偏移字段存储（为未来多时区预埋）。

### 8.2 数据与存储
- schema 迁移前自动写 `pre-migrate-<ver>` 备份，失败自动恢复并进入只读修复模式；每日 DB 完整性自检（integrity_check），损坏引导从最近 .lhbak 恢复。
- 孤儿附件回收（记录删除级联回收，回收站 7 天缓冲）；存储 <500MB 预警、<200MB 禁新增附件。
- **数据导出**（补遗需求，入 V1.0）：全量/分模块导出 JSON（无损）/CSV/Markdown（含笔记/日记）+ 附件打包。

### 8.3 同步与导入
- WebDAV 批量原子性：先附件→后 DB→成功标记；无标记则下次续传；坚果云 429 限流指数退避；冲突「逐条选择」未处理时默认双留（重命名副本），**永不静默丢弃**。
- 重复导入同一账单文件 → 全命中去重并提示「该文件已于 X 日导入」；万条级大文件分批事务、进度可视、可取消；整批撤销窗口 90 天。

### 8.4 权限与降级
- 通知权限被拒 → 全部提醒降级为应用内待办角标并明示；Android 12+ 精确闹钟缺权 → 近似闹钟+说明；Android 13+ 图片选择用 Photo Picker 免存储权限。
- 应用锁（**OQ-1 已决策：不设 PIN/生物识别锁**）：纯本地无找回通道下，锁忘 PIN 必然造成数据不可恢复丢失，危害大于收益；如需要「图标/应用名伪装」轻量遮挡可作为 V1.x 备选池条目（不涉及数据加密锁）。

### 8.5 插件与主题
- 安装原子化：校验→临时目录→成功才替换，失败即清理；插件 JS 沙箱 watchdog（3s）超时杀死，宿主零影响；可独立禁用崩溃插件。
- 损坏主题 json 热加载失败 → 自动回退上一有效令牌集并提示；签名/SHA 不匹配 → 拒绝 + 本地审计日志。
