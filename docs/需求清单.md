# LifeHarness 需求清单（V1.14 汇总冻结版）

> 本文件为经多轮确认（至 V1.14）后冻结的完整需求汇总，是后续开发的唯一需求依据。
> ⚠️ 品牌修正（V1.14）：项目由 LifeHaness 正式更名为 **LifeHarness**，工程目录 `lifehaness` → `lifeHarness`。
> 状态：**已确认，可进入开发**。任何增删改请更新本文件并在《交接文档》变更日志中登记。

## 一、产品定位

| 项 | 内容 |
|---|---|
| 产品名称 | **LifeHarness**（V1.14 由 LifeHaness 拼写修正更名；工程目录 lifeHarness，包名 lifeharness） |
| 目标平台 | Android（Flutter 开发，架构预留 iOS） |
| 目标用户 | 需统一管理日程、任务、记录个人生活的学生 / 职场人士 |
| 核心价值 | 多模块非孤岛，形成「计划 → 执行 → 记录 → 复盘」闭环 |
| 运行模式 | 纯本地无账号、离线优先；同步 = 本地备份 + WebDAV（坚果云） |
| 语言 | 仅中文 |
| 兼容 | Android 8.0+（API 26+） |

### 已确认关键决策
- 纯本地无账号，不做 OAuth；WebDAV 直连（坚果云应用密码）。
- 习惯打卡、番茄钟/专注计时等 → 后置至 V1.x+。
- 多设备同步：本地备份 + WebDAV（坚果云首选适配）。
- 微信读书导入采用「第三方导出文件解析」方案（无官方接口）。
- 备份文件采用自定义 `.lhbak` 格式；可选口令加密。
- 优先级由产品方委托技术方排定（见《开发计划书》）。

## 二、功能模块（共 15 个大模块）

### 模块 1 · 时间管理
日程增删改查（起止/地点/备注/提醒）、日/周/月视图、周期事件、时间冲突检测、时间块规划（拖拽）、计划vs实际偏差、时间去向分类与统计图表。专注计时（番茄钟）**V1.x**。
- **日视图双模式（时间轴 / 格子）**：日视图可切换为格子视图，粒度 **1–60 分钟由用户自行设置**（默认 15 分钟）；**按住滑动多选相邻格子**，松手弹出标记面板快速记录时间块（选分类/备注，可选同步生成时间轴日程与计入时间账本）；点击已标记格子可查看、取消或覆盖标记；格子按分类着色，整点刻度标识。
- **进行中事项实时记录（V1.12）**：新建日程提供「**▶ 现在就开始**」两态流——点击即设开始时间（记录正在做的事），事项进入**进行中状态**：时间轴顶部红色脉冲卡（实时已耗时）、格子视图对应块红色呼吸标识、日历对应天红点；做完点「■ 结束」自动生成结束时间与耗时，事项转为**已完成态**（时间轴绿色✓卡片 + 划线样式，保留可查），回填实际耗时（L1）并入时间账本（L4，供周报/复盘分析）；也支持预约未来事项的常规创建。
- **格子总面积固定（V1.12）**：格子容器高度固定为屏幕可视区比例（与页面滚动解耦），列数按粒度自适应（1080 格也不滚动），任意粒度全天一屏完整概览；低粒度隐藏整点数字标签保持整洁。
- **日历智能折叠（V1.12）**：顶部日历默认月历展开态；**用户在下方时间区操作或页面向下滚动超阈值时自动收起为单周 7 天行**；周行支持**手势左右滑动切天（超阈值触发，带平滑滑入动画）**，也可 ‹ › 步进/点选；点当前日重新展开月历；跨月引导展开后切换。固定 6 行 42 格，收起/展开不跳版。
- **事项存在性圆点（V1.12）**：月视图/周行/月视图 tab 统一规则——凡当日有事项（已完成/进行中/计划中）则**日期右下角实心小圆点**；**按状态三色区分：进行中红色脉冲、计划中蓝、已完成绿**；同日多态取最高优先级（进行>计划>已完成），面板附图例说明。

### 模块 2 · 待办事项（含四象限）
任务 CRUD、2 级子任务、优先级、截止+提醒、重复任务、快速添加；清单/智能视图（今天/近7天/已安排/已完成/过期）；拖拽排序。
- **四象限模式（核心交互）**：2×2 矩阵看板，卡片象限间拖拽流转；双录入（手动 / 引导式"重要吗·紧急吗"两问）；象限名称颜色可自定义；智能规则（临期升入紧急、滞留淘汰建议、"重要不紧急"空置失衡提醒）；象限量与耗时占比统计。
- **习惯打卡（V1.14 提前落地原型演示，正式开发为 V1.x 首位候选）**：正向（好习惯坚持：打卡/连续天数/可撤销）与**负向**（坏习惯控制：设定周期内目标不出现次数上限，每天未触发→正向积累 +1，当天触发→扣减并记录触发日，达上限预警，连续达标升级「戒除中🎉」）双模式；周/月双维统计（完成率趋势/连续天数/圆点矩阵）；入口：底部导航可启用「习惯」栏目 + 宫格；习惯提醒归「提醒通知」二级页；创建即接 L10。

### 模块 3 · 日记 / 笔记
每日多篇日记、富文本（粗体/列表/勾选待办）、图片附件、心情 emoji+标签、天气、日记模板（自由/感恩三件事/KPT）；回顾（那年今日、心情趋势、词云）。语音附件 V1.x。
- **日记列表体验升级**：月度概览卡 + 筛选 + 时间线卡片；**☂ INS 风格（V1.14）**：列表页与详情页均可切换「📱 INS 卡片流」——每篇日记为独立卡片（日期+天气头部、心情 emoji 大图、正文、**2×2 图片网格**、标签与关联待办/摘录引用块、❤/⭐ 互动占位），支持 **⛶ 单帖全屏浏览**（点空白关闭）。
- **笔记·纯纯写作风编辑器（参考纯纯写作）**：极致安静的纸感书写界面；**纸色主题**（米纸/纯白/护眼绿/深夜）与字号可调；**段落聚焦（dim）模式**——当前段高亮其余淡出；输入即存的**自动保存**与状态指示；**版本快照**（停输 30 秒/每 500 字自动留存，恢复为副本不覆盖现稿）；断点续写（草稿提醒）；☑ 待办行同步任务列表（L3）；TXT/PDF 导出；字数与阅读时长实时显示；行高 2.15/字距 0.03em 中文阅读优化。
- **Markdown 全能力（V1.9 强化）**：
  - **四模式**：🖊 专注写作 / ⌨️ MD 源码 / 🔀 分屏实时渲染（输入即变）/ 👁 渲染预览，任意切换；
  - **MD 语法快捷操作栏**：标题/粗体/斜体/删除线/行内代码/引用/无序列表/待办项/表格/图片/链接/行内公式/块级公式/分割线，一键插入并包裹选中文本；
  - **语法支持集**：标题 1-4、粗斜删、行内代码与代码块、引用、有序/无序列表、GFM 待办、表格、链接、图片、分割线；
  - **LaTeX 数学公式**：行内 `$...$` 与块级 `$$...$$` 实时渲染；正式版用 flutter_math_fork（KaTeX 语法）支持分式/根式/上下标/希腊字母/大型运算符/环境等全量语法；
  - 读写一体：渲染态为展示层，源文件始终为标准 Markdown 纯文本（导出无损、插件可处理）。
- **笔记管理**：文件夹体系 + 置顶 + 归档/回收站（长按）+ 全文搜索 + 排序（更新/创建/字数）+ 图片笔记。

### 模块 4 · 阅读笔记
书库（在读/想读/已读/弃读）、原文摘录+感想、划线颜色分类、书籍标签搜索、一页式总结；**外部导入**：Markdown/TXT/HTML/CSV·JSON（Notion/Obsidian 等）、微信读书（第三方导出解析，字段映射预览）、Kindle `My Clippings.txt`；Evernote(.enex) V1.x；按"书名+原文哈希"去重；导出为 Markdown。
- **阅读计时（V1.11）**：书籍详情页「▶ 开始阅读」一键计时，**悬浮计时条常驻**（跨页面不中断）；看完点「结束」→ 弹出进度录入；也可不走计时直接手动补记。
- **多方式进度录入**：页数区间（132→320页）/ 百分比 / 章节（自动匹配目录）；观影同构：时间点 / 百分比 / 集数（第 5/12 集）；保存后计算本次时长、阅读速度（分钟/页）。
- **耗时统计与预估**：累计总耗时（书级/周/月）、计时次数、均速节奏、**预计剩余耗时与预计读完日期**（按当前进度节奏动态重算）；阅读时长自动写入时间账本「阅读」分类（L4），计入周报与目标进度（L7）。
- **目录体系**：每书目录（章/节两级）：手动维护 / **AI 补全**（按书名作者生成标准目录待确认，属 AI 能力矩阵）/ **导入解析**（微信读书导出含目录节、calibre epub toc.ncx、MD·TXT 每行一章自动识别；按 ISBN 查在线书目库 V1.x）；目录节点标记状态（已读/在读/未读 + 摘录数），点击直达对应笔记。
- **豆瓣书单导入（V1.11）**：导入向导新增「豆瓣 · 书单/片单」源：解析导出文件（第三方导出工具数据或网页导出），导入 已读/在读/想读 标记 + 豆瓣评分 + 标记日期；去重：ISBN → 豆瓣 subject_id → 书名+作者哈希；写入后保留来源标记可批量撤销。排期 V1.0。

### 模块 5 · 收集箱 / 碎片笔记
通知栏/桌面快捷 3 秒记录；每条分流为 待办/日记片段/笔记/阅读摘录；定期清空提醒。

### 模块 6 · 今日仪表盘
首屏：今日日程时间轴+待办进度环+连续记录天数+阅读摘录+心情一键打卡+**今日持有成本卡**；今日小结分享卡片；自动周/月报。
- **主页模块自由编排（V1.10）**：主页所有卡片模块（概览卡/心情/今日日程/收集箱快捷/时间分布/功能宫格等）**顺序完全自由**：「⇄ 编排」模式进入后支持长按拖拽排序与 ↑↓ 微调，卡片描边虚线提示可拖动；退出即自动保存布局并持久化，下次启动保持；设置页提供「主页模块顺序→去编排」直达入口；后续可扩展「重置布局/卡片显隐开关」。

### 模块 7 · 目标与 OKR
年度/季度目标 + 2~4 个 KR（百分比/数值）；关联任务/阅读/日记自动汇聚进度；季度复盘引导（KPT）；目标数量上限提醒。完整版 V1.x。

### 模块 8 · 记账 / 财务简账
收支快速记账、分类、预算（超支提醒）、周期账单、月度报表/饼图/现金流；订阅支出→续费提醒日程。基础 V1.0，预算报表 V1.x。
- **账单导入（V1.9 新增）**：**支付宝 / 微信支付**账单 CSV 自动解析导入：
  - 引导文案内置（两平台导出路径步骤提示）；两平台导出均为 **zip 加密包**，导入时输入申请时设置的解压密码；
  - 自动识别支付宝（18 行表头前缀）/微信（17 行）元数据结构与列布局，字段映射自适应；
  - **去重**：交易单号唯一键优先，缺失时按「时间+金额+对方」哈希兜底，重复项自动跳过可预览；
  - 分类自动映射（支付宝交易分类/微信交易类型 → 应用分类，未命中进「其他」可改，可叠加 AI 辅助归类）；退款冲抵记为负支出；代付/转入等非支出流水可选跳过；
  - 导入预览（条数/重复/将写入）+ 向导式四步流程；**整批导入记录支持一键撤销**；全程本地解析不上传；导入后可衔接物品建档（L12）。
  - 排期：随基础记账同入 **V1.0**。

### 模块 9 · 物品价值 / 每日成本核算
物品档案（名称/分类/品牌/照片/购入日期/价格/预期年限/保修/状态）；**每日成本引擎**（直线法默认：`(价+二次付费−残值)÷持有天数`，实时重算+成本流水时间轴；按次均摊/预估止损 V1.x）；**生命周期操作**：二次付费（计入成本池，摊回全周期或重算）、回收（残值扣减，生成净持有成本决算，可继续留用或转出）、报废（停止计费，冻结决算，转历史库，二次确认+审计）；统计（今日合计持有成本、Top N、分类占比）；与记账/到期提醒/日程联动。

### 模块 10 · 影音游（生活记录）
电影/剧集/动漫/综艺/游戏/播客的内容打卡记录，评分 + 一句话短评 + 长评（可关联笔记）。
- **与阅读笔记完全同构（V1.11 强化）**：观影计时（开始/结束，含倍速记录）、多方式进度（时间点/百分比/集数）、累计观影时长与年度统计（本年 86h/41 部级）、预计剩余时长；时长写入时间账本「娱乐」分类（L4/L9）。
- **豆瓣片单导入**：与书单共用导入向导（想看/在看/已看 + 豆瓣评分 + 标记日期，去重同上）。
- 排期调整：因与阅读同构复用度高，**电影/剧集基础版（计时+进度+评分+片单导入）提前至 V1.0**；游戏时长同步、剧集追更提醒、播客保持 V1.x。

### 模块 11 · 重要日子与提醒
纪念日/生日/倒数日（**支持农历**）、多级提前提醒、首页倒数卡；证件/订阅/保修到期统一提醒中心；关联当年日记、准备事项转待办。农历倒数日+生日提醒 V1.0，证件到期 V1.x。

### 模块 12 · 健康管理
极简记录：喝水、睡眠（时长+质量）、运动、用药；趋势图（热力图/曲线）；运动写入时间账本、睡眠进仪表盘/周报。睡眠+喝水 V1.0，运动/用药 V1.x。

### 模块 13 · 人生看板 / 领域轮盘
自定义人生领域（健康/事业/学习/财务…），各领域得分由其他模块数据自动汇聚，雷达图呈现平衡度，季度复盘对照。V2。

### 模块 14 · 小工具合集 ⭐ V1.7 新增
首批 10 个工具，全部本地计算、离线可用、无广告：
- **网络**：Ping 工具（主机/次数/结果统计可分享）· 网络测速（下载/上传/延迟/抖动，多节点）
- **长度**：尺子（按设备 DPI 校准 + 银行卡校准引导）· 测距（离线地图比例尺点选 / GPS 轨迹双模式）
- **随机**：轮盘抽签（自定义选项，结果可写入日记）· 随机数（区间/个数/骰子硬币预设）
- **色彩**：取色盘（HEX/RGB/HSL 互转，屏上取色，最近取色收藏）· 颜色互补色（互补/类似/三角配色盘，一键复制）
- **计算**：日期计算（间隔天数/日期±N，支持农历）
- **图片**：图片体积缩小（本地压缩：质量/最长边/格式，可批量）
- **插件式拓展机制**（产品差异化能力）：
  - 插件规范：`plugin.json`（名称/版本/图标/入口/权限声明）+ HTML/JS 工具页，打包 zip
  - 本地拓展：将插件包放入应用私有 `plugins/` 目录 → 自动扫描加载出现在「拓展工具」列表，可启停
  - 在线拓展：填入 **GitHub Release 等下载链接** → SHA-256 哈希校验 → 自动下载安装
  - 安全：插件沙箱运行，默认无网络/无用户数据访问，敏感权限需用户逐项授权；插件列表随备份/同步导出
- 排期：基础内置工具（日期/随机/轮盘/取色/图片压缩）V1.0；Ping/测速/尺子/测距与**插件机制完整体** V1.x。

### 模块 15 · 母婴呵护 ⭐ V1.13 新增
双主页结构：「🌸 她 · 生理周期」/「👶 宝宝 · 喂养」。
- **她（女性：排卵/经期记录）**：周期阶段卡（周期天数/当期阶段）；**自动预测**下次月经、排卵日（下次经前 14 天）、易孕窗口；周期日历着色（月经/排卵/易孕三区 + 可点击补录改状态）；每日记录：经量分级、症状多选标签（痛经/情绪/食欲等 8+ 预置可自定义）、体温（V1.x）、备注；统计：平均周期/平均经期/最长最短/波动规律度（异常波动超 ±7 天温柔提醒就医参考，非诊断）；三类提醒（来潮提前 N 天/排卵日/易孕开始）；AI 周期趋势解读（V1.x，挂 AI 矩阵，仅发聚合数据）。
- **宝宝（婴儿喂养记录）**：多宝宝 + 记录人身份（妈妈/爸爸/长辈，每条记录留痕）；**八类一键记录**：哺乳（**左右侧切换计时**，结束生成分段记录 左x′/右y′）、配方奶（ml/温度/距上次喂养间隔）、补剂（D3/剂量，每日提醒自动打卡）、尿布（尿/便，布里斯托分级，可关联称重联动体重曲线）、睡眠（入睡/醒来计时，自动关联吃-睡间隔）、游戏（亲子/俯卧等，里程碑打点 V1.x）、测量（体重/身高/头围）。
- **数据一览**：今日记录流（时间轴卡片可删改）；**生长曲线**（WHO P3/P50/P97 百分位带，三曲线切换，跨 2 带偏离预警）；疫苗计划表（计划/已种/凭证照片，「完成」自动生成下次接种提醒）；近 7 天概览双柱图（喂养次数/睡眠时长）；周报纳入喂养规律分析。
- **联动 L15**：哺乳/睡眠计时复用日程进行中基础设施与悬浮计时条；时长写入时间账本（L4）；疫苗/下次经期预测自动入「重要日子」倒数与提醒（L10）；异常记录可一键生成待办（如「预约体检」）。
- 隐私：周期/健康数据属敏感类，默认本地 + 备份加密覆盖；同步可选排除母婴数据。
- 排期：整体 **V1.x**（计时基础设施随 V1.0 就绪，接入即可）。

## 四、通用与非功能

- 提醒通知：日程/任务/（番茄钟）；早间简报、晚间复盘、免打扰时段。
- 全局搜索：一入口搜遍全模块。
- 数据安全：应用锁（PIN/生物识别）、本地备份恢复、导出 JSON/CSV/Markdown、WebDAV 同步（手动+可选仅Wi-Fi自动；冲突逐条选择；保留 N 份历史快照可回滚；可选口令加密）。
- 个性化：浅/深/跟随系统、主题色、字号、桌面 Widget（后期）。
- **主题系统（V1.14 增强）**：内置 **7 套**整体风格（简约/小清新/复古/轻拟态 + 🌙赛博朋克(霓虹紫青渐变+发光边框+网格纹理·强制深色)、🍂秋日暖调(焦糖琥珀+暖黄底+衬线字体)、🌊海洋深蓝(深海蓝渐变+白卡+波浪光晕)）；**主题即配置文件**：设计令牌 json（themes/ 目录，含亮/暗双态、纹理、字体），**热加载无需刷新**，与深色模式正交；设置页「🛍 更多主题」主题市场演示拉取→签名校验→应用全流程（社区主题：樱花粉系/薄荷抹茶/石墨黑白）。
- **FAB 按需显示（V1.14）**：移除全局固定展示——仅在具备添加能力的页面显示对应语境 FAB：仪表盘悬浮球菜单（快速记录）、收集箱⚡聚焦输入、待办＋新建任务、日程📅新建、记录✎（随日记/笔记/阅读 tab 语境变动作）、记账💰、物品📦、日子🎂、习惯＋、健康💧快捷计水；无添加能力页（目标/设置/详情页等）自动隐藏。
- **设置信息架构（V1.14 二级化）**：「我的」一级页仅保留——资料/统计概览/二级入口列表（数据与同步、提醒通知、AI 增强、小工具，带状态摘要）/主题风格/导航自定义/关于；长配置项全部下沉为独立二级子页，消除单页过长滞动负担。
- **主题风格（4 套整体换肤）**：通过全局设计令牌（CSS 变量）一键切换整体观感，非仅换主色；与深色模式正交叠加。
  - **简约（默认）**：白/深蓝底、轻阴影、圆角 20px，现有风格。
  - **小清新**：青绿→青→蓝渐变、更柔背景、大圆角 26px、低饱和。
  - **复古**：米黄纸张底、棕橙渐变、硬边投影（offset 实色）、小圆角 12px、切换为衬线字体（Georgia/宋体）。
  - **轻拟态**：卡与背景同色、无描边、双向柔光投影（左上白/右下灰）、内嵌渐变。
  - 入口：设置页主题风格选择器 + 桌面预览侧栏；选择结果持久化（模拟）。
- **底部导航栏（简约线性图标 + 文字在下）**：可自定义——设置页对全部栏目（今天/待办/日程/记录/收集箱/记账/物品/日子/健康/目标/我的）开关，**最多同时启用 5 个**，「今天」「我的」固定不可关；顺序按模块池固定序自动排列；配置持久化。图标统一为细线条（stroke 1.8）素色风格，选中态主题色 + 顶部小横条指示。
- 性能：冷启动 ≤2s、列表流畅、图片压缩；离线全功能；导入解析失败容错入库为普通笔记；WebDAV 走后台 isolate 不阻塞 UI。
- 隐私：V1 无网络上报（同步除外）；权限最小化；同步加密可选但首配强提示。

## 六、AI 增强能力（V1.8 调研结论 · 跨模块可选能力）

### 设计原则
1. **默认关闭、显式 opt-in**：总开关 + 能力矩阵逐项授权，未开启时全应用零 AI 请求；
2. **Key 本地化**：API Key 存系统级加密区（flutter_secure_storage），不入备份明文、不落日志、不随 WebDAV 同步；
3. **端点自治**：仅请求用户配置的 Base URL（OpenAI 兼容 Chat Completions 协议），应用自身无任何埋点上报；
4. **数据最小化**：每个功能只发送必需字段，发送前弹层展示完整发送内容可审阅；日记/财务/物品等敏感数据支持「仅摘要发送」模式；
5. **AI 结果透明**：所有 AI 生成内容带标识，写入数据前需用户确认；周报点评只发聚合统计不发原文；
6. **全离线选项**：支持 Ollama 本地模型端点，满足无云需求。

### 预置服务商
DeepSeek / OpenAI / Moonshot Kimi / 通义千问 / 智谱 GLM / Ollama（本地）/ 自定义（OpenAI 兼容）。
