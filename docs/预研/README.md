# 预研目录

存放**功能立项前**的技术预研：可行性验证、方案对照、量级测量（体积/功耗/内存）、原型脚本与演示面板。与 `docs/` 根下的「开发计划书 / 需求清单 / 批次计划」区分开——这里是"还没拍板做什么"阶段的证据，那里是"已决定怎么做"阶段的规范。

## 约定

- 每个课题一个子目录，命名 `主题-短名/`，内含：
  - `预研结论-YYYYMMDD.md`：主文档，必须包含素材画像、量化对照表、明确的「采纳/否决/未决」三段；
  - `code/`：可独立运行的复现脚本（头部注释写明运行方式与依赖）；
  - `panels/` 或 `artifacts/`：演示面板、截图、样例产物（外部大素材不拷入，写清原始路径）。
- 结论被 PRD/计划书采纳后，在本目录对应文档头部标注「已采纳 → 去向」，文档本身保留不删（决策证据）。
- 复现脚本允许是任意语言（Python/Node 均可），但必须与项目构建隔离、不进 lib/tools 生效路径。
