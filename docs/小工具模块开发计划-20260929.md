## 0. 已拍板口径（2026-09-29 产品确认）

1. **一期范围**：13 个内置工具 + 三屏（首页控制盘 / 工具管理 / 使用统计）先全量做实；插件中心走**本地 `plugins/` 目录扫描 + WebView 沙箱 + 启停/详情/权限审计**；**在线六步安装（GitHub index + SHA-256 下载）单独最后一批**，真机验证过再收口。

## 1. 数据模型（批0 落库）

| 表 | 列 | 说明 |
|---|---|---|
| `kit_usage` | `id` INTEGER PK AUTOINCREMENT · `tool` TEXT · `kind` TEXT(builtin\|plugin) · `ts` INTEGER | 足迹流水，一条=一次使用（原型 `{k,ts}` 同构）；统计页热力/分布/Top8 全部由它实算 |
| `kit_layout` | `key` TEXT PK · `value` TEXT(JSON) · `updated_at` INTEGER | `fav` / `hidden` / `order` / `recent` / `hero`（四枚数据位） |
| `kit_tool_data` | `tool` TEXT PK · `data` TEXT(JSON) · `updated_at` INTEGER | 工具私有参数与留痕：轮盘多套数据与权重、提词器五项、尺子银行卡校准倍率、最近取色、随机数历史、测距模式、测速留档 |
| `kit_plugin` | `id` TEXT PK · `name` · `ver` · `src`(local\|github) · `size` INTEGER · `perms` TEXT(JSON) · `granted` TEXT(JSON) · `enabled` INTEGER · `installed_at` · `updated_at` · `audit` TEXT(JSON 时间线) | 插件登记与权限授予、审计时间线；`plugin_` 前缀表空间规范（`DbSchema.pluginPrefix`）留给插件自带数据表 |

迁移：`lib/core/database/schema/kit.dart` 内 `mig = {27: [...kitSchemaStatements]}`，`DbSchema.version` 27→28。

## 3. 分批

- **批0 地基**：农历提升 shared（含 days 改引 + 守护用例）· DB v28 四表 + 迁移 · kits 模块骨架（providers/routes/NavModule 入池/宫格与设置页入口接线）· `kit_schema_test`。
- **批1 首页控制盘**：hero 四枚数据位（实算 + 草稿保存制配置弹层）· 收藏/最近/插件/统计四入口 · 分类 chips + 搜索 + 空态 · 合并单网格工具卡（每行 5 枚）· 使用足迹落库 · 模块设置弹层四开关。
- **批2 工具屏 A（计算/随机/色彩）**：日期计算（含农历换算）· 随机数 · 轮盘抽签（多套 + 权重 + 批量粘贴 + 结果写日记联动）· 取色盘（图片导入取色 + 全屏舞台）· 互补色色相环。
- **批3 工具屏 B（网络/长度/图片/编码/演示）**：Ping · 网络测速 · 尺子（**全屏舞台 + 可滑动游标与零点**，DPI 实测 + 银行卡校准）· 测距（地图比例尺点选 / GPS 轨迹）· 图片体积缩小 · Base64 转换（图片 + 文本）· 提词器（参数五项 + LED 点阵）· AI API 验证（走 `aiRunWithReview`/`verifyEndpoint` 既有通道）。
- **批4 管理屏 + 统计屏**：工具管理（★ / 排序 / 隐藏 / 已隐藏区 / 恢复默认编排）· 使用统计（17×7 热力 + 分类分布 + Top8 + 插件用量 + 分享长图）· 足迹清空二次确认。
- **批5 插件中心**：私有 `plugins/` 目录扫描 · 包规范解析（manifest + sha256）· WebView 沙箱加载与能力桥 · 启停/详情/权限逐项授权/审计时间线 · N-1 回滚。
- **批6 在线安装（单独一批）**：GitHub Release index · 六步向导 · 下载与哈希校验 · Wi-Fi 开关门控 · 失败归因。
- **收口**：全量门禁（`bash tools/run_gate.sh`）· release 三包 · 真机 adb 逐屏走查 · 双端 push + 预发布挂 APK（**均需产品负责人明确授权**）。

## 4. 红线与验证口径

- 隐私：除 AI API 验证按用户填写端点真实发请求外，其余工具 **100% 本机计算**；页脚统一「本地计算 · 抓包 0 请求」口径照原型。
- 架构：R1（feature 不互 import，跨模块走 `shared/`）· R3（domain/data 不 import presentation）· R7（AI 能力一律 `aiRunWithReview`）· 禁 emoji 图标（全走 `IconData`/自绘）· 禁系统取色器与系统日期控件（走应用内滚轮/色板，照 V1.47 真机轮2 拍板）· 弹层与页面零 `BackdropFilter`。
- 每批验证：`flutter analyze` 零新增 + 本批新增用例绿 + 受影响既有用例绿；收口批跑全量门禁。**widget 测试禁真实异步 I/O**（图片/网络一律注入 fake），全 app 用例一文件一个。
- UI 保真：开发对齐原型，若实现中需改 UI/交互，**先改 `prototype/index-kits.html` 并经产品确认再动 Dart**（专版唯一写者约定仍生效）。
- A4 挂起项（专版共享面回灌）不阻塞本计划：Flutter 侧的宫格/我的页/设置页以 `index.html` 最新定稿为对齐目标，随主原型 R14 批次收口再核一遍。
