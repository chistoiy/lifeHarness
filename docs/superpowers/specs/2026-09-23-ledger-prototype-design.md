# 记账模块高保真全家桶 · 设计规格（index-ledger.html）

- 日期：2026-09-23
- 状态：已与用户逐节确认（范围=完整全家桶；交互=全功能可操作；入口=复制 index.html 壳层）
- 产物：`prototype/index-ledger.html`（记账专版原型）；需求回写 `docs/需求清单.md` 模块 8；开发计划另立文档

## 1. 目标与定位

把现原型中仅一屏的记账（P6 + 账单导入 P6b）升级为**成熟记账 App 级别的完整模块**，对标小星记账等主流记账产品的功能形态：速记体验、多账户资产、两级分类、预算体系、统计报表、周期账单/订阅、心愿单、借贷、标签、结转、搜索、导出。原型为单文件 SPA、内存态数据、全功能可操作（记一笔后流水/合计/预算/环图/余额五处实时联动），刷新回演示种子数据。

## 2. 壳层与入口

1. 完全复制 `prototype/index.html`（今日仪表盘、底部导航、模块池、FAB、全局返回栈、暗色/主题系统、全局搜索）。
2. 原位删除 P6 记账与 P6b 账单导入两个 section 及其专属 JS；新记账套接管 `p-finance` 路由键（主页宫格「记账」、模块池、底栏可配置项、搜索 scope「记账」全部保持可达）。
3. 入口三条：
   - 主页宫格/模块池「记账」→ L1 记账主页；
   - 仪表盘 FAB「记一笔」→ 速记半屏弹层（S1）；
   - 全局搜索 scope「记账」→ L12 搜索。

## 4. 数据模型（内存对象，镜像未来 Drift 表）

```
txns      { id, kind: expense|income|transfer|refund|adjust, amount, catId, subCatId,
            accountId, toAccountId?, date, note, tags[], source: manual|bill|recurring|wish|debt|item|read,
            linkId?, refundOf?, createdAt }
accounts  { id, type: cash|debit|credit|ewallet|lend|other, name, balance,
            creditLimit?, billDay?, repayDay?, iconKey, color, archived }
categories{ id, parentId?, kind(树归属), name, iconKey, color, hidden, order }
budgets   { month:'YYYY-MM', total, perCat:{catId:amt}, carryEnabled }
recurring { id, name, amount, catId, accountId, freq: daily|weekly|monthly|yearly,
            nextDate, active, note }
wishes    { id, name, target, saved, doneTxId? }
debts     { id, side: lend|borrow, person, total, paid, note }
tags      [ { id, name } ]
settings  { hideAmounts, defaultAccountId, monthStartDay, confirmDelete, ... }
```

## 5. 联动回算引擎

- 所有写操作统一走 `writeTx / editTx / deleteTx`，完成后同步重算：账户余额、月/日合计、预算进度、分类占比、统计图、主页三数（记一笔→五处联动）。
- 转账不影响支出合计，只移动余额；退款为负支出并冲抵分类；周期账单「生成到期」批量写流水并推 nextDate；余额修正生成 adjust 流水。
- 与其他模块的联动在本原型中用**来源徽标 + 说明行 + 跳转占位**表达：L8 订阅→日程、L12 流水⇄物品、L4 阅读计时流水、心愿→支出。不真跳其他模块页（壳层中原型页保留原样即可）。

## 6. 视觉与文案规则（项目既定约定）

1. 分类与功能图标一律**线性 SVG**（stroke 1.8、currentColor），禁止 emoji；分类用色底圆点+白线图标。
2. 无教学性说明文案，只留功能标签与状态提示。
3. 时间/金额选择一律**就地内嵌滚轮**，禁止两段式「点击→弹层→再操作」。
4. 跟随 index.html 的 indigo 品牌色、暗色模式、卡片与圆角语言。

## 7. 验收口径

- `node --check`（提取 script）语法零错误；
- 无头浏览器深链逐屏 `gotoPage` 渲染断言 + 截图；
- 核心闭环脚本断言：记一笔五处联动、删改回算、周期生成、预算超支变红、转账只动余额、退款冲抵；
- 交付后用户逐屏真机/浏览器验收（既定流程）。
