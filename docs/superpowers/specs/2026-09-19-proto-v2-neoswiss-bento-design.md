# LifeHarness 原型 V2（index-v2.html）· 新瑞士便当格 全量重制设计文档

日期：2026-09-19 ｜ 状态：**已获产品方批准**（设计语言选 A · 新瑞士·便当格；范围与规范照本案执行）

## 1. 背景与目标

- 现有高保真原型 `prototype/index.html`（壳 V1.3，需求迭代至 V1.26.2，约 350KB）保持**一行不动**。
- 本任务在**其之外**新做一份单文件 SPA 高保真 UI 原型，保存为 `prototype/index-v2.html`，目的：
  1. 以**全新设计语言**重绘全部 14 个模块，为产品方提供设计灵感对照件；
  2. 全量覆盖需求 V1.26.2 的页面、控件、状态交互与页面跳转模拟。
- 仅 UI 交互原型：涉及数据的一律内存数组占位模拟（刷新即重置），不做底层业务逻辑。

## 2. 技术约束（硬边界）

- 单 HTML 文件，CSS/JS 全内嵌；外部依赖仅 **Tailwind CSS CDN + Google Fonts Inter**（中文回退 PingFang SC / Microsoft YaHei）。禁止重型第三方 UI 组件库、禁止图标库 CDN（图标全部手写内联 SVG，stroke 1.8）。
- 本地双击浏览器直接运行，无需后端；`node --check` 可过语法校验（提取内嵌 script 校验，本项目历史踩坑项）。
- 持久化仅限：底栏导航配置 / 仪表盘卡片顺序 / 深浅色偏好 → localStorage；其余全部内存态。

## 3. 设计语言 A · 新瑞士便当格（Neo-Swiss Bento）

### 3.1 令牌（CSS 变量，深/浅双模；多主题市场仅占位入口）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--paper` | `#F6F5F1` | `#0D0D0B` | 页面底（暖纸白/近黑） |
| `--card` | `#FFFFFF` | `#161613` | 卡片面 |
| `--ink` | `#141414` | `#F2F1EC` | 正文/标题（近黑墨） |
| `--ink-2` | `#6B6A64` | `#9C9B93` | 次级文字 |
| `--line` | `#E3E1D8` | `#26261F` | 发丝线/卡描边（1px，替代阴影） |
| `--accent` | `#FF4A1F` | `#FF5C33` | 信号橙红：唯一强调色（选中/主按钮/当前日/进度） |
| `--ok` / `--no` | `#1E874B` / `#C0392B` | 提亮一档 | 完成/负向语义 |
| 分类色板 ×8 | 低饱和克制多色（陶土/苔绿/板岩蓝/芥黄/灰紫/砖红/橄榄/青瓷），亮暗双值 | 同左 | 时间块/事件/象限共享同一分类表 |

### 3.2 形态规则

- **圆角**：卡片 10px、控件 8px、chip 胶囊；**无软阴影**，层次靠 1px 发丝描边 + 底色差；仅 hero 卡可选 4px 硬偏位移投影（`box-shadow:4px 4px 0`）作点缀。
- **排版**：数字一律 Inter 700/800 + `tabular-nums`，大号统计数字（32–44px）+ 小字标签上置（新瑞士标签风）；正文 13–15px；标题 `tracking-tight`。英文小写标签（如 `TODAY` `FOCUS`）作卡片 eyebrow 点缀。
- **便当格**：仪表盘与模块首页用 2 列 bento（hero 卡跨 2 列），卡内留白充足、信息密度靠对齐网格（8px 基线）。
- **底栏**：5 项细线条图标 + 文字在下，选中态 `--accent` + 图标上方 3px 短横指示（延续既有底部导航视觉规范）。
- **FAB**：按语境显示（仅可添加页），样式为方形圆角 8px 墨黑底＋＋白号，弱化悬浮感；无添加能力页隐藏。
- **动效**：150–200ms ease，视图切换/卡片进场仅做轻量位移淡入；禁止炫技动画。

## 6. 实现结构（单文件内部骨架）

- `<style>`：令牌 + 滚轮/便当/日历等 Tailwind 不便表达的自定义类。
- `<body>`：手机壳（390×844，桌面居中展示）+ `#app` 页面容器 + 底栏 + sheet/toast/计时条挂点。
- `<script>`：`DB`（内存数据集）→ `UI`（sheet/toast/wheel/icon 基建）→ `PAGES`（页面注册表：render + mount）→ `go(route)` 路由 + `setSess` 会话态；事件用容器级委托，避免重复绑定泄漏。
- 交付批次：骨架与基建 → 仪表盘/待办 → 时间 → 记录 → 其余模块 → 我的/设置/插件 → 全量走查 + `node --check`。
