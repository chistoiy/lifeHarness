## 4 · 批4 AI 精化（门控与真请求两态）

**A 态：AI 未开启（关掉总开关或没配 Key）**

- [ ] ⋯菜单点「X-Ray 精化」→ **只出 toast「AI 未启用：…」，不弹预检卡、零网络请求**
- [ ] 日志页可见「AI 零请求被拒」；AI 使用记录里有一条被拒留痕（能力点 `read.xray_refine`）

**B 态：已配 DeepSeek Key 且能力矩阵开启**

- [ ] 预检卡三数对得上账：候选条数＝本书词条数；预计批次数随「单请求字符预算」五档切换**实时变大/变小**
      （1000 字档批数应明显多于 8000 字档；预算改小批数不变＝联动假绿）
- [ ] token 估算数量级合理（≈字数÷1.5），且开跑前不发送任何请求
- [ ] 点「开始精化 · N 批」→ 预检卡收起，**面板 X-Ray 段顶部出现进度卡**（不遮正文、不打断翻页）
- [ ] 「暂停」→ 文案「已暂停 · 断点在第 x 批」，钮变「继续」；继续能接着跑（不是从头再来）
- [ ] 跑完 → 「N 批跑完 · 建议 M 条」+「查看汇总」；审阅三段＝建议删除/改类/补词，**默认全勾**
- [ ] 取消勾选一条 → 底部「确认写入 M-1 条」同步掉数；写入后该条**不落库**
- [ ] 写入范围「仅本书 / 升级为全局」二选有效：选全局后，词库管理页该词来源显示 GLOBAL
- [ ] 写完词库管理页能查到新词，且再点「导出养成词库」时 `.xrwords` 里带上它（批3/批4 闭环）
