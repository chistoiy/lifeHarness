## 一、原型三屏（逐屏看点）

深链：`?xr=ai`（预检卡）、`?xr=airun`（面板内逐批进度态）、`?xr=airev`（汇总审阅弹层）。入口＝阅读器 ⋯ 菜单新增行「X-Ray 精化」，右侧状态字 `brMoreXrAi` 随写入结果变「AI · 已写 N 条」。

1. **预检卡 `sheetXrAiPre`**：标题「AI 精化」+ 角标能力点 `read.xray_refine`；一行三数＝**候选条数 / 预计批次数 / 约 N tokens**；下方**单请求字符预算五档 chips**（1000/2000/3000/5000/8000，默认 3000，就地选、点了立刻重算批次数——预算调小批次必变多，这是需求拍板④「每请求体量必须可控」的可见化）；主钮「开始精化 · N 批」，取消钮；脚注一行：确认后将**逐批顺序请求**，未配 Key 或离线时**不出现本入口**。
2. **面板内进度态**：进度条**嵌在 X-Ray 段内容区顶部**（`#xrAiBar`，不另开页面、不弹全屏遮罩，不打断阅读）；文案「AI 精化 · 第 b/n 批」，条宽＝批次进度；右侧「暂停」↔「继续」就地切换，暂停 toast 报**断点在第几批**；演示链上第 4 批失败 → 条下出一行「第 4 批失败 · 已重试后跳过，后续批次继续」（单批失败不拖垮全书）；跑完转「N 批跑完 · 建议 7 条 + 查看汇总」。
3. **汇总审阅弹层 `sheetXrAiReview`**：三段分组＝**建议删除 / 建议改类 / 建议补词**，每条一行（词 · 理由 · 目标类型），默认全勾、点行勾选/取消，底部按钮实时显示「确认写入 N 条」；**写入范围二选 chips**＝「仅本书」（默认）/「升级为全局」；「先不写」关弹层不产生任何写入。写入后词库管理页与 `.xrwords` 导出即带走这批数据（与批3 同一条路）。
