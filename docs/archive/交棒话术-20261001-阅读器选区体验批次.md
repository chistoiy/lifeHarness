## 二、本批规格（6 项）

### ① 头手柄跨段/跨页扩选卡住（bug 级，可优先，不依赖新原型）
- **现象**：拖首手柄往上一段/上一页，端点偶发冻住，放大镜（焦点=anchor）一起定格。
- **根因**：翻页模式 `_stage` 只渲染当前页的段（`pages[pg]`），滚动模式只渲染窗口段；上一段未渲染 → `_paraRender` 返回 null → `_paraHitAt` 抓不到新段、`_selAnchor` 返回 null。
- **落点**：`reader_page.dart` `_flip`/`_ensureCur`、`reader_sel_ops.dart` `_dragSel`/`_paraHitAt`/`_selAnchor`、`reader_stage.dart` 渲染窗口。
- **方案（待确认）**：拖到页首/页尾边界时自动 `_flip` 翻页并延续扩选（跨页选区需把 `ci` 也纳入，`_sel` 目前是单章 `ci` + 段区间，跨章要扩模型）。工作量最大，建议单独子批。

### ② AI 解读二选一 + 新「解释」任务
- **现状**：工具条「AI 解读」→ `_actAi`（`reader_sel_ops.dart:395`）直接 `aiRunWithReview(taskId:'read.quote_insight')`（=摘录感想生成）。
- **目标**：点「AI 解读」→ 先弹底部二选一「解释词句 / 深度解读」→ 选后进审阅 → 发送 → 结果。
- **新任务**：`prompts.json` 加一条（建议 `read.explain`，module 阅读，placeholders `['text','book']`，expect text/json 待定）；`ai_page.dart:41` 阅读分组 `tasks` 加 `'read.explain'`；`ai_validate.dart:60` 加 case；测试 cap `test/ai_wire_read_test.dart`、`test/reader_select_test.dart:438` 的 `ai.caps` 加键。
- **原型**：二选一弹层 + 结果弹层形态先改 `prototype/index.html` 阅读器屏，经确认。
- **prompt 内容**：「解释」= 对选中词/句给释义+背景+简析（区别于「感想」）；文案我起草后你定稿。

### ③ prompt 全局默认折叠
- **现状**：`ai_review.dart` 的 `aiRunWithReview` 审阅弹层已完整展示 System/User（`_Box(system)`/`_Box(user)`），是**全模块共用**。
- **目标**：System/User 默认折叠，点击展开（`ExpansionTile` 或自建折叠）。一处改，所有模块审阅一致。
- **风险**：R7「发送前审阅」精神是让用户看到发什么；折叠后仍可展开，需确认不违背守护用例（`architecture_test` 对 `aiRunWithReview` 的断言）。
- **原型**：折叠态/展开态先在任一 AI 审阅弹层原型体现。

### ④ 长按选字/选句开关进设置
- **现状**：长按固定 `_sentenceAt` 命中整句。
- **目标**：设置项「长按选择粒度」，默认**选字**（命中单字/可扩），可选**选句**。落 `read.brSelGranularity` 之类 KV；`_selectPara`/`_extendSelTo` 按开关决定命中粒度。
- **落点**：设置页（阅读组，参照 `read.brSync`/`read.brMinSecs` 的 `readKvProvider` 模式）+ `reader_sel_ops.dart`。
- **原型**：设置项行 + 选字态长按表现。

### ⑤ 工具条工具排序 + 显隐
- **现状**：`reader_sel_layer.dart` `brSelLayer` 里 8 个 chip 硬编码顺序（复制/划线/写想法/书摘/查询/听当前/AI解读/分享）。
- **目标**：设置里可拖拽排序 + 开关每个工具是否上工具条；KV 持久化（参照主页编排 `home_order` 的做法）。`brSelLayer` 按配置渲染。
- **落点**：`brSelLayer`、设置页新增「选区工具条」管理子页、KV。
- **原型**：管理页 + 工具条按配置渲染。

### ⑥ 系统打开 EPUB → 导入/已导入跳书架
- **目标**：文件管理器/其它 app 用「打开方式」选本 app 打开 `.epub` → 走导入；若该书已导入（按路径/哈希/书名匹配）→ 提醒「已导入」并跳书架页定位并高亮该 epub。
- **落点**：`android/app/src/main/AndroidManifest.xml` 加 `<intent-filter>`（action VIEW/SEND，`<data mimeType="application/epub+zip">` + 文件扩展名）；接收 URI 的入口（`MainActivity`/深链 → go_router 路由）；复用 `EpubImportService`（`lib/features/read/data/epub_import.dart`）导入；已导入判定查 `Book`/`EpubRef`；跳书架 `context.go` 带定位参数。
- **风险**：Android 平台集成，**必须真机验证**（content:// URI 权限、持久化 URI 授权、HyperOS 差异）；导入校验口径（按什么判「已导入」）先与你确认。
- **原型**：无 UI 新增则跳过原型，但导入确认弹层/已导入提示条要按 UI 规范。
