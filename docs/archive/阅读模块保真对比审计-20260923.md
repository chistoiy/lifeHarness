## 二、🐞 疑似 bug（建议最优先修）

1. **复习「记得」档 toast 拼接重复**：实际输出「7 天后**后**延长」。`read_sheets_b3.dart:884` 的 `$l后延长` 中 `_label` 已含「天后」。原型 4869＝「7 天后延长」。
2. **收集箱→摘录分流后列表不刷新**：`inbox_page.dart:139` 分支 `return` 在 `ref.invalidate(inboxItemsProvider)`（:141）之前，条目残留在未整理列表。
3. **设置页 simple/fullCh 默认显示"开"与实际行为"关"矛盾**：原型 BS_SET(4528) 二者默认 false；`read_settings_page.dart:323` 的 `_def` 兜底 `'true'`，而消费端（`quotes_lib_page.dart:75,355`）默认 `'false'` → 首开设置页状态失真、开关看似生效实则未落库前行为相反。
4. **read.openTab 默认值未生效**：原型 bsInit(5878) 强制按 BS_SET.openTab='在读' 进入书架；`shelf_page.dart:116-128` 仅当用户显式存过 kv 才生效，未设时落「全部」，与设置页展示的默认「在读」不一致。

## 三、❌ 功能缺失 TOP（按屏）

### 工作台 + 书架
- 批量管理工具条缺「**加标签 / 删除 / 取消**」三钮（原型 849-855）；批量删除的「笔记与时长保留 30 天」承诺无处兑现；移分区按钮原型为「循环到下一分区」。
- **时间线视图缩水**（原型 4597-4610）：缺评分事件、计时会话事件（读了 N 分钟·P起→止）、日头「· N 条」、每卡图标+书名·作者副行、尾部「共 N 条 · 显示最近 N 天 · 范围可在阅读设置里调」说明。
- 列表视图：缺在读行「开始/结束」计时 mini 按钮、元信息缺「读完 MM-DD/开始 MM-DD」日期段。
- 搜索：placeholder 与实现均应按原型「搜索书名 / 作者 / 标签 / 摘录」——现只匹配书名+作者（`shelf_query.dart:31-40`）。
- 排序面板：缺「清空筛选」「完成」双钮；排序标题「书架排序与筛选」；选项改回 6 行竖排全宽按钮（选中显✓）。
- 目标卡：缺剩天数、「节奏刚好（预计 X 达成）」、白色进度条、达成态文案切换；「今年读完」展开缺编号格阵与「年度书单」入口（点格子应触发 blDetailYear 无年度单自动生成）。
- 维度值行缺计数徽标与「管理标签/来源/分组/作者/出版社」入口；底行统计缺「#标签 · 维度：值」段。
- 长按菜单缺尾行「查看书籍详情」灰钮；书脊视图缺说明行「书脊高度＝总页数 · 白点＝在读…」。
- 视图循环顺序：原型 墙3→墙4→列表→书脊→时间线；实现把「列表」挪到末位。
- 工作台在读轨道卡缺长按菜单（原型 5543 oncontextmenu）。
- 书名排序拼音未用 localeCompare('zh') 等价实现。

### 详情 / 档案 / 计时
- **相关推荐退化为平铺列表**：原型 bsRelGroups(4720)＝同作者/同系列/同标签/**同出版社** 四组分别成卡（组标题「同作者 X · N 本」、各限 6）；实现为单列表「或」条件、丢组标题与同出版社。
- **进度口径特判缺失**：bsPosLabel(4534) 四态（位置/百分比·有声/按章节/页）在详情页 chip 与档案页只剩两态，有声书误显示为「页」。
- **计时页底部 rtFoot 整块缺失**（原型 5005-5009）：今日 X/dayMin 进度条 + 记摘录/记进度/书籍详情三钮；另缺封面大图+副标题块、「未开始/正在为X计时」态、rtClose toast。
- 记进度弹层：缺「本次计时…/本次未计时·手动补记」上下文行、页数/位置「从→到」双输入、底部「保存记录 · 累计总耗时」钮；保存 toast 富文案（均速/预计剩/已入时间账本 L4）被压成「《书名》· %」。
- 档案页：数据卡第 4 卡原型为「分钟/页」速度被换成「评分」；页头缺星级；总结查看态缺「导出MD / 转存笔记」钮与 reset toast；chips 缺「购书 ¥fee」。
- 目录卡标题「目录 · N 节」缺节数；每节原型显划线数角标+done/在读状态点，实现显页码；缺「AI 补全」钮；书摘 tab 缺分段 chips 条。
- 计时明细：缺汇总「均 M 分钟/次」、行序号、「完成」钮；补记 toast 文案不同。

### 摘录 / 笔记库
- **卡片点按路径相反**：原型点卡直接进编辑表单，卡内带「→日记 →待办 →笔记 标星」快捷行；实现点卡开操作弹层且无快捷行。
- **「导出与分享」整卡缺失**（原型 876-884：导出MD/书摘卡片/摘录→待办/AI感想归并）。
- 表单违反「就地滚轮」铁律：创建时间用日历对话框、页码用键盘输入（工程内已有 `_NumWheel` 未复用）；新建默认颜色分类原型「重点」实现「共鸣」；识图/加图/剪贴板三钮反馈 toast 缺失或不同（加图成功无 toast、剪贴板不带章节、原文校验/保存 toast 文案均改写、「（联动 L5）」后缀系统性丢失）。
- 搜索不含书名；图片墙无图提示行缺失；感想卡缺「想法：」前缀；复习翻面无 3D 动画；空池/入口副标题口径与原型不同（实现更实用，需拍板以哪为准）。

### 统计 / 目标 / 书单
- **热力图布局错误**：原型＝GitHub 式 **7 行×周列按列流**+格 title+点击 toast「{年}年第 n 天 · X 分钟 · 摘录约 Y 条」；实现＝12 列按行流、格无交互。⚠ 注意：开发计划 §4 批4 写的是「12 列」，与原型源码不符——按「原型=事实源」铁律应以原型为准，计划文档同步勘误。
- **目标弹层大幅缩水**（本屏最大偏差）：原型 sheetGoal(2436-2485)＝滑杆 6-120+快捷 chip、每日/每周**时分双滚轮**、每月读完本、未读提醒开关+时刻滚轮、**实时预览卡**、保存钮「保存目标」+富 toast；实现仅 5 个数字滚轮+「目标已更新」。
- 统计页：支出/速度与目标卡顺序互换；月度卡不随「摘录」度量切柱值；目标卡预测缺「每周需多读 1 本」、提醒行、「阅读时长自动写入时间账本（L4）」说明；四卡缺「已达成/差 X 分钟」后缀；筛选摘要标签「2026·全年·时长·标签」缺失；图例缺「多」、副标题缺「色深＝{度量名}」。
- 支出卡缺「看账本」钮；字数卡缺「均速 N 字/分钟」。
- 书单：详情页「下载 TXT」实现为「导出 TXT」；行 meta 缺评分；分享弹层缺「下载 .md」与 canvas 脚注（MD/TXT 已归位详情页=顺序不同）；创建 toast 缺「· N 本，可生成分享图」；选书 auto 提示文案不同。
- 书架联动：点编号格自动生成年度单逻辑缺失（同书架条目）。

### 设置 / 导入 / 资料 / 收集箱
- 设置：组卡头「N 项」徽标缺失（微）；timerUI 说明截断；导入行说明「Notion/Markdown」被换「KOReader」、按钮「配置」→「打开」。
- 资料管理：缺概述行「N 个来源 · 覆盖 M 本书」、页头卡与「回书架」钮；行内无引用计数、无「在用即置灰删除」视觉、无点行跳书架筛选；五 tab 顺序应为 来源/分组/作者/出版社/标签（实现标签在第 3）；新增重复静默吞掉仍误报「已添加「v」」、空输入缺「先起个名字」；改名钮「确定」、toast「已改名为「nv」」；守卫句应为「还有 N 本书在用，请先在这些书里改掉{类名}」；空态「还没有条目，先在下方添加」。
- 导入：「按清单建书」尾句「同名同 ISBN 不重复建」丢失；「将建档」三态/撤销钮/粘贴框＝实现超前（计划已拍板，保留）。
- 收集箱→摘录：选书+真落库＝实现超前（保留），toast 文案需拍板是否回改原型句。
