## 三、批3 八屏要点（事实源 = `prototype/index-kits.html`，屏名后括号为工具键）

1. **Ping（ping）/ 网络测速（speed）**：原型为「模拟网络层」，页脚文案改「模拟网络层 · 不发真实请求」；Ping 有次数/超时参数、终端风格输出、四格统计；测速有节点 chips、环形仪表（conic 进度）、近 5 次历史 + 对比。真发请求只在 AI API 验证里发生。
2. **尺子（ruler）**：全屏舞台 + 可滑动游标与零点（V1.47 验收轮2/3 口径）、cm/in 单位、长边/短边、倍率滑杆 0.85~1.15 + 银行卡校准 + 重置 1.000；量程按**实测 DPI**（`MediaQuery.devicePixelRatio`），A4 真机校准项仍在验收清单里。
3. **测距（dist）**：离线地图比例尺点选（自绘网格画布 + SVG 折线同义改 CustomPaint）与 GPS 轨迹两模；比例尺滑杆 0.5~10、撤销/清空、模拟行走 60s。
4. **图片体积缩小（imgz）**：最长边 + JPEG/WebP + 质量滑杆 + 右下角水印开关 + 批量队列逐张；全本机处理不上传。实现走 `dart:ui` 编解码或 `package:image`（择重者需登记体积预算）。
5. **Base64（b64）**：四 tab（图→b64 / b64→图 / 文本→b64 / b64→文本）、复制裸串与 data URI、存 .txt、近期转换与操作记录留痕；限定图片与文本两类。
6. **提词器（tele）**：参数五项=方向 / 速度 / 字号 / 文字色 / 底色（色值一律走 `kitShowColorSheet`）+ LED 点阵舞台；**不做**语音跟随、自动停顿、反向滚动（V1.47 拍板）。
7. **AI API 验证（aiapi）**：走既有 `aiRunWithReview` / `verifyEndpoint` 通道（红线 R7），服务商/Key/模型/提示词四入，结果卡显示回复·延迟·token 或精确错误原因；页脚例外标注真实出站。

## 五、本批三条踩坑（已写进计划文档 §「批2 过程留档」）

1. 公有字段做 key 必须 `ValueKey<String>(x!)`；`ValueKey(keyName)` 得到 `ValueKey<String?>`，与 `find.byKey(const ValueKey('x'))` 不同型不命中——现象是「widget 明明在树里，finder 说找到 0 个」。
2. 绝对角度不要写进 `AnimationController.value`（`upperBound=1`，越界会让 `pumpAndSettle timed out`）；controller 只跑 0~1 归一进度，角度用 `_from + (_to-_from)*value` 在监听里算，收尾把 `_from` 收到 `_to` 再复位。
3. 图片类工具留静态注入缝（`KitPick.imagePicker` / `KitPick.decoder`），widget 测试给固定小图；读不到原始字节时退化 `_PixelGrid`，生产与测试共用同一命中公式。
