**② 硬约束**
- **DB 版本**以 `lib/core/database/schema.dart` 实际值顺延（当前 v24 → 本批从 **v25** 起；文档中序号仅相对）。
- **数据口径（已拍板，不可单方更改）**：① 阅读器划线/感想**直接读写既有摘录表**（原型 BS_QUOTES 对应表），划线行追加 `cf:{c,p0,p1} + rid` 出处字段且编辑保存时保留（原型 qeSave 守卫同语义）——**不新建批注表**；brSync 关闭时高亮暂存本地、重开回灌；② 本地书=既有书籍记录追加 `local:1 + epub:{fmt,size,path}`，新书带「本地」标签与「本地导入」来源，**同书重复导入走合并**（挂到已有记录，书摘/计时/进度共用一条）；③ 阅读位置/逐书外观/全局默认持久化（原型单键 `lh_reader_bs_v1`，开发可表或 prefs 承载），必须支持**逐书独立记忆 + 回落全局**两档；④ 计时复用既有全局悬浮计时基建：进阅读器自动 `timerTap('read')`，退出结算 min/times/进度入既有书籍记录与阅读记录。
- **边界写死**：仅本地 EPUB2/3 图文混排；**DRM 加密书拒开**（导入向导内置拦截）；PDF 归独立模块（置灰+指向说明）；不内置书城、不联网下载；除用户配置的双云同步外无网络请求。
- **全局 UI 规则**：禁 emoji 图标（一律简约线性 SVG/纯文字）；禁教学性文案（只留功能标签与状态提示）；数值/时间选择**就地内嵌滚轮**（CWheel），禁「点击→弹层→再操作」两段式；外观面板=**固定预览 + 草稿保存制**（HG-D3，本书专属/全部书籍两档）；含输入框的弹层自理 viewInsets；底栏不随键盘抬升（3.38 起）。
- **分页引擎为实算**：字号/行距/字距/边距变化 → 页数与进度即时重排（TextPainter/layout 真实测量），禁止假数字；CFI 形态 `epub/2/{章序+2}/{段}` 绑定书+章+段，退出重进自动恢复。
- **文件所有权**：只动 `lib/features/read/**` 与共享挂载点（路由、阅读设置分组、书架封面角标/点击分流、添加图书 FAB 菜单）；新测试**拆独立文件**并 `import test/helpers.dart`（防 isolate 污染挂死）。
