## 三、真机日志暴露但**本批不动**的问题（属同步模块，另批处理）

1. **WebDAV 上传 409 `AncestorsNotFound`**：日志先记「云端目录不存在 · 首次上传将自动创建（qoderwork）」，
   随后 PUT `/dav/qoderwork/*.lhbak` 仍被坚果云判祖先缺失 → 说明「自动创建」只写在话术里没有真的 MKCOL。
   建议：目录不存在时先 MKCOL（并对 405/201 都视为成功）再 PUT，失败给可复制的归因。
2. **S3 容量读取 `FormatException`**：`ListAllMyBuckets` 拿到 403/非列举形态回包时，
   除已有的「容量降级为未知」外，还会把异常原文（含 XML）抛出。本批日志引擎已把多行压平成一行，
   不再炸成假行；但降级路径仍应识别「回包不是列举 XML」这一形态并直接记降级，而不是抛 FormatException。
