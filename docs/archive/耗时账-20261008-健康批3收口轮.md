P2 三条实耗（都是「首跑 widget 测试才暴露的实现层真 bug」，不是自造轮次）：

1. **body 页 `SegRow` 无界宽**：裸挂在横向 `Row` 里，内部 `Expanded` 拿到无界约束，
   `performLayout` 直接 Null check 炸 → body 页 10 例首跑全红。修＝`Expanded` 包 `SegRow`、
   `Spacer()` 换 `SizedBox(width: 6)`。耗一轮 analyze＋一轮单文件诊断日志。
2. **`_WeightSheet` 三个 `late int?`**：读未赋值的 `late` 字段＝`LateError`，弹层首帧当场挂；
   摘掉 `late`（null 语义本来就是「还没滚过」）。
3. **目标页滚轮回写自循环（本批最贵的一条）**：诊断链＝一片红先怀疑工装 → 单文件直跑＋独立日志 →
   `pumpAndSettle timed out` 定位到 `spin` → 临时有界推帧打印 `initialIndex`，读出逐帧 `0/4` 交替
   → 才确认是「provider 进 loading 那几帧读数回落成空 → 滚轮 `initialIndex` 被打回档表首档 →
   程序跳转被 `onSelectedItemChanged` 当成用户改动上报 → 又写回库 → 再触发刷新」的环。
   修两处：`LHWheel.didUpdateWidget` 先认档再跳（程序跳转不报）；目标页加 `_pending` 乐观覆盖
   ＋按档案钉住的 `_settleCache`。**这条环在真机上是数据损坏**（刚存的 57 被档表最小值 55 盖掉），
   不是测试环境的假故障。修完整个目标页文件从 13s 掉到 2s。
4. **刀2 第一次摘错了地方**：`_optional` 里 `?? prev` 是冗余保护，单摘任一处都不红
   （已有记忆条目「变异要整体退回修复前形态」）；退回「未滚过的列按首位『—』写 null」的整体形态才现形。

固化候选（待产品点头再进计划书 §7.5，本文件只是留账）：

- **共享滚轮类改动先跑「写入—刷新」闭环用例**：凡「就地滚轮 → 写库 → tick 刷新」的屏，
  批内至少一条用例要真走完「滚 → 写 → 刷新 → 读数仍是用户那一档」，否则这类回写环只能在首跑撞见。
- **弹层内按钮先 `settle5` 再点**：入场动画没走完时按钮落在屏幕外（实测 `hw-cancel` y=3006），
  而 `pollText` 只看文案在不在树里（离屏也算）会提前放行。
- **横向 `ListView` 里的 chips 不能断 `findsNWidgets(n)`**：懒列表只建可见那几枚，
  判据要写成「滚到底，n 枚都点得到」。
