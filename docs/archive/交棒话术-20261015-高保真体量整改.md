## 2 · 拆法铁律（先读，违反即判不合格）

1. **原型禁「多文件＋装配」存量迁移**（治理档 §6 已冻结）。正解＝**按屏单一归属把屏迁回专版**，
   原件留占位屏或不留占位、由 `navTo` 兜底 toast＋重定向表。**禁**新建 `index-a.html`/`index-b.html` 这类切片。
2. **深链不许断**：历史工单/验收清单引用 `#p-xxx`、`?brNN=`；归属表兼作重定向表。
3. **删屏必须连带删逻辑**：以「保留屏集合」为根做可达性分析（`onclick=`、`getElementById`、函数调用图），
   清掉只服务被迁屏的函数与演示数据。**只删 markup ＝ 体积不降 ＋ 留死代码。**
4. **代码侧 `part` 优先**：同一 library 的私有小件（`_sheetShell`/`_wheel`/`_busy` 等）走 `part`，
   **私有性放宽一律不许**；跨 library 复用才提独立文件并显式导出。
5. **并行窗口必须冻结**：动原型前核 `docs/STATUS.md` 互斥面。影音游 `lib/features/media/**`、
   健康线 `lib/features/health/**` 属**其余线常备写区＝只读不写不提交不回退**。
6. **禁顺手改视觉与交互**：本工程只搬不改。搬过去的屏若看着不对，另开工单。
7. **禁 `dart format`**（非格式化干净态，小改动会炸成整份重排）。
8. **提交用文件级 pathspec**，禁 `git add -A`（并行会话共用暂存区）。
