### 批2 设计钉子（实现口径，防漂移）

1. **注册表与投影器落位**：模块注册表＋投影器在 `lib/shared/linkage/`（R1/R2：features 互不 import、core 不碰 features，聚合层唯一合法落点）。12 模块→表清单用 schema 常量；**子集排除用活库表名差集法**（`sqlite_master` 实表 − 所选单元表并集），注册表漏表不会误删数据。
2. **入包成员**：`config/settings.json`（SettingsRepository.exportAll→UserSettings.toMap，全口径字段、零凭据——凭据在系统保险箱本就不在此层）＋ `notes/` md 投影（notes.md/diary.md/book_quotes.md/mindmaps.md，front-matter 存元信息，图片引用改 `../attachments/note_images/<basename>` 相对路径）；`create` 增 `extraFiles`（成员名→文本，恒明文，与 logs 同档）。`withMd` 关＝只无 notes/，config 恒入（withProjection 开时）。
3. **投影开关传播**：`exportBackup` 增 `withProjection`（默认 **false**＝auto_before_restore 回退包不背投影）＋`modules`＋`withMd`；ExportSheet 与「另存到…」传 true；**同步快照也传 true**（换机云恢复必须带回口径设置——这正是四件套的题眼），`sync_snapshot_test` 若断言成员集随批更新。
4. **恢复侧**：`importBackup` 在附件腿后读 `config/settings.json` → SettingsRepository.importAll；失败 **warn 不炸恢复**（config＝投影非权威，DB 已替换，fail loud 反而把好数据堵在门外——与附件腿 fail loud 的差别在工单留痕）；恢复报告增 `configRestored`。
5. **可读目录档**：`<docs>/exports/lifeharness_readable_<ts>/`：config/＋notes/（与包内同源）＋记账（LedgerRepository.exportTxnsPage 逐账本复用 `writeLedgerExportFile`，csv+json）＋健康（HealthRepository.exportRows 复用 `writeHealthExportFile`，csv+json）＋其余模块 `data/<table>.json` 通用投影＋附件拷贝（开关）。**记账 p-export 整屏与笔记「导出为本地目录」原入口不动**（模块内深度导出保留，§9.6 口径）。
6. **UI 动面**：BackupSheet 导出段＝日志勾选保留＋「导出数据…」改开 ExportSheet＋「另存到…」保快速全量（带投影·口令删）；口令段全拆（状态字段/输入框/_exportPassphrase）；**导入侧 needPassphrase 分支保留**（旧加密包恢复兼容，红线）。文案两处：sync_page sub、settings_page sub 去「加密」字样。
7. **体积预估**：附件＝所选模块映射目录实算（日记→note_images·阅读→book_covers，exports/share 不属模块数据）；DB＝库文件全量实算，子集按行数占比折算，UI 带「约」。

## 批1 范围（本工单·核心链）

1. **P0-3 套包排除**：`LhBak` 打包对附件成员按扩展名排除 `.lhbak`（本地导出与同步快照两条腿同闸——`exports/` 落点的云快照同样套包）。
2. **P0-2 退版包 schema 漂移**：`unpack` 从「按包内快照 DDL 重建」改为**按当前 schema DDL 重建＋按列交集拷贝**；快照缺表按当前 DDL 建空（missingTables 口径不变）；快照多出的遗留表（如 events 退役）按快照 DDL 保数据迁入；辅助索引/触发器＝当前 schema 的建、快照遗留 best-effort；事务后显式 `PRAGMA user_version = 当前版本`。
3. **P0-1 附件落盘恢复**：新增 `LhBak.restoreAttachments`（`attachments/<目录名>/...` → 目录映射落盘、`attachments/<散件>` → 根落点；加密包逐成员解密；**组在包内才清旧目录**）；`BackupService.importBackup` 在 unpack 成功后接线（目录映射＝attachDirs 基名→原目录，散件根＝attachRootDirs 父目录）；恢复报告增附件组清单。
4. **structVersion**：manifest 增 `structVersion`（create 写 2；旧包无此字段读作 1，verify 双版本通吃）。
5. 新增常驻用例（面板第三行）。

## 红线

- 附件恢复失败＝导入失败（fail loud，自动备份 `auto_before_restore_*` 已先行可回退）。
- `unpack` 整库替换语义不变，**绝不复用做子集恢复**。
- 凭据（云 token/密码/口令）绝不入包。
- 旧口令加密包解侧（KDF 白名单/轮数封顶/GCM tag）一行不动。
