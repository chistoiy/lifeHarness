## 二、A 批要点（分享长图）

现成链路只有一处（**照它收成公共件，别另写一套**）：`lib/features/read/presentation/shelf/read_lists_page.dart:592-605`
——`RepaintBoundary(key)` → `toImage(pixelRatio: 1080/640)` → PNG → `getApplicationDocumentsDirectory()/share/<名>.png` → toast 回显**真实路径**。

公共件签名建议：

```dart
/// 把预览层渲染成 1080 宽 PNG 落到 <文档目录>/share/<文件名>.png，返回真实路径。
Future<String> captureShareCard(GlobalKey boundary, {required String name, String? src});
```

- 文件名必须 sanitize（去 `\/:*?"<>|` 与首尾空格），落盘前 `await f.parent.create(recursive: true)`。
- 失败路径要留痕：`AppLog.add('分享长图生成失败：$e', level: LhLevel.warn, src: ...)`——**不能只 catch 后静默**（catch 守护会红），也不能只弹 toast。
- 「保存图片」回执统一：`分享长图已保存：<f.path>`。**「保存到相册」的说法作废**（不申请媒体权限、不接 `share_plus`，系统分享面板仍是 V1.x）。
- 六处站点与原型逐字对照（现在全是假 toast）：
  `item_stats_page.dart:112`（统计卡）· `item_settle_page.dart:190`（决算卡）· `day_detail_page.dart:297`（倒数日卡）·
  `goal_review_page.dart`（**归档复盘卡＝新增入口**，未归档态不给钮）· `ledger_yearly_page.dart:364`（年度图）·
  `habit_auto_sheets.dart:946`（习惯「保存图片」）。
- 卡片内容结构照原型：渐变头（eyebrow · 标题 · 一行口径 · 大数字+单位 · 三格）＋白底分段列表（左名右值；值空则整段文本行）＋脚注「数据仅存本机」。
  「复制文字版」＝`Clipboard.setData` 后 toast「文字版已复制」（习惯侧 `habit_stat_page.dart:183` 已有同款装配可参考）。
- 用例：新建 `test/share_card_test.dart` 钉三件事——① 文件名 sanitize 与目录创建；② 渲染失败走 warn 日志且 toast 不谎报成功；
  ③ 站点级：点「保存图片」后 toast 文本含 `share/` 且**不是**「模拟」。注意 widget 测试里**不要跑真异步 I/O**（FakeAsync 下 `createTemp` 永不返回），
  用固定路径或 `tester.runAsync`，末尾 `await drainLogTimer(tester)`。
