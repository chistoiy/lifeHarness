## 3 · B 段实测：真正的杠杆＝bookshelf 壳段孤儿 JS（本批主体）

`prototype/index-bookshelf.html`（699,042）文档骨架实测：

```
head style     949 → 32,984      （32,035 字符·全文件唯一 style 块）
body HTML    33,001 → 174,928   （141,927 字符·21 个 section）
script#1     174,951 → 695,226  （520,275 字符＝全文 74.4%）
  ├─ 壳段    174,951 → 330,412  （155,461 字符·通用壳 JS）
  └─ 书架段  330,412 → 518,813  （书架专版·含阅读器/X-Ray）
script#2     695,236 → 699,026  （3,790 字符）
```

**核心事实**：body 只有 **21 个 `<section>`，全部是阅读系**（`p-readhub`/`p-bookshelf`/`p-bookDetail`/`p-readerPage`/`p-xrwords`/`p-readstat`…），**无一个待办／日历／笔记／母婴／习惯／记账屏的实体 HTML**——但壳段里这些屏的 JS 全在（壳段 24 个分节、364 个顶层符号）。

**依赖闭包实测**（分节粒度，判据＝本节符号在「body HTML ＋ 书架段」中零引用，且不被任何必须保留节调用）：

- **壳段外零引用符号 306/364**
- 剔除初始化调用链里的死调用（`renderSideThemes()`/`renderMedia()`/`renderBabyToday()`/`drawGrowth('w')`/`renderVax()`/`renderHabits()`/`renderPstore()`/`renderRecords()`/`renderGrid()`——这些调用指向 body 里不存在的屏）后，**安全可删 13 节＝58,672 字符**
- **判据①测算**：699,042 − 58,672 = **640,370**，仍差 55 万线 **90,370 字符**

**为什么不再深挖**（§0 裁定「只删安全部分」）：剩余须保留的 13 节里，`日历`（12,351，被 `WHEELS`/`posW`/`wReg` 引用）、`块视图`（17,838，被 `fmt`/`pomoFinish` 引用）、`笔记`（16,075，被 `renderPwBar` 引用）、`计时`（11,364，被 `openProgress`/`pillDragStart` 引用）**与阅读器有真实耦合**——阅读器进度弹层、番茄钟、飞架滚轮都吃这些符号。拆它们要逐屏过门＋真机复验，收益 9 万字符 vs 风险，不划算。**剩余缺口按 §0 裁定带缺口销账。**

**⚠️ 随节误伤与补回（本批的真实教训）**：静态分析判「外部零引用」时，**定义在节尾的基础设施符号会被连带删掉**——`$`/`$$` 定义在「模拟数据」节尾部（全文件通用 DOM 助手）、`curTheme`（FAB 用）、`esc2`/`imgTarget`/`pwLnOn`（笔记引擎用）、`D` 模拟数据对象（待办/日历的数据源）。共 10 个符号漏网，**由 §5 新闸运行期验证抓出**，已按最小集补回（`D` 只补被引用的 4 个键，不整节回滚）。

**⚠️ 变异自证的一处自我修正**（值得记）：新闸首版只遍历 21 屏 + 渲染族，注水删 `esc2` **未被抓到**——因为笔记 Markdown 的真实入口是 `pwSync()`（`PW_TA` 进编辑态才非空），不在遍历路径上。补该路径后再变异 ⇒ 抓红。**教训＝闸的覆盖必须对齐真实调用面，否则「变异全红」是假绿**（与「反推断言固化缺陷」同源）。

**⚠️ 批 2 副产物：保留的 13 节里多数也是孤儿**。`待办`/`日历`/`块视图`/`记录`/`笔记批`/`顶栏`/`账单导入`/`FAB` 对应的屏（`p-todo`/`p-calendar`/`p-records`…）在 bookshelf 里**连 HTML 实体都没有**（`grep 'id="p-records"'` = 0），它们当初被保留只因被间接引用牵连。**这意味着判据①剩余的 87,333 缺口，主体同样是孤儿代码**——但清理它们必须连带处理与阅读器真实耦合的 `计时` 节（`openProgress`/`stopTimerUI`/`timerTap` 是阅读器进度弹层的活代码），属**深挖**范畴，超出 §0「只删安全部分」裁定。**留作下一批候选，本批不动。**
