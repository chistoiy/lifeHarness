## 3. 门面口径（为什么这么切）

1. **形态照抄既有的 `stats_providers.dart`**：纯 `export … show 白名单`，一行一个符号——耦合面永远可枚举，读门面即知外部用了对方哪些能力；不是把整个 domain 转出去。
2. **`mindmap_api.dart`＝「别的模块 → 导图能力」单向出口（7 个符号）**：横向树引擎／度量／节点模型／样式／painter 五个是笔记导图视图要的（复用同一份渲染实现，各写一套必然漂移）；`MindmapDao`／`mmOutlineFlat` 两个是收集箱「文字转导图」要的。
3. **`export_source_mounts.dart`＝导出取数口（3 个 provider）**；序列化端 `IcsItem`／`buildIcs` 挂在既有的 `ics_collect.dart` 上——收集器与序列化端本就是同一份口径，再开一件只会让跨模块面变宽。
4. **反向不混**：导图 ← 笔记/收集箱的数据读写仍走 `mindmap_mounts.dart`（原样未动）。
