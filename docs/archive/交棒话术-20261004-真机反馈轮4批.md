## 2 · 已定口径（不再讨论）

- ②③ 的点击一律**直达对应模块页**，不弹中间层、不加教学文案（AGENTS：不写说明性文字）。
- ④ 多条复制的落点＝系统剪贴板，格式沿用单条的 `formatted`（一条一行），不做导出文件。
- ⑤ 默认选项＝**保留阅读记录**（书摘/划线/计时/进度），删除项只清源文件与缓存；两选项都要能看清后果。
- ⑥ 只改计时挂起，不改结算规则与「短于 N 秒不计入」门槛。
- ⑦ 先出需求条目（进 `docs/需求清单.md`）＋原型，再谈实现；不许顺手做成单模块回收站。

**⑥ 落地记录（2026-10-04）**：`reader_page` 新增 `_readSecs`（已封口段累计＋当前段）与 `_pauseReadingTimer`/`_resumeReadingTimer`——退后台（inactive/paused/hidden）把当前会话段**就地封口**（走既有 `endSession`，未达 `read.brMinSecs` 的短段照旧整条丢弃），清空当前段起点＝暂停；回前台为同一本书另开一段。只动**本页自己开的计时**（沿用他处会话时不抢别人的条）。时钟与结算提示都改吃 `_readSecs`。常驻用例 `test/reader_bg_timer_test.dart`：进页一段在跑→挂起后 0 段在跑·1 段已封口→回前台再开一段→二次挂起＝2 段已封口·0 段在跑（门槛设 0 秒才看得见封口行）。批内 63 绿（含 `reader_v52_sess`/`read_data` 会话回归）。**遗留**：多段会话的结算提示只报最后一段分钟数（`closed.minutes`），跨段总时长另议。

**① 取证已完成（2026-10-04 本会话，产品补口径＝「设置→日记天气→输入城市名→无匹配城市」）**：

- 链路＝`settings/presentation/weather_city_sheet.dart` → `shared/weather/weather_service.dart::searchCity` → Open-Meteo geocoding（`geocoding-api.open-meteo.com/v1/search?name=&count=10&language=zh`）。
- **根因不是匹配算法**：`_defaultFetch` 把「非 200 / 超时 / DNS 失败 / 解析失败」全部 `return null` 且**一行日志都不落**；`searchCity` 见 `results` 不是 List 就回空表；弹层再把空表统一显示成 **「无匹配城市」**（`_failed = hits.isEmpty` 注释自己写着「含无网/无匹配」）。＝**无网被伪装成查无此城**，同时违反两条已立口径（能力边界不许静默／自建日志一条记录落盘一行）。
- 旁证：本机 `curl` 该端点**零字节返回**（与 AGENTS 记的 GitHub/open-meteo 受限一致）；6051 包 release 清单已含 INTERNET（aapt 核过），所以不是权限那条坑。
- **施工图（下一会话照做，勿重查）**：
