## 十、版本冻结说明

### V1.53 修订记录（2026-09-28 · AI 使用记录全屏页 · Flutter 已落地（v26）· 真机已走查并修四条 · 发布 `v0.1.31-ai-fix1`）

- **用户指令**：「优化下 AI 增强模块，增加使用记录，输入、输出内容记录，可以按模块进行筛选、删、查等操作，这个跟日志页面一样，也搞成全屏显示的，避免查看时效率过低。」
- **现状缺口**：AI 调用只落两处——`ai.tokenStats`（prefs 里「日 × 能力点」聚合，无正文）与运行日志流水（`AppLog`，只有耗时/token 摘要，环形缓冲 300 条会滚掉）。**发送内容与返回正文在调用结束即丢弃**，无法回看「上次让 AI 补的目录到底输出了什么」「这条为什么失败」；查看只能进日志页翻流水，效率低。
- **数据口径（拟）**：新增 `ai_calls` 表（**DB v26**）＝`ts / task_id / module / name / status(ok|fail|cancel|denied) / in_tok / out_tok / ms / sys / usr / out / err / cut`。`module` 取能力点自带模块字段（待办/日记/阅读/收集箱/日程/呵护/记账/小工具），与提示词资产 `prompts.json` 同源，新增能力点零改表。门控拒绝与取消同样入账（denied 无正文·零请求，cancel 有输入无输出）。**API Key 永不入库**（仍在系统加密区，日志侧已有脱敏）。
- **全屏页 `/ai-usage`**（交互语言与日志页 p-logs 同族，push 栈路由，**无底栏、列表通底**）：首行＝筛选统计（`筛选 N 条 · 入/出 tokens · 未成功 · 今日次数`）+ 右侧三钮（记录设置 / 复制 / **删除筛选结果**）；第二行＝**三个条件胶囊**（`时间 · 今日`、`状态 · 全部`、`模块 · 全部 N`，各显示当前值，行高仅 24px）；**点某个胶囊才在该行下方横向弹出该组选项**（当前项高亮，选完即生效并自动收起，再点同一胶囊收起；同时只开一组）；第三行＝关键词搜索（能力名与输入输出正文）；其下全部高度留给列表（`100vh - 258px`）。行＝时间 + 状态徽 + 模块·能力名 + 入出 token + 耗时；**点行内联展开** System / User / 输出 三段全文（失败行给「原因」段不显示空输出），行内四钮＝复制输入 / 复制输出 / 复制全部 / 删除本条；**长按行＝复制该行摘要**（与日志页同交互）。破坏性动作用**两段式按钮**确认（首点变「再点一次确认」，3 秒回退），Flutter 侧改走既有确认弹层。
- **记录设置**（右上「记录设置」弹层）：① 记录输入与输出正文开关（关闭后只记用量）② 保留天数 7/15/30/90/不限（默认 **30 天**，超期按天丢弃）③ 单条正文上限 **8000 字**，超出截断并在详情里标「已截断」④「清除已存正文（保留用量记录）」⑤「清空全部 AI 使用记录」。
- **入口两处**：AI 增强页顶部新增「AI 使用记录」卡（今日次数 / 今日 tokens / 近 7 天 / 累计 四格摘要 + 查看全部 ›），原「AI Token 使用」聚合卡并入此卡（**原型此前缺这张卡，本批按 Flutter 现状补齐**）；日志页保持独立职责（系统流水），不混装 AI 正文。
- **随备份走**：表在 DB 内 → 本地备份 `.lhbak` 与云同步快照自动覆盖（`ai_calls` 不属 care 排除组，无需新登记）；换机恢复即带回历史调用记录。
