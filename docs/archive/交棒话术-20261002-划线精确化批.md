## 1 · 根因（已核实到行）

- 选区本身是**字符级**的：`SelectionState` 带 `o0/o1`，选中态渲染 `_subSpan` 也只包子串
  （V1.53.2 修②）。但落库时 `reader_sel_ops.dart` `_addHl` 构造
  `QuoteCf(c: sel.ci, p0: sel.p0, p1: sel.p1)` **把偏移丢了**——数据模型只存「章+起止段」。
- 重渲染 `_hlAt(ci,pi)` 按段命中 → `reader_stage.dart` `_para` 给整个段落 Container 铺
  27% 底色。图6 那章是超长注释段（近满页），观感＝"整页涂绿"。

## 2 · 规格（口径唯一，勿自行加码）

1. **模型**：`QuoteCf` 增可选 `o0/o1`（`int?`）。语义＝`o0` 为 `p0` 段内起始字符偏移、
   `o1` 为 `p1` 段内结束字符偏移（原文坐标系，不含缩进前缀；简繁转换逐字等长不破坏对齐）。
   JSON 编码仅在非空时写键；**旧行无偏移 decode 回 null＝维持整段旧行为**（向后兼容，
   零迁移——cf 是 `book_quotes.cf` 列内 JSON，无 schema 变更）。
2. **落库**：`_addHl` 把 `sel.o0/o1` 写进 cf。`_delHl` 匹配口径不变（章+段区间相等即删，
   旧行也删得掉）。`_LocalHl`（brSync 关暂存）经 `QuoteCf.encode/decode` 自动带上。
3. **渲染**：稳态（无活跃选区）下 text 段的划线改走 `_textSpan` 内**子串铺底**：
   按段算命中区间——`p0==p1`＝`[o0,o1]`；首段＝`[o0,末]`；尾段＝`[头,o1]`；中间段整段。
   `o0/o1` 任一为 null（旧数据）→ 该段维持整段 Container 铺底。引文/标题段本就不走
   `_textSpan`，维持整段铺底。活跃选区在场时（`_subSpan` 场）维持现状整段浅底，
   不叠加精确色（瞬态，避免双重合成）。
4. **带感想橙点**逻辑随色底迁移到段尾，不因精确化丢失。
5. 「跳原文」（书摘库→阅读器）仍按段定位，本批**不做**精确滚动。
