## 2. 原型改法（落在 `prototype/index-bookshelf.html`）

> 行号会漂，**用文本锚重定位**，别照抄本文件的行号：
> `grep -n 'bk-cov\|cov-box\|长按选区\|收敛层\|P-B1b' prototype/index-bookshelf.html`

**R14-4（书架卡 · 三档回落）**
- 现状锚点：`.bk-cov{`（卡面容器）、`.cov-box{`（虚线占位）、`id="nbCovBox"` / `id="ebCovBox"`（录入/编辑封面框）。
- 三档口径：**A 取 EPUB 内嵌首图**（默认）→ **B 书脊色块**（按 `color_idx` 取主题色，无图也不空）→ **C 纯文字卡**（书名+作者排印，无图无色）。
- 原型里要能**同屏对比三档**：书架页给一个临时切换器（`A/B/C` 三枚 seg-pill），并让**无封面**的书卡按当前档渲染；
  另在「阅读设置/书架设置」里登记一个长期开关的位置与文案（默认 A）。
- 深链按本项目既有约定 `#p-<屏id>_<iN>`，保证逐屏走查能直达。

**R14-6（选区工具条 · C 方案）**
- 现状锚点：`/* ---- V1.53 轮3 · 底栏五图标 + 进度/亮度/字号三面板 + 长按选区（参考图1~4） ---- */` 与紧随其后的
  `/* 长按选区：段落与中心热区都支持（点按＝收放 chrome，长按＝弹摘抄工具条） */`；另有 `/* 收敛层：一行工具条 · 二级操作面板 · 折叠区（批F） */`。
- 原型改两处：① 工具条容器加**不透明底衬**（沿用主题 token，别裸色值；深色模式同样不透明）；
  ② **让位规则**：工具条所在行与被选段所在行不重叠——上沿贴选区上方空白，放不下时才下压，
  并给出「选区在最底部行」时的退化画法（贴屏下沿、翻到选区上方）。
- 顺带把首尾手柄视觉放大一档（清单里同一工单的抱怨），但**只改原型样式**，不改交互。
