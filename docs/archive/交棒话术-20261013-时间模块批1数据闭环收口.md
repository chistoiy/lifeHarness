## 3. 本批实锤坑（复用价值高）

1. **FakeAsync 下 `await Future.delayed(Duration.zero)` 会挂死**：零时长 Timer 无驱动者，10 分钟超时才红。修法＝`tester.pump(1ms)` 推帧兼推时钟（round5_f5 实锤，探针五打点定位）。
2. **两个 flutter test 进程并发＝互抢 `build/native_assets/windows/sqlite3.dll`**（errno 183 PathExistsException）。本机纪律：flutter test 全程串行；偶发该错先清 `build/native_assets`。
3. **滚轮拨档**：fling 带惯性漂档；drag 须「itemExtent+2px 过 slop」（本弹层 itemExtent=26 → drag 28）。
4. **弹层头部读数含结束日期**（「起 → 结束日 结束时」），拿「10:00 → 10:00」当子串判据永不命中；e==s 判据用「· 0 分钟」。
5. **schema 种子分类与用例同名**（工作/学习）会让 `_byName` 命中种子行 → 用例一律唯一名（甲组/乙组）。
6. **变异工装往返会把 CRLF 工作区归一成 LF**（autocrlf=true 下内容零损、索引一致），回写判据用「变异串清零＋git diff hunk 数不变」，勿用整文件 md5 对比改前 CRLF 基线。
7. **同文件两处同构守卫**（`_add`/`_save` 各一份 e≤s 判据）时变异锚点须带差异后缀（`&& !_timing`）保证命中=1。
