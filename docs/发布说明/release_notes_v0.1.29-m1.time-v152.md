LifeHarness 预发布 v0.1.29-m1.time-v152 · 时间模块统一编辑与计时语义 + 时间账本 L4（需求 V1.52）

【本版本内容】（提交 82c0c1b · DB 无变更，沿用 v25，覆盖安装即可）
- **点已有事件 = 与新增同一个弹层**：轴 / 块 / 日 / 周四视图点击任意事件、时间块、完成标记，一律打开与「＋添加」同一个弹层，预填起始 / 结束 / 一级+子分类 / 备注，底部＝「删除 ＋ 保存修改」。旧的「事件详情」「标记块详情（取消标记）」「新建日程」三个弹层整体退役。
- **今天的计时语义（单一状态机）**：日期为今天时弹层起止默认**当前分钟**，确认添加即成为「计时中」块（结束随当前时刻推进），轴视图卡片与编辑弹层都给「■ 结束计时」；块视图右侧分类速记未选中时点分类＝**单点直接开一段计时块**（免弹层），非今天拒绝并引导用 ＋ 补录。计时态用 `time_blocks.source='timing'` 表达，**无数据库版本迁移**。
- **自动收口规则**：计时中 a 未结束时添加 b——b 起始 ≥ a 起始 → a 收口时刻 = `max(a起始, min(b起始, 当前))`；b 起始 < a 起始 → 视为纯补录不收口，且 b 结束晚于 a 起始会被弹层守卫拒绝。选区直标、速记开新段同样触发收口，全局同时只允许一个计时中块。非今天为纯补录，任何位置不出现计时按钮。
- **拆分 / 合并 / 撤销**：已结束块弹层给「✂ 对半拆分」「⇧ 与上一个合并」「⇩ 与下一个合并」，计时中块不显示；合并仅限同日前后相邻且间隙 ≤ 30 分钟（超出置灰提示）；删除 / 拆分 / 合并均入撤销快照，提示条上「撤销」一键回滚。
- **四视图渲染修正**：轴视图副行不再重复起止时间（左侧刻度即开始时间）、每段 ≥15 分钟空隙都是可点补录条、计时时长走秒级文本刷新不整页重绘；日 / 周视图格内显示**事件名 + 时长**；周视图改**按小时重叠**渲染（原整点采样导致非整点起始的事件/块整行隐身）并固定 7 列、跨月日渲染惰性列；**月历圆点由数据实算**（计时中红 > 完成绿 > 计划蓝）；跨天事件按两段行落库并在次日可见。
- **时间账本 L4 独立页 `/time-stats`**（时间页顶栏柱状图标 + 仪表盘「本周时间分布」卡双入口，后者由写死 SVG 改实算）：**日 / 周 / 月 / 年**四档 + 期间翻页、卡片可折叠；日档 24 小时时钟盘面（扇区=每段事件·红线=当前时刻）；周 / 月档单日时长对比面积图 + 满高底轨堆叠柱；年档热力图 + 单月对比 + 按月分桶；总时长环形含**未记录**灰段（分母 = 天数 × 1440）；分类排行带次数 / 占比 / 进度条 / **与上期环比**。
- **滚轮与弹层瘦身**：分钟档 5 分 → **1 分钟**且滚轮循环滚动；滚轮可视 3 行、行高 26；一级分类每行 6 个、行距 4、最多 3 行；删除「时长 0/15/30/1时/2时」快捷钮；「标签」「管理」并入「一级分组」标题行右侧，管理直达分类管理页。
- **删除项**：时间冲突提示条（写死文案且永不显示）移除，冲突检测能力如需恢复另立需求。
- **同批顺带修复（与时间模块无关的两条 HEAD 基线既有红）**：① 日志落盘行自阅读器批3（`64448fb`）起带 `MM-dd ` 日期段，而冷启动回填的反解正则未跟进 → 回填行全部退化成「info 级裸文本」（级别/来源/时刻全丢），现令日期段为可选并统一按文件名取日期；② 习惯模块三条用例的周几时间炸弹（周一跑时种子日落到未来被时钟防护拒写、或落到上周致当期分母漂移）→ 改按「当期 / 上一整周」锚点，纯测试侧修复。

【已具备能力】时间模块四视图单一数据源与单一编辑入口闭环（计时态状态机 + 自动收口 + 拆分合并 + 撤销快照 + 跨天两段行 + 月历实算），统计侧从写死示意升级为全量实算的 L4 账本页；高保真侧 `prototype/index.html` 与实现同批（`tools/time52check.js` 无头回归 31/31）。

【已知占位项】块视图粒度 1 分钟 = 1440 格需虚拟化（真机长列表性能待验收）；撤销栈为内存态，跨进程不保留；账本「分类明细下钻」当前为占位提示，待另立需求；**待办模块的时间滚轮仍是 5 分档**（属待办模块，未随本批改动，是否与事件弹层统一待产品确认）；时间冲突检测能力已随提示条移除，如需恢复另立需求。
