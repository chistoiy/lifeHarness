- 日志入口外移：同步/备份页不再挂「日志」行，唯一入口＝「设置 → 运行日志」。
- 日志新增**来源**标签：由调用帧的代码路径自动归类（AI / 同步 / 阅读 / 记账 …，无法归类的归「系统」），各模块零传参零注册；日志页筛选升级为**级别 × 来源 × 关键词**三重叠加，带条数计数。附带修掉一条引擎级不变量：**一条日志＝文件一行**（换行压平、超长截断），此前整段云端错误 XML 入缓冲会把冷启动回填炸成多条假行。
- 日志跨重启可见：冷启动把上次进程落盘文件的尾部行读回内存缓冲（每文件只读尾 128KB，补齐到 300 条），日志页不再是重启即空。
- AI 调用全量留痕：门控拒绝记 warn、失败记 error（含归类）、成功记 info（耗时 + 入/出 token），API 验证工具成败同样落日志。
