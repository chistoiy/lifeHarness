# 发布说明 · v0.1.32-reader（预发布 · 0.1.32+4030）

发布日期：2026-09-28 ｜ 分支：`feat/m0-skeleton` ｜ 数据库版本：**v27**

本批为阅读器 V1.53.2 轮5~轮5.4 的 Flutter 落地（原型 `prototype/index-bookshelf.html` 已先行确认），
外加 AI 调用整改接入统一入口。

## 一、本轮新增/变更

### 1. 阅读器 UI 统一（轮5.1 / 轮5.4）

- 底栏由五图标（目录/主题/进度/亮度/字号）收敛为**三图标：目录 / 进度 / 外观**；
  「进度」「亮度」「字号」三个内嵌面板全部升格为正常底部弹层（点图标从下方升起，不再压在底栏上方）。
- 主题、亮度、字号、行距、字距、边距**合并进「外观」弹层一处管理**；外观弹层新增：
  背景色预设、**自绘色相/明度取色**（改底色 / 改字色两档，不使用系统取色器）、
  **纹理背景**（纸纹 / 牛皮 / 网格）、**相册图片背景 + 淡化档**（保存时拷入应用私有目录）。
  面板保持草稿制：改动只进草稿并实时预览，「取消」丢弃、「保存应用」按「本书专属 / 全部书籍」落库。
- 顶栏补「⋯ 本书操作」弹层：目录/检索/书摘/记录/统计/详情/外观/删除八宫格 + 阅读模式（翻页⇄滚动）
  + 本书书摘条数 + 书籍详情 + 阅读器设置 + 屏幕常亮。
- **顶栏/底栏跟随阅读主题取色**：浅色主题＝同色浅栏深字，深色主题＝深栏浅字，并加背景模糊，
  不再固定黑色底条。
- 进入阅读器时**挂起全局读书计时条**（顶部那条《书名》· 阅读中 N 分钟），阅读页内只在顶栏显示计时胶囊，
  退出后自动恢复。

### 2. 选区改系统复制式（轮5①）

- 长按正文仍默认命中一句，但**扩选改为首/尾两枚可拖动手柄**（圆点＋竖枝），
  与系统复制手感一致：手柄可跨行、跨段拖动，两端相遇自动互换。
- 摘抄工具条移除「前扩 / 后扩」两枚按钮，保留：复制 · 划线 · 写想法 · 书摘 · 查询 · 听当前 · AI 解读 · 分享。
- 修正：有选区时不再挂载父级横向滑动翻页识别器，避免手柄横向拖动被翻页手势抢走（真机同样会拖不动）。

### 3. 目录抽屉与跳转返回（轮5②③ / 轮5.2①）

- 目录抽屉头部新增**「全部折叠 / 全部展开」一键钮**（与逐组 chevron 共存，图标随状态切换）。
- 通过目录或书内链接跳章后，**抽屉内出现「‹ 回到刚才在读 · 章名」一行**，点按回到跳前位置（用后即清）。
- 拖进度离开进书位置后，**进度弹层内出现「回到进书位置」按钮**。
- **正文不再悬浮任何胶囊**（原「‹ 返回原进度」浮条已删除），两个返回入口分别收进上述弹层与抽屉。
- 章节名闪现提示（跳章/翻页时短暂显示章名）按拍板保留。

### 4. 阅读计时自动结算（轮5.2② · DB v27）

- `book_sessions` 新增四列：`from_chapter` / `to_chapter` / `from_pct` / `to_pct`
  （v26→v27 迁移 + 建库同文；既有 `from_page`/`to_page` 继续用作全书页码）。
- 进入阅读器即记录**起始章节、全书页、百分比**；退出结算时自动写入**结束位置**并在提示条播报，
  不再需要手动填页码/位置/百分比。
- 新增门槛设置项 **`read.brMinSecs`（默认 30 秒）**：短于该时长的阅读**时长与会话都不入账**
  （明细里不留痕），但书籍进度与最后阅读时间照常更新。位置：设置 › 阅读 › 本地阅读器 ›
  「短于该时长的阅读不计入」（5/10/15/30/60/120/300 秒）。
- 书架时间线与阅读记录页的会话行同步展示起止章节、页码与百分比。

### 5. 书籍详情页本地文件区（轮5.3）

- 原页面底部的「本地 EPUB · 可直接阅读」整卡**上移到信息行之下、三 tab 之前**，压成**两行紧凑条**：
  第一行＝格式徽标 + 体积·无 DRM·图文混排 + 「?」；第二行＝进度/位置/划线 + 打开阅读器 + 全书检索 + 删除。
- 「?」打开**本地文件与缓存说明**半屏：文件路径、体积/加密/版式、位置/划线/进度、
  删除两口径说明、缓存状态与「清理缓存」入口（沿用三态弹层，源文件永不删除）。
- 预载中 / 已清缓存等非就绪态仍保留原四态行，重新载入与重新选文件入口不丢。

### 6. AI 调用整改（R7 架构门）

- 划词「AI 解读」的摘录感想改走统一入口 `aiRunWithReview(taskId: 'read.quote_insight')`，
  阅读侧不再自建第二条请求路径；结果弹层降级为纯展示。
- 阅读侧对 AI 规范棘轮（R7）的豁免已清空，`architecture_test` 守护通过。

## 三、已知边界与下一步

- **脚注/角标与精排包渲染未支持**（轮5④）：`_extractParas` 不识别 `<sup>`/`aside`/`epub:type`，
  `href` 一律剥锚点，内链只能跳目标章首页；fixed-layout 包会被拆成碎片段。
  落地范围（仅角标↔注释跳转 / 连精排包检测降级一起）待拍板，需改 `EpubLink`+锚点表+`_onLink`
  段级定位，并让 DocStore 快照版本 2→3、分页表作废重算。
- TTS 朗读按既定拍板延后，工具条「听当前」仍为占位提示。
- 本轮为**预发布**，待真机逐屏验收（重点：手柄拖动、弹层遮挡与层级、图片背景+淡化可读性、
  退出结算提示与短会话门槛）。
