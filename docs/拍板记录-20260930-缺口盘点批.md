## 五、#2 分享长图包的落地形态（开工前定案，避免走偏）

核过代码后有个结论要先记下：**这六处不是"把 toast 换成写文件"就完事**，它们缺的是"分享出去的东西长什么样"。

- 现成范式在习惯侧：`habit_auto_sheets.dart:620` 的 `sheetHabitShare` —— 预览弹层（数据快照由统计页装配）
  \+ 「复制文字版」\+ 「保存为图片」，真链路是 `read_lists_page.dart:592-605` 的
  `RepaintBoundary.toImage(pixelRatio: 1080/640)` → PNG → 应用文档目录 → **回报真实路径**。
- 所以要补的是：① 一个公共通道件（建议 `lib/shared/widgets/share_card.dart`，把上面那条链路收成一个函数，
  六处共用，含失败留痕）；② 各站点的**分享预览弹层**（物品统计卡 / 决算卡 / 倒数日卡 / OKR 复盘卡 /
  记账年度图 / 习惯保存图片）。
- 门序：预览弹层属 UI 新增 → **先改原型**（`index-day_aim__goods.html` 三卡、`index-ledger.html` 年度图、
  `index_habitcheck.html` 两钮），照 `sheetHabitShare` 同一套语言画，不另造风格；逐屏确认后再落 Flutter。
- 另两处不同性质：`habit_detail_page.dart:144` 的「已导出 x.json（模拟）」是**数据导出**（写文件即可，无需预览层）；
  `ledger_add_page.dart:416`「添加图片附件（模拟）」是**记账附件能力**，属另一条待排期需求，不在本包内顺手做。
