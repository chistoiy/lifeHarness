## 三、本轮 5 条用户指令的落地形态（验收定位用）

1. **尺子自动按手机长边**：`rulerDraw()` 以 `max(screen.width,screen.height)/3.78` 求长边毫米数铺满尺面，
   顶栏右侧「长边 / 短边」两枚 chip 切换方向（`KITS.rulerDir`，默认 `long`）；倍率滑杆只做微调，
   底部读数行实时显示「长边 NNN mm ≈ N.N cm」，`银行卡校准` 一键写入倍率。
2. **轮盘支持多套数据 + 权重 + 粘贴**：`KITS.wsets=[{id,name,items:[{t,w}]}]`，顶部套集 chips 切换（≤8 套）；
   粘贴框支持 `选项:权重` / 逗号 / 顿号 / 换行分隔，「追加到当前套」「替换整套」两种落法；
   权重 1~9，扇区角度按 `w/Σw` 实算，列表行内显示 `−/＋` 权重步进与占比百分数；结果按当前套留历史。
3. **取色盘图片取色**：导入本地图片→canvas 渲染（100%~400% 缩放滑杆 + 容器内滚动），
   点击像素点走 `getImageData` 实取，结果行显示 HEX/RGB/像素坐标/α，可「复制」或「加入取色盘」；
   最近取色去重持久化，长按移除。
4. **互补色圆环**：`cmpWheel()` 用 SVG 画 60 段色相环 + 当前方案取色角高亮扇区与圆点（点圆点即复制），
   方案钮「切换方案 · 互补/类似/三角/分裂互补/四方」，`一键复制全套 HEX` 输出整组色值。
5. **新工具 ×2**：
   - `b64 图片 ⇄ Base64`：拖拽/选择图片→`FileReader` 本地编码，出裸串与 data URI（各自复制/存 txt），
     体积对比实算（约 +33%）；反向粘贴→`atob` 解码并还原预览（可保存），非法串给「解码失败/不是有效图片流」归因；
     近期转换与操作记录留本机。
   - `tele 提词器`：速度 10~300 px/s、字号 18~96、文字/底色、行距、方向（横向=内容转 90°，手机横过来即正向）、
     **LED 点阵屏**开关（颗粒遮罩 + 扫描线动画 + 发光字），全屏舞台层 `#tpStage`，
     进屏即存稿，参数与文稿随 `lh_kits_v1` 持久化。
