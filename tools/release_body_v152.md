# V1.52 时间模块 · 统一编辑与计时语义（预发布）

本包为 M0/M1 时间模块的 V1.52 改造收口包，含高保真原型与 Flutter 双端同步落地。

## 一、点已有事件 = 与新增同一个弹层
轴 / 块 / 日 / 周四视图点击任意事件、时间块、计时块，一律打开与「＋添加」**同一个**弹层，
预填起始 / 结束 / 一级+子分类 / 备注，底部为「删除 ＋ 保存修改」。
旧的「事件详情」「标记块详情（取消标记）」「新建日程」三个弹层整体退役。

## 二、今天的计时语义（单一状态机）
- 日期为今天：弹层起止默认**当前分钟**，确认添加即成为「计时中」块，结束时间随当前时刻推进；
  轴视图卡片与编辑弹层都给「■ 结束计时」。
- 块视图右侧分类速记：未选中时点分类 = **单点直接开一段计时块**（免弹层），非今天则拒绝并引导用 ＋ 补录。
- 自动收口：计时中 a 未结束时添加 b —— b 起始 ≥ a 起始 → a 收口 = `max(a起始, min(b起始, 当前))`；
  b 起始 < a 起始 → 纯补录不收口，且 b 结束晚于 a 起始会被拒绝。全局同时只允许一个计时中块。
- 非今天：完全按所设时间落库，任何位置不出现计时按钮。
- 实现口径：计时态用 `time_blocks.source='timing'` 表达，**无数据库版本迁移**。

## 三、拆分 / 合并 / 撤销
已结束块给「✂ 对半拆分」「⇧ 与上一个合并」「⇩ 与下一个合并」，计时中块不显示；
合并仅限同日前后相邻且间隙 ≤ 30 分钟；删除 / 拆分 / 合并均可在提示条上「撤销」回滚。

## 四、四视图渲染修正
- 轴视图：副行不再重复起止时间（左侧刻度即开始时间）；每段 ≥15 分钟空隙都是可点补录条；
  计时中时长走秒级文本刷新，不再整页重绘丢滚动位置。
- 日视图：块显示「名称 + 时长」；点空白小时按该时刻补录。
- 周视图：改**按小时重叠**渲染（原整点采样导致非整点起始的事件/块整行隐身）；格内显示名称与时长；
  固定 7 列，跨月日渲染为不可点的惰性列。
- 月历圆点由数据实算：计时中红 > 已完成绿 > 计划中蓝。
- 跨天事件按两段行落库，次日在日 / 周视图可见。

## 五、时间账本（L4）独立统计页
新增 `/time-stats`（时间页顶栏柱状图标、仪表盘「本周时间分布」卡两处入口，后者由写死图形改为实算）：
- **日 / 周 / 月 / 年**四档 + `‹ 期间 ›` 翻页，每张卡可折叠；
- 日档 24 小时时钟盘面（扇区=每段事件，红线=当前时刻）；
- 周 / 月档单日时长对比面积图 + 满高底轨堆叠柱；年档热力图 + 单月对比 + 按月分桶；
- 总时长环形含「未记录」灰弧（分母 = 天数 × 1440）；
- 分类排行带次数 / 占比 / 进度条 / **与上期环比**。

## 六、滚轮与弹层瘦身
分钟档 5 分 → **1 分钟**且滚轮循环滚动；滚轮可视 3 行；一级分类每行 6 个；
删除「时长 0/15/30/1时/2时」快捷钮；「标签」「管理」并入一级分组标题行，管理直达分类管理页。
