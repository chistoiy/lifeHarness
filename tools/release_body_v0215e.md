# v0.2.15-tree-overlay（预发布）· 笔记树常驻叠层批：开树真跟手 · 遮罩同帧 · 抬手按位置或甩速定开合（装机 6104）

本枚换的是**树面板的承载方式**（路由式弹层 → 笔记 tab 内的常驻叠层），交互形态照原型不变
（悬浮圆角卡·留边·圆角 16·底部四钮·行内就地两钮）。DB 仍 v42＝覆盖安装不迁移。

## 真机门七条（工单 §3）

1. 屏幕**任意位置**起手右滑＝面板**跟着手指走**，中途停住就停在半途（不是「过阈才啪一下弹出」）。
2. 继续拖过四成或轻轻一甩＝补间全开；推一点点就松手＝回弹收回。
3. 遮罩由浅到深**同帧**变化（手指停住时暗度也停在同一档）。
4. 面板上左滑＝跟手收起，剩不到六成或向左一甩即关。
5. 返回键＝收起树，**不是退出笔记模块**。
6. 卡片左滑进回收站、列表竖着滚＝都不误开树（中途态手指仍归列表）。
7. 长按文件夹→行内铅笔/垃圾桶两钮照旧可用（点图标中心与点边缘都要真执行动作，不是变成选中目录）。

## 与上一枚（6103）的差别
