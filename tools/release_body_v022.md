## 一、V1.57 缺口盘点实现批（本批主体·`ff57199`→`c829cc0`）

### A 分享长图公共通道（`ff57199`）

新建 `lib/shared/widgets/share_card.dart` 收一函（`captureShareCard` + `ShareCardModel/View` +
`showShareCardSheet` + 文字版 `copyText`），**六站点接真渲染**：物品统计卡 / 物品决算卡 / 倒数日详情卡 /
目标归档复盘卡（原「已归档」假 toast 改真入口）/ 记账年度卡 / 习惯分享卡。
统一口径：`RepaintBoundary → PNG → <应用文档目录>/share/<净化名>.png → 提示条回显真实路径`；
不申请媒体权限、不接系统分享面板。**「保存到相册（模拟）」这类假回执全量作废。**

### B 通知排程三枚接真 + 呵护二次验证摘除（`e2d173f`）

- `NotificationService` 补 `scheduleOnce / showBudgetAlert / deferOutOfDnd`（免打扰固定 23:00–07:00，命中即顺延到 07:00）。
- **预算超支提醒**：支出达预算 80% / 100% 各提醒一次，同一预算周期内按 KV 去重；触发落 key 行日志。
- **月度小结推送**：每月 1 日 09:00 推**上月**收支收官（支出/收入/分类大头）；开关关闭即取消排程。
- **儿保体检节点提醒**：节点表驱动（42 天 · 3/6/8/12/18 月龄），按出生日期排下一节点。
- 记账设置三行（预算月起始日 / 预算超支提醒 / 月度小结推送）提示条与副标题按原型逐字改真，两态各说清行为与后果。
- 呵护「进入模块需二次验证」整行**摘除**（产品定调：不遮挡、直接打开，与其他模块无区别），
  遗留键 `care.rm.lock` 读取时一次性清除——它是「只写不读」的假承诺。

### C 时间账本分类明细下钻（`377c319`）

`widgets/ts_cat_sheet.dart` 新半屏：段数 / 合计 / 日均三格 + 逐段列表（日期·备注或分类名·起止 HH:MM·占比条·时长）+
空态 + 「去时间页」。明细谓词与页面汇总、DAO 区间过滤**三处同源**，用例按「明细段数与合计＝汇总行显示值」钉死。

### D 同步「允许严格校验（MD5）」真门控（`7c36a00`）

S1 服务配置弹层补 Switch（编辑态回填既有值）。此前 `verifyContent` 字段**全仓零消费者**，
开关形同虚设；本批接真：`snapshot_service.localInventory(withDigest:)` 仅在开启时逐文件算 MD5
（单文件 >64MB 或读失败自动回落空摘要），`sync_orchestrator.compare()` 按服务配置传参。

### E 待办垃圾箱（`a110e9d`·唯一动 schema 的一批）

- **schema v28→v29**：`todos` 加 `deleted_at INTEGER`（NULL=在册）；迁移只加列不动既有行数据（用例断言迁移后恒 NULL）。
- DAO 补软删五件套：`softRemove / trashed / restore / purge / purgeExpired`；`remove()` 保留为彻底删除通道。
- **在册读数全量加谓词**：`list()`、`countOverdue()`、目标 KR 自动汇聚计数一律 `deleted_at IS NULL`；
  新增源码级守护测试 `test/todo_trash_guard_test.dart`（扫 `lib/**` 直碰 todos 表名的位置，白名单外必须含谓词，
  且带「白名单失效自检」防守护空转）。
- 新屏 `/todo/trash`：行＝象限点 + 标题 + 截止/标签/删于 MM-dd HH:mm + 剩 N 天（≤7 天玫红加粗·过期显「待清理」·
  「不清理」档独立文案）+ 行内恢复/删除；右上「选择」「全选」或长按进批量，底栏 恢复/彻底删除/✕；
  彻底删除走二次确认弹层并逐条列出；空态「暂无已删除的待办」。**恢复＝同一条目回原象限原截止，不新建行。**
- 待办页底部入口行（清单/四象限两视图共用）：计数与保留期文案同源。
- 「记录管理 · 通用 · 回收站自动清理」由占位改真选择器（30/7/90 天 · 不清理，默认 30），落设置键 `lh.trash_keep_days`；
  删除提示改「已移入垃圾箱 · 删除 N 天后自动彻底删除」（读真档位，摘掉「规划 V1.0」）。
- 冷启动按档跑一次 `purgeExpired` 并落 key 行日志：`垃圾箱自动清理：删除 N 条 · 保留期 …`。

## 四、真机验收重点（本版新面）

1. **垃圾箱端到端**：待办详情「🗑 删除」→ 提示条「已移入垃圾箱 · 删除 30 天后自动彻底删除」→ 待办页底部入口行计数 +1 →
   进垃圾箱恢复 → 清单/四象限/仪表盘今日数字同时回补，且是**同一条目**（id 不变）。
2. **期限档位真落库**：记录管理选「7 天」→ 垃圾箱屏头与入口行文案同步 → **force-stop 冷启动后再进仍是 7 天**。
3. **冷启动自动清理**：应用内日志页出现 key 行 `垃圾箱自动清理：删除 N 条 · 保留期 …`。
4. **分享长图真实出图**：任选一站（建议物品统计卡 / 目标归档复盘卡 / 记账年度卡）→「保存图片」→
   提示条回显真实文件路径，核图宽 1080、卡片不糊。
5. **同步严格校验开关**：S1 服务配置打开「允许严格校验（MD5）」后，差异对比可选「严格 MD5」档；关闭则自动降级并提示。
