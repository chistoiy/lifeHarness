# v0.2.15-note-export（预发布·**待产品同意才挂**）· V1.64 批3：笔记导出为本地目录（装机 6105）

本枚动的是**导出写入侧**（原生 `lh/saf` 通道扩口＋新的导出半屏），树的形态与手感照 6104 不变。
DB 仍 v42＝覆盖安装不迁移。

## 真机门八条

1. 打开笔记页 → 右滑出文件树 → 底条第 3 枚（移到文件夹那个线性图标）＝「导出为本地目录」，按下出半屏。
2. 半屏默认停在**全部笔记**；没在树里点选过文件夹时，点「当前目录」＝**切不过去**并出一句「先在树中点选文件夹，或改选「全部笔记」」；点选过之后这档才带得上夹名。
3. 按下「选择目录并导出」＝系统目录选择器出现；**中途取消＝什么都不发生**（不转圈、不弹提示、树上不多节点）。
4. 选一个真目录后：进度行出现 → 完成出一句「已导出 N 篇 · 附件 M 张」；用手机文件管理器进那个目录，应看到 `笔记导出/` 里面每篇一个 `<标题>.md`。
5. **带图片的那篇是这枚包能不能用的判据**：`笔记导出/_assets/` 里有原图，md 里的引用是相对路径，**在手机上用阅读器打开这篇 md，图片要显示出来**。
6. 同一个标题导出两遍（或库里本来就有两篇同名）＝文件名自动 `(2)`，不互相覆盖；标题里带 `/`、`:` 的笔记，文件名里这些字符换成横杠。
7. 文件树上应出现一枚「笔记导出」带「导出」标：**长按它＝走既有的「移除挂载」确认层**，确认后磁盘上的导出包与库内笔记都不动；同一目录**再导一次**＝树上不重复建节点、目录里不出现「笔记导出 (2)」这样的重复文件夹。
8. 只读守卫两条：① 导出夹里的笔记在应用内再编辑保存＝**不许写回导出包**（也不许弹「写回失败」这种谎话，静默只改库里）；② 选一个当初只给了读权限的老目录＝出一句「这个目录只有读取权限 · 没能导出」，而不是转圈或假装成功。

## 与 6104 的差别

- 6104＝笔记树换承载（常驻叠层·开树真跟手）；本枚＝树底条补齐导出入口＋原生通道支持写附件与建目录。
- 底条由四枚变五枚，并改成等分排布：360dp 宽屏上五枚钮的命中格 44.6（旧排布加第 5 枚会把右端挤出卡面）。
