# 预发布 v0.2.1-r14-fidelity-logs（0.2.1+4032 · 数据库 v28）

发布日期：2026-09-29 ｜ 分支：`feat/m0-skeleton` ｜ 上一版：v0.2.0-governance

本版收 R14 真机走查派生的保真修订与日志覆盖专项，另含并行会话交付的小工具（V1.47）
与在线书源（V1.55，仅原型/预研）批次。装机包体为 release split-per-abi 三包。

## 一、本版本内容

### 1. UI 保真批 V1.54（R14-7/8/12/13/14 · `4fcfcce`）

原型先行并经逐屏确认后落实现（提交 `bf4ae06` / `b271deb` / `e090cdf` 为对应原型批）：

- **设置族去 emoji（R14-7）**：设置族三页入口图标由 emoji 换 Material 线性图标，
  标题与副标题按原型对齐；页内教学性说明文案摘除，只留功能标签与状态提示。
- **块视图与仪表盘去教学化（R14-8）**：日视图块视图刻度读数、仪表盘教学行清理。
- **我的页资料可编辑（R14-12）**：昵称/签名走**半屏编辑弹层**，数据落设置项 KV，
  **不新增表**（无迁移成本，备份随整包走）。
- **三张统计卡联动（R14-13）**：书架/日记/物品卡由写死数字改为「基数 + 实时聚合」，
  与模块数据源同口径。
- **今天页问候卡全实算（R14-14）**：四数（今日待办/场安排/完成环/精力占比）单一实算入口，
  与「今日日程」列表同源同数；顺带修 V1.52 迁移清空 `events` 后「今日日程」恒空的问题。
  已定口径：今日待办＝截止日=今天；场安排＝今日日程列表条数；完成环与精力占比只算今日/未完成。
- 阅读器顶栏/设置页纯图标钮补语义标签（`36b3164`），无障碍与 adb 自动化可命中。

### 2. 日志覆盖专项 L1~L5 收口（`df1d205` `5fc57c6` `c00f363` `bbee577` `4a88de6`）

按 `docs/日志覆盖工单-20260929.md` 五批铺完，**全程只加日志、零行为改动**：

- **L1** 数据库建表/升级/逐级迁移（每级前后 key 行带版本号与影响行数）+ 备份导出/校验/解包/导入四链路。
- **L2** 通知排程降级链（精确闹钟→普通→被系统杀）、AI 调用与服务商台账、图片引用与孤儿清理；
  AI 密钥**只记槽位名，绝不记 Key 本体**。
- **L3** 账单解析编码回落链与汇总、导入预览与**落库 key 行含批次 id**（页面没有撤销入口，只能从这条追）、
  待办读取失败留痕（按文案去重后 `rethrow`）、日程 `markRange` 段数前后对照。
- **L4** 习惯落账（结算 streak/best 写进行文）、呵护速记与删档级联、日记读写与富文本回退、收集箱四向分流。
- **L5** 日子派生刷新、目标自动汇聚失败归因（源·KR·期）后照抛、物品建档/二次付费/回收/报废四动作。

**架构守护「catch 必带日志」已上线**（`f1b6300`）：`lib/**` 每个异常处置块——含不带 `catch` 的
`on X {…}` 回落——必须「记日志 / 重抛上交 / `catch-ok: 理由` 批准注释」三者之一，
新增静默吞噬直接红；存量 108 处/51 文件走登记式棘轮，只许减不许增。

## 二、已具备能力

- 全模块操作可在应用内「日志页」复盘：级别 × 来源 × 关键词三重筛选，一条记录＝落盘一行，堆栈可折叠。
- 日志随整包备份导出，跨设备排查不必连 adb。
- 数据库迁移逐级留痕（版本号 + 影响行数），「升级后数据不对」类反馈有线索可查。

## 三、已知占位项

- 在线书源（V1.55）仅原型与预研，功能待排期。
- R14 余项仍卡原型门：待办页长按拖拽排序 / 智能筛选提示 / 逾期提醒样式、其余屏 emoji 清理、
  心情九宫格（产品决策）、轮5④ 脚注精排取「暂缓」。
- 静默 catch 存量登记面 108 处待各批次随批递减，其中 read(47) / kits(2) 属并行会话写区。

## 四、安装要求

- Android 8.0+（minSdk 26），纯本地无账号，无需网络权限即可使用全部本地功能。
- 数据库 **v28**：从 v0.2.0-governance（v27）覆盖安装即自动迁移，**请勿卸载**（卸载＝清数据）。
- 三包按设备 ABI 选：`arm64-v8a`（主流真机）/ `armeabi-v7a`（老旧 32 位）/ `x86_64`（模拟器）。
  已装分包者复测请继续用同 ABI 分包，universal 包会被系统判「无法降级」。
- 签名仍为 debug key（正式签名随发布工程配置）。
