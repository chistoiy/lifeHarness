# v0.2.13-media（预发布 · 正式版口径 · release split-per-abi 三包）

钉版提交 `20c5a51`（`0.2.13+4089`）· 从这一枚提交在新开 worktree 里构建（`lh-rel20c5a51`）· 包体 versionCode 按 ABI 抬偏移：**arm64＝6089 / armeabi-v7a＝5089 / x86_64＝8089**（出包后以 `aapt2 dump badging` 逐包实测为准）。

数据库 **v36 → v38 两级迁移**（本版累计）：`migrations[36]` 建健康 `health_*` 十四表＋「本人」档案种子，`migrations[37]` 建影音游 `media_*` 七表。**覆盖安装即自动升级，数据不丢、无需卸载重装**。

## 本版本内容

### 影音游模块解禁并开工（产品令 2026-10-07「影音游解禁可以开发」，此前「延后裁定」作废）

- **数据层（批1）**＝`media_items`/`media_sessions`/`media_notes`/`media_units`/`media_dict`/`media_lists`/`media_list_items` 七表；条目主键是**文本**（外部 id 归一后直接当主键）；八个外部来源（豆瓣/IMDb/TMDB/TVDB/MusicBrainz/Discogs/Steam/IGDB）各建一条**部分唯一索引**——同一个 IMDb 号第二条直接撞库、不同来源互不干扰、没填来源的照常并存；影音笔记带去重哈希；来源字典预置 14 家。
- **影音架（批2）**＝模块第一屏，三种视图：**桌面**（三列卡墙）·**脊**（等高侧脊，**电影没有侧脊＝这一视图里自动不出现**）·**列表**（缩略＋按类型各说各话的副行：电影＝年份·时长·导演，剧集＝几季几集·看到第几集，音乐＝曲目数·循环次数，游戏＝周目·主线%·发行商）。类型 chip 五枚（全部/电影/剧集/音乐/游戏，角标＝在册条数）＋分区 chip（全部类型下按语义归并四档：未看／在看·追·玩／看完·追完·通关／搁置；单类型下就是该类自己的分区）＋搜索（片名·原名·主创·发行·标签）。
- **四类卡＝各自形态**（原型 `.mds-item` 扁平 V3，与主框架同一语言；**微拟物方向 2026-09-23 已被否决，本版不实现卡带/BOX 翻盖/双层光影**）：影视＝3:4 竖版封面＋底部压暗标题带；音乐＝封套＋探出的黑胶（盘面纹路·中心标·轴孔自绘）；游戏＝16:10 key-art＋周目/发行商角标。**没有封面时按条目色板出渐变＋标题首字**（与书籍侧书脊色板同构机制；只做本地上传，不拉第三方封面 API＝版权边界）。
- **新条目录入按类型分派四套字段**（不是一张表单换个标题）：电影＝时长＋进度方式（百分比/时间点）；剧集＝季数＋总集数＋看到第几集；音乐＝曲目数（**循环次数按听歌会话自动计，明确不在此填**）；游戏＝周目数＋三档进度方式（剧情主线%/周目/成就完成度）。名称留空＝红字写在字段旁，不弹提示条；保存进行中按钮给可见禁用帧，连点只落一条。
- **长按批量**＝选中数＋改分区／加标签／删除三个动作（选中态下卡面右上评分换成选中圈）。改分区在「全部类型」下按各类自己的分区落值（"在看/追/玩"这种归并标签绝不写进库）；加标签＝追加且去重；删除＝进回收站口径的软删（必二次确认，7 天内可找回）。
- **入口接通**：记录页第四段「影音游」不再是「规划 V1.1」占位卡，改成**真实影音架入口**（在册计数＋四类直达＋桌面俯瞰最近四条）；该段的 ＋ 钮＝新条目录入；今日仪表盘宫格补**「影音游」一枚**（线性图标，直达影音架）。

### 阅读器划线热链三条（真机 6085 已过门）

- **同段多条划线各自铺色**：此前一段只留一条，后划的把先划的顶掉。
- **长按选区在场时已有划线不再整段消失**：选区外每一截按划线区间切段铺底，选区那一截仍吃选区色。
- **删划线不再同段连坐**：只删与当前选区真相交的那条，提示条带条数。

## 装机与自验清单（真机主流装 `app-arm64-v8a-release.apk`）

1. **影音架三视图**：今天页宫格点「影音游」→ 应进影音架；桌面三列卡墙；点顶栏「脊」→ **电影那两条不该出现**，剧集/音乐/游戏都在；点「列表」→ 每行副行按类型各说各话。
2. **四类卡观感（1080 宽不糊不截字）**：新建四条（四类各一）看卡面——影视竖版封面/音乐封套＋黑胶/游戏横版 key-art；长标题应省略号收尾不溢出；没有封面时应是色板渐变＋首字，不该是断图或纯色块。
3. **录入四套字段**：点 ＋ → 依次切四类，字段组应**跟着变**（电影出时长＋进度方式；剧集出季数/总集数/看到第几集；音乐出曲目数并写明循环次数不在此填；游戏出周目数＋三档进度方式）。名称留空点保存 → 红字应写在名称下方，不弹提示条；补输入红字即撤。
4. **长按批量**：长按任一张卡 → 底部出「选中 N · 改分区/加标签/删除」（**右端删除要真点得到，不被 ＋ 钮压住**）；改分区在全部类型下选「在看/追/玩」，四条应分别变成 在看/在追/在玩/在听；加标签重名不双写；删除出二次确认，确认后卡出列、计数减。
5. **脊视图置灰**：类型切到「电影」时顶栏「脊」钮应置灰点不动（点了不许悄悄切视图）。
6. **记录页第四段**：记录页右上 ⇄ 切「影音游」→ 应是真实影音架入口（在册计数＋四类直达＋最近四条），不再出现「规划 V1.1」字样。
7. **划线三条复扫**（6085 已过门）：同段连划两条不同子串都在；长按选区在场时已有划线不消失；删划线只掉与选区相交那条。
8. **深色三档复扫**（6086 已过门）＋影音架在深色下的观感（本版新增面，深色观感门见「已知未做」）。
