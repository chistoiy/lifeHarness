## 本枚内容（笔记树手感批·批2＝两条手势手感）

- **右滑开树全程跟手**：以前是"推到一定距离树才弹出来"，现在手指一过起点阈值树就跟着出来，**面板随指推出、遮罩同步变淡**；松手时按"拖到位（超过约四成）或者甩得快"决定是补间全开还是回弹收起。树面板上**往左滑也是跟手收起**（同一套进度反向走），松手按位置决定关回还是弹开。
- **长按文件夹改成就地动作**：长按一个手建的文件夹，行尾直接出现**重命名／删除**两枚小图标（不再弹出那层白色半屏菜单）；再长按同一条、点别的文件夹、点展开箭头都会收起；重命名仍是就地输入框。挂载目录（本地导入／导出）长按仍然走「移除挂载」确认半屏，语义没变。

## 装机自验清单（真机门 · 6101 六条）

1. 从屏幕左边起手右滑 → 树**跟着手指走出来**（不是等推够距离才弹），中途停住面板就停在半途；继续拖过半再松手 → 补间全开。
2. 右滑只推一点点就松手 → 树**回弹收起**；快速轻甩一下（位移不大）→ 应该开出来。**这条"甩速"判定只能在真机上验**，自动化测试里读不到速度。
3. 树开着时，在面板上往左滑 → 面板跟手往回走，松手过半即收起；没过半 → 弹回全开。
4. 卡片上左滑**仍然是移入回收站**，不会被误判成"关树"；点树右侧内容区 → 照旧收起。
5. 长按手建文件夹 → 行尾就地出两枚图标钮；按重命名 → 出输入框并改名成功；按删除 → 该文件夹摘掉（里面的笔记不删、子夹上移）；点别的文件夹 → 动作收起。
6. 上一枚（6100）的真机门四条照跑：边缘右滑不吃系统返回／左滑回收站如旧／四锚触觉（滚轮吸中·破坏确认·长按进管理·复习翻面）逐条感受。
