## 本版本内容（自 v0.2.14-health-media 起 38 枚提交·三条线）

### 笔记 · V1.64 本地导入／系统打开方式／挂载移除（批1＋批2）

- **手机里点一个 .md → 选本应用打开**＝自动导入到文件树内固定的「系统打开」夹并直达编辑器；**改完保存会写回手机里的原文件**；原文件已删或授权失效时降级为「仅存应用内」并出一行人话提示，不静默糊过去。同名文件再次打开＝更新那一条，不堆副本。
- **导入本地（目录）**＝树底新入口，选一个目录后**按手机里的层级还原**：子文件夹各成树上一个带「本地」标的节点，笔记归到各自那层，导完自动展开；只收 `.md`/`.markdown`，隐藏项与图片不进来；**按内容哈希判重**，重复的跳过并汇总「已导入 N 条 · 跳过重复 M 条」，回收站里的不算重复。
- **导入本地（单/多文件）**＝多选文件落进当前目录并给该目录挂「本地」标（没选目录＝落未归类）；该标会随目录内本地来源笔记清空自动回落，不留假标。
- **移除挂载**＝长按「本地」或「导出」标的节点出确认层，三行后果按当前实数写（只从树摘掉该挂载连同子夹／手机里的目录与文件不删除／已导入的 N 条笔记保留在库且来源标仍可筛）；确认后**只摘挂载记录**，笔记一条不少，重启不复活；固定的「系统打开」夹与手建文件夹没有这个入口（删除它也会给一句实话，不再点了没反应）。

## 装机自验清单（真机门 · 6098）

**本批新增（笔记 V1.64 四条）**

1. 系统里用一个文件管理器打开任意 `.md` → 可选程序里出现本应用 → 进入后落在「系统打开」夹并直开编辑器；改一个字保存 → 回手机文件管理器看原文件，内容已更新。
2. 把那个原文件删掉 → 再进应用编辑同一条并保存 → 出「仅存应用内」类人话提示，不崩不静默。
3. 导入本地选一个**带子文件夹**的真目录 → 树出层级节点、各带「本地」标、导入后自动展开；**再导一次** → 汇总「已导入 0 条 · 跳过重复 N 条」且笔记总数不多出。
4. 长按「本地」节点 → 确认层三行数字与实数一致 → 确认后节点消失、笔记仍在（全部笔记计数不变）、杀进程重开不复活；长按手建文件夹与「系统打开」→ 不出「移除挂载」。
