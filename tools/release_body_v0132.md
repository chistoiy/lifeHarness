# v0.1.32-reader（预发布）

**日期**：2026-09-28 ｜ **分支**：`feat/m0-skeleton` ｜ **版本**：0.1.32+4030 ｜ **数据库**：v27

阅读器 V1.53.2 轮5~轮5.3 的 Flutter 落地（高保真原型已先行逐屏确认），另含 AI 调用整改（R7 架构门）。
完整说明见仓库 `docs/发布说明/release_notes_v0.1.32-reader.md`。

## 本轮变更

**阅读器 UI 统一（轮5.1 / 轮5.4）**

- 底栏五图标 → **三图标：目录 / 进度 / 外观**；原内嵌的进度·亮度·字号面板全部升格为正常底部弹层。
- 主题 / 亮度 / 字号 / 行距 / 字距 / 边距合并进「外观」弹层；新增背景色预设、**自绘色相+明度取色**
  （不使用系统取色器）、**纹理背景**（纸纹/牛皮/网格）、**相册图片背景 + 淡化档**。草稿制：取消丢弃、
  保存应用按「本书专属 / 全部书籍」落库。
- 顶栏补「⋯ 本书操作」弹层：八宫格 + 阅读模式（翻页⇄滚动）+ 书摘/详情/阅读器设置 + 屏幕常亮。
- **顶栏/底栏随阅读主题取色**（浅底浅栏深字、深底深栏浅字 + 背景模糊），不再固定黑条。
- 进入阅读器自动**挂起全局读书计时条**（避免重复计时信息），退出恢复。

**选区改系统复制式（轮5①）**

- 长按默认命中一句，扩选改为**首/尾两枚可拖动手柄**（跨行跨段、两端相遇自动互换）。
- 摘抄工具条移除「前扩 / 后扩」；保留 复制·划线·写想法·书摘·查询·听当前·AI 解读·分享。
- 修正手势冲突：有选区时不再挂父级横向滑动翻页识别器（否则手柄横向拖不动，真机同样成立）。

**目录与跳转返回（轮5②③ / 轮5.2①）**

- 目录抽屉新增**「全部折叠 / 全部展开」**一键钮（与逐组折叠共存）。
- 跳章后**抽屉内**出现「‹ 回到刚才在读 · 章名」；拖离进书位置后**进度弹层内**出现「回到进书位置」。
- **正文不再悬浮任何胶囊**（删除原「返回原进度」浮条）；章节名闪现提示按拍板保留。

**阅读计时自动结算（轮5.2② · DB v27）**

- `book_sessions` 新增 `from_chapter/to_chapter/from_pct/to_pct`（v26→v27 迁移 + 建库同文）。
- 进页自动记起始位置、退出结算自动写结束位置（章节 / 全书页 / 百分比），**不再手填**；提示条播报结果。
- 新增门槛 `read.brMinSecs`（默认 30 秒）：未达门槛则时长与会话都不入账（明细不留痕），进度照常更新。
  位置：设置 › 阅读 › 本地阅读器 › 「短于该时长的阅读不计入」。
- 书架时间线与阅读记录页展示起止章节/页/百分比。

**书籍详情页（轮5.3）**

- 「本地 EPUB」整卡上移到信息行之下、三 tab 之前，压成**两行紧凑条**（进度/位置/划线 + 打开/检索/删除 + ?）。
- 「?」新增**本地文件与缓存说明**半屏（路径、体积/加密/版式、删除两口径说明、缓存态与清理入口）。
- 预载中 / 已清缓存等非就绪态仍保留原四态行，重新载入与重选文件入口不丢。

**AI 整改（R7）**

- 划词「AI 解读」的摘录感想改走统一入口 `aiRunWithReview`，阅读侧不再自建第二条请求路径；
  阅读侧对 R7 棘轮的豁免已清空。

## 验证

- `flutter test` 全量 **1467 例通过**；`flutter analyze` 本轮改动文件零 error/warning。
- 原型回归 `tools/reader/bs5{5,6,7,8,9}check.js` 共 68 断言全绿。

## 已知边界

- 脚注/角标与精排（fixed-layout）包渲染仍不支持（轮5④范围待拍板）：解析不识别 `<sup>`/`aside`/`epub:type`，
  内链一律剥锚点，只能跳目标章首页。
- TTS 朗读按既定拍板延后，「听当前」为占位提示。
