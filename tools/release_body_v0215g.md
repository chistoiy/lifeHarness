# v0.2.15-nav-collapse（预发布 · release split-per-abi · **只挂一枚 arm64**）

钉版提交 `1972501`（`0.2.15+4106`）· 从这一枚在新开 worktree `lh-rel1972501` 里构建 · 分包形态 arm64 抬偏移：**装机 versionCode 期望 6106**（出包后以 `aapt2 dump badging` 实测为准）。

**本枚是攒批发行**：自上一个已挂预发布 `v0.2.15-tree-swipe`（6103）之后，6104／6105 两枚复测包按产品令只装机、未挂预发布；本枚把攒下的四块内容一起挂出。
数据库 **v42 → v43**（**纯加列·零搬数据**，覆盖安装自动升级、数据不丢、无需卸载）：**v43**＝V1.64 批4 给 `notes` 加 `wb_at`（最后一次成功回写原文件的时间，＝三态判定里「已回写／仅应用内」的唯一依据）。

机上若是 6103／6104／6105（同签名）→ 本包为正常升级路径，覆盖安装即可。

## 本版本内容（四块）

### 壳层 · 底栏双指收起态（V1.65 · 本轮）

- 壳内任意页**双指张开＝底栏整条收起、内容通底**；**双指捏合＝底栏回来**（方向以轮4 原始需求为准）。
- 收起后底栏不占位，页底留白让过系统手势条；底部常驻一条**可见线索**防「东西去哪了」——两条形态（A 细握把 / B 胶囊折角）在「设置 › 外观 › 底栏手势」切换，线索距屏幕底部 **8–48px 可调（默认 16）**。
- **手势总开关默认关**＝新装/升级零行为变化，用户自己到设置里开；关掉即完全失效、已收起态立刻展开。
- **悬浮球不落底**：收起态下页面级悬浮球按屏幕位置钉住，不下坠。
- 双指手势**只观察不消费**（不进手势竞技场），不抢子页的列表滚动／卡片左滑／长按。

### 笔记 · 「系统打开」树顶固定行＋历史半屏（V1.64 批4）

- 文件树顶部恒定一行「系统打开」（**只有一处**），带「临时」标与条数；点它开的是**历史半屏**（不是切目录）。
- 半屏每行＝标题＋本机路径＋打开时间＋三态胶囊（已回写原文件／仅应用内·原文件不在／已转正式目录）；就地两步确认「清空」（只软删仍在临时夹的进件、已转入的不动）；「转入正式目录」复用既有「移动到文件夹」弹层。
- 该夹从下方普通节点里排除（防重复计数）。

### 笔记 · 导出为本地目录（V1.64 批3 ＋ follow-up）

- 树底第 3 枚「导出为本地目录」→ 半屏 → 系统目录选择器 → 每篇一个 `<标题>.md`，带图笔记的图片进 `笔记导出/_assets/`，md 里用相对路径引用；导出夹在树上挂「导出」标，长按可走「移除挂载」（只摘记录、不删磁盘文件）。
- **follow-up**：富文本里若是 http 外链图片（没进附件包），导出时**原样保留**外链（不再写成指不到的空相对路径）。

### 笔记 · 树换承载（常驻叠层批 · 6104）

- 树面板由路由式弹层改为**笔记 tab 内的常驻叠层**：屏幕任意位置起手右滑＝面板跟着手指走、中途停住停在半途；过四成或甩速即补间全开，推一点点松手回弹；遮罩同帧变化；面板上左滑跟手收起；返回键收起树、不退出笔记模块。

## 装机自验清单（真机门 · 6106）

**本枚新增 · A 底栏双指收起态（V1.65）**

1. 壳内任意页（今天/待办/日程/笔记等）双指**张开** → 底栏整条收起、内容通到底部；双指**捏合** → 底栏回来。
2. 「设置 › 外观 › 底栏手势」总开关**出厂为关**：关着时双指手势完全无效（页面无任何变化）。
3. 打开总开关后：线索出现（出厂形态＝细握把）；切到「胶囊折角」→ 线索立即换形。
4. 距底滑杆拖动 → 线索位置实时跟着变；最小 8、最大 48 都试一下。
5. 收起态下：页面右下角的悬浮球**不下坠**（仍按原屏幕位置钉住）。
6. 收起态下竖着滚列表、卡片左滑、长按 → **都不误触发**收放。
7. 线索在**最小 8px** 档时，真机底部手势条上仍能看到、且不被系统吃掉（模拟器给不了）。
8. 把总开关关掉 → 若之前是收起态，**立即展开**并回展开几何。

**本枚新增 · B 「系统打开」树顶行＋历史半屏（V1.64 批4）**

9. 树上恒定有「系统打开」行且只有一处，带「临时」标与条数；点它开半屏（不是切目录）。
10. 经系统打开一个 `.md` → 进编辑改两字保存 → 历史行显示「已回写原文件」。
11. 再改一次但故意不给写权限（或把原文件移走）→ 保存后该行回到「仅应用内 · 原文件不在」。
12. 点「转入正式目录」→ 出现的是既有「移动到文件夹」弹层；转入后该行变「已转正式目录」且**不再有转入钮**。
13. 点「清空」→ 第一次只变「确认清空？」，第二次才删；**已转入的那条还在**。
14. 清空后的条目应能在全局回收站恢复。
15. 无进件时半屏显示虚线空态「还没有经系统打开的文件」。
16. 进件数、树上「临时」标计数与半屏列表**同一份读数**（不各算一套）。

**随本包一并复验 · C 导出为本地目录（V1.64 批3）**

17. 树底第 3 枚「导出为本地目录」按下出半屏；默认停在「全部笔记」；没在树里点选过文件夹时点「当前目录」＝**切不过去**并出一句提示。
18. 按「选择目录并导出」→ 系统目录选择器出现；**中途取消＝什么都不发生**（不转圈、不弹提示、树上不多节点）。
19. 选一个真目录后：出进度行 → 完成出一句「已导出 N 篇 · 附件 M 张」；文件管理器进那个目录应看到 `笔记导出/` 里每篇一个 `<标题>.md`。
20. **带图片的那篇是这枚包能不能用的判据**：`笔记导出/_assets/` 里有原图，md 用相对路径引用，**在手机上用阅读器打开要显示图片**。
21. 同一标题导出两遍 → 文件名自动 `(2)` 不覆盖；标题带 `/`、`:` 的换成横杠。
22. 树上出现「笔记导出」带「导出」标：长按走既有「移除挂载」确认层，确认后磁盘包与库内笔记都不动；同一目录**再导一次**＝树上不重复建节点。
23. 只读守卫：导出夹里的笔记在应用内再编辑保存＝**不许写回导出包**，也不许弹「写回失败」这种谎话。
24. 选一个只给了读权限的老目录 → 出一句「这个目录只有读取权限 · 没能导出」，而不是转圈或假装成功。

**随本包一并复验 · D 树换承载（常驻叠层批 · 6104）**

25. 屏幕**任意位置**起手右滑＝面板**跟着手指走**，中途停住就停在半途。
26. 继续拖过四成或轻轻一甩＝补间全开；推一点点就松手＝回弹收回。
27. 遮罩由浅到深**同帧**变化（手指停住时暗度停在同一档）。
28. 面板上左滑＝跟手收起，剩不到六成或向左一甩即关。
29. 返回键＝收起树，**不是退出笔记模块**。
30. 卡片左滑进回收站、列表竖着滚＝都不误开树（中途态手指仍归列表）。
31. 长按文件夹 → 行内铅笔／垃圾桶两钮照旧可用（点图标中心与点边缘都要真执行动作，不是变成选中目录）。
