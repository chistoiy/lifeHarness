# v0.2.12-ux2（预发布 · 正式版口径 · release split-per-abi 三包）

钉版提交 `54fd65a`（`0.2.12+4077`）· 从自己的提交在新 worktree 构建 · 包体 versionCode 按 ABI 抬偏移：**arm64＝6077 / armeabi-v7a＝5077 / x86_64＝8077**（出包后以 `aapt2 dump badging` 逐包实测为准）。数据库 **零迁移**（仍 v36），覆盖安装即可，数据不丢。

## 相对 v0.2.11-ux 的变更（UX 审计真机批·实现面 ＋ 备份批 B-1 ＋ 轮5 F5-3）

- **阅读计时实时刷新**（`567e84d`）：阅读结算／编辑／删除后，时间模块日视图与月圆点**当场更新**，不再要冷启动才看得见（八处写点全接同一刷新出口）。
- **阅读统计热力图**（`4aad818`）：进屏不再停在 1 月——当年贴最近有数据的周、按月贴该月首列、往年贴该年第一个有数据的列；格子上方新增**月份刻度**（与列同节距对齐）。此前「全年有数据却看着整片灰」＝有数据的月份滚在屏外且无位置提示。
- **底部导航固定栏目**（`4aad818`）：「我的」页导航自定义卡里，今天／我的两枚不再画成关着的开关，改**常开＋置灰＋点不动**。
- **回收站保留期入口挪位**（`b5e3519`·轮5 F5-3）：档位设置从「记录管理」撤出，改放**回收站屏右上角时钟图标钮**→半屏四档单选（7/30/90 天·不清理，副注照原型）；改档后屏头期限与每行剩数即时随动。
- **统计页窄屏溢出同治**（`1ed0a46`·U11）：目标卡三枚按钮（生成周报／年度总结报告／调整年度目标）与四宫格在 390dp 下的 `RenderFlex overflow` 消除（按钮换紧凑胶囊＋可换行，宫格改固定主轴高度）。
- **备份文件管理屏**（`70d5215`·备份批 B-1）：「我的 › 数据与同步 › 备份文件」新屏，列出应用 `exports/` 里的全部备份包（本机导出／云端下载／恢复前自动三档角标），行内**恢复**直接进既有校验链（校验→口令→二次确认→整库替换，恢复前自动存 safety 快照），行内**删除**＝物理删除·不进回收站·必二次确认（删到恢复前自动包时另出「回滚资产」警示），支持长按/多选批量删。**这条补的是换机恢复断掉的最后一环**：云同步下载的包落在应用内部目录，系统文件选择器逛不到，此前根本选不到。
- **表情符号清零一处＋新硬闸**（`c4e8854`·T13 档③）：笔记 Markdown 工具条的图片／链接两枚改为线性图标口径（提示条去表情）；新增 `emoji_triage --check` 接进文档门禁——「代码里有、原型里没有」的表情符号只许出现在带理由的白名单里，新增即红灯。

## 装机与自验清单（真机主流装 `app-arm64-v8a-release.apk`）

1. **实时刷新**（6076 欠的那条）：阅读计时结算后**不退出**直接切到时间页，那块时间应立刻在。
2. **热力图**：进「记录 › 阅读 › 统计」，热力图应停在最近有读书记录的几周，上方能看到月份刻度。
3. **底栏固定项**：「我的 › 底部导航栏自定义」，今天／我的两枚＝开且点不动（置灰），其余照常可切。
4. **回收站档位**：进「我的 › 回收站」，右上角时钟图标 → 选「7 天」→ 屏头期限与各行剩数应立刻随动；再进「记录管理」确认已经没有「回收站自动清理」那一行。
5. **备份文件屏**：「我的 › 数据与同步 › 备份文件」——列表应含本机导出与云端下载的包（角标区分）；点某行「恢复」应直接进校验报告（不必再经系统选择器）；点「删除」应出「物理删除 · 不进回收站 · 不可恢复」，若那枚是恢复前自动备份还会多一行回滚资产警示。
6. **统计页窄屏**：手机上滑到「年度目标」卡，底部三枚按钮不应再有裁字/溢出。
7. **笔记工具条**：笔记 Markdown 编辑态底部工具条的图片／链接两枚应为线性图标，链接添加成功提示不再带表情。
