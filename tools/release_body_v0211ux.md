# v0.2.11-ux（预发布 · arm64 单包复测形态）

钉版提交 `758aeef`（`0.2.11+4075`）· 包体 versionCode=6075（arm64 +2000 偏移）· 从自己的提交在 worktree `lh-ux6075` 构建。正式版将按惯例补挂三包。

## 相对 v0.2.10-underline 的变更（UX 审计真机批·批1 ＋ 流程流水线批）

- **U2 返回语义修复**：主清单显式 `android:enableOnBackInvokedCallback="false"`——Android 15+ 预测式返回通道上壳层 `PopScope` 不生效，此前「今天页一次返回＝退到后台」；修复后非 tab 模块一次返回落回「今天」、tab 模块二次返回才退出。出包预检已加同条硬闸防回潮。
- **彻底删书连带清计时块**：回收站「彻底删除」与 30 天自动清理路径下，`book_sessions` 对应的时间块不再成为孤儿（此前阅读统计与今天页时长对不上）。历史孤儿块不回填（与手动打点不可分辨）。
- **顶栏标题全仓统一左对齐**（67 处），主题默认 `centerTitle:false`。
- **呵护页顶栏切换补可访问性语义**（读屏可辨「点击切换周期/宝宝」，零视觉变化）。
- 壳层列表底部安全区余量 26dp（按原型 `.safe-pb` 口径；贴底行吞点击 U1 仍在人工复测定性中）。

## 装机与自验清单（产品下载 `app-arm64-v8a-release.apk`）

覆盖安装即可（6071→6074→6075 同签名递增，数据不丢；数据库随首启自动升 v36＝回收站第七类物品）。

1. **返回语义**：从「我的」页/宫格进记账（tab 模块）一次返回落「今天」、二次返回才退 app；进物品详情（非 tab）一次返回直接落「今天」。
2. **成本池**（V1.61 欠账复验）：物品详情记一笔二次付费 → 删除该档案进回收站 → 回收站物品行的「成本池」应＝购入＋二次付费−残值（净值），**不再是购入价**。
3. **U1 人工 5 秒**：「我的」页滚到底，让「外观」行只露上半截时点它的可见文字——看进不进（这条是 U1 定性的关键读数）。
4. **删书账目**：回收站彻底删一本书后，时间模块/今天页不再残留该书的阅读时长块。
