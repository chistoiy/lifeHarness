## 真机（23127PN0CC / Android 16）逐屏走查发现并修掉

1. **展开行里三段正文之间出现大片空白**（最明显的一条）
   `SelectableText` 带 `maxLines: 12` 会按行数预留高度，System / User / 输出 每段都占掉 12 行。
   → 去掉预留行数，正文按内容撑高；并加断言：展开区任何正文的 `maxLines` 必须为 null，防止回退。
2. **顶部统计行被截断成「未成…」**
   411dp 宽下「筛选 N 条 · 入/出 tokens · 未成功 · 今日次数」+ 右侧三个动作钮放不下。
   → 压成「N 条 · 入x/出y · 未成 n · 今日 m 次」，数字一个不少。
3. **入口卡显示「今日 tokens 219p」**
   多余的 `p` 后缀像单位错乱 → 去掉，标签已写明 tokens。
4. **列表底部与空态写了教学文案**
   「点一行展开输入与输出全文」「各模块用一次 AI 就会在这里留一行」「换时间范围或清掉关键词再看」
   → 按既定 UI 规则只留计数与状态，交互靠自发探索。
